## 固定样本与局限

卡片样本在 M2 纠错前按每产品日期/ID 等距冻结，每产品 7 张早期、7 张中期、6 张近期。60 张均保留原始证据和预期结果。Codex 初审判定 56 张保留，4 张剔除：独立平台限制句、无具体能力的 Enterprise 标题、启用指引、安装配对步骤。**剔除样本仍在 60 张分母中，未另选简单样本替换。** 56/60 是包内初审及回归结果；用户已整体确认该复核包通过，未另行提供逐卡评分表。这不构成总体准确率估计。

关系样本取历史分析结果中的 10 条 evolves_from 与 10 条跨产品边，含同一发布内碎片、同主题不同功能、时间较早但不存在采用证据等反例。代码允许明确的时间关联，禁止自动推断因果或能力跟随。精修的主题文案可以解释有直接证据的同一产品能力扩展，但不把该解释泛化成自动连边规则。

仍有 143 张待主题审核的候选保存在 `_review/`，不进入公开索引。既有已验收卡被重新分类为候选时按 M1 规则保护，不直接删去。规则提取每条 Release 最多输出 5 张卡，并过滤低信号维护项，因此卡片数量不等于所有官方变化的数量。三来源刷新不意味着所有卡已由人工逐张验收。

### 重放步骤

从仓库根目录执行，`--output` 必须是仓库外的新目录：

```bash
.venv/bin/python -m pytest -q
.venv/bin/python tests/manual/verify_m2.py --output /tmp/chronolog-m2-review-copy
npm run build -- --directory /tmp/chronolog-m2-review-copy/vault --output /tmp/chronolog-m2-review-copy/site
.venv/bin/python tests/manual/check_m2_publication.py \
  --vault /tmp/chronolog-m2-review-copy/vault \
  --site /tmp/chronolog-m2-review-copy/site \
  --output /tmp/chronolog-m2-review-copy/publication.json
```

`verify_m2.py` 从归档压缩输入复现完整 reconcile，使用 Markdown 历史并校验源 Vault 没被改动。归档采集时间是 2026-10-13，未来执行属于重放，不是未来日期的新抓取。
