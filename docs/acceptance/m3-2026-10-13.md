`m3-live-manual` 为真实手动网络采集，结果是 **failed**，没有写回正式 Vault，也没有推送或部署。详见[来源状态与错误](m3-evidence/live-failure/quality.json)及[可读报告](m3-evidence/live-failure/quality.md)：

- ChatGPT HTTP 失败后，成功使用同日官方浏览器快照，解析 292 条 Release。保留原获取时间 `2026-10-13T10:59:17Z`，没有以本次重放时间替换。
- Cursor HTTP 成功，取得 254 条 Release，获取时间为 `2026-10-13T12:30:42Z`。
- Claude Code 在 GitHub API 第 2 页收到匿名请求限流 403。整批停止，未将部分成功误记为可发布。

该失败之后，采集器新增可选 `CHRONOLOG_GITHUB_READ_TOKEN`，工作流提供只读 `github.token`，并禁止认证请求跟随重定向。最终离线回归覆盖带/不带令牌的分页请求，以及令牌不传给其他 RSS 来源；尚未在真实 Actions 中验证认证采集恢复。本次 live 失败报告保留修复前代码摘要，不冒充修复后的远端成功记录。
