# Protect a project from abandonment cleanup

**Lovable** · 2026-11-03 · [[Themes/safety-privacy|Safety and Privacy]] · Launch · [Official source](https://docs.lovable.dev/changelog) · from [[Releases/Lovable/lovable-2026-11-03-2026-11-03-b62c62d7|Lovable updates — 2026-11-03]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> On Enterprise plans, you can now [protect a project from cleanup](https://docs.lovable.dev/features/privacy-and-security-settings.md#protecting-a-project-from-cleanup) so Lovable never marks it abandoned. A protected project is never deleted for inactivity. Enable **Abandonment protection** in your project's settings, or select **Protect it** on the abandoned project banner. Workspace admins and owners can protect any project in **Security insights**.
>
> Source: https://docs.lovable.dev/changelog
