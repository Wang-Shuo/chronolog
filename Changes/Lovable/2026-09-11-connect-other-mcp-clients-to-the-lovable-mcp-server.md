**Lovable** · 2026-09-11 · [[Themes/apps-integrations|Apps and Integrations]] · Launch · [Official source](https://docs.lovable.dev/changelog) · from [[Releases/Lovable/lovable-2026-09-11-2026-09-11-fe1ab3d8|Lovable updates — 2026-09-11]]

<!-- chronolog:begin region="evidence" -->
> The [Lovable MCP server](https://docs.lovable.dev/integrations/lovable-mcp-server.md) now works with any MCP client that runs on your computer and supports OAuth.
