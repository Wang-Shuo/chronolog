# Dreaming: Lovable keeps its memory up to date

**Lovable** · 2026-11-04 · [[Themes/memory|Memory and Personalization]] · Launch · [Official source](https://docs.lovable.dev/changelog) · from [[Releases/Lovable/lovable-2026-11-04-2026-11-04-22f6b059|Lovable updates — 2026-11-04]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> Lovable now tidies up project memory in the background on paid plans, a process called [Dreaming](https://docs.lovable.dev/features/memory.md#dreaming-how-lovable-keeps-memory-up-to-date). Lovable checks its memory and the rules in your `AGENTS.md` files against your code and the project chat.
>
> Lovable then rewrites or removes what no longer applies, and rules you asked for stay as written. Your app's code never changes, and `AGENTS.md` changes show in the project chat and in version history as **Lovable tidied up its notes**. Dreaming does not use credits.
>
> Source: https://docs.lovable.dev/changelog
