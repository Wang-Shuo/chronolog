# 2 Safety and Privacy changes in Kimi Code 0.40.0

**Kimi Code** · 2026-09-02 · [[Themes/safety-privacy|Safety and Privacy]] · Digest · [Official source](https://github.com/MoonshotAI/kimi-code/blob/main/docs/en/release-notes/changelog.md) · from [[Releases/Kimi Code/kimi-code-2026-09-02-0-40-0-d3ae6ef8|Kimi Code 0.40.0 (2026-09-02)]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Block dangerous shell commands such as shutdown, reboot, or rm -rf in Auto mode, and always ask before running them in Manual and YOLO modes; disable the guard with `[permission] dangerous_command_guard = false` or `KIMI_CODE_DANGEROUS_COMMAND_GUARD=false`.

> Default the workspace trust prompt selection to "Trust this folder" instead of "Don't trust".

Source: https://github.com/MoonshotAI/kimi-code/blob/main/docs/en/release-notes/changelog.md
