# 3 Interface Experience changes in Kimi Code 2.1.0

**Kimi Code** · 2026-09-23 · [[Themes/interface-experience|Interface Experience]] · Digest · [Official source](https://github.com/MoonshotAI/kimi-code/blob/main/docs/en/release-notes/changelog.md) · from [[Releases/Kimi Code/kimi-code-2026-09-23-2-1-0-1c8bbd91|Kimi Code 2.1.0 (2026-09-23)]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Add an experimental fullscreen mode toggle for the TUI. Enable it via the TUI mode setting in `/settings`, or set `tui_mode = "fullscreen"` in `~/.kimi-code/tui.toml`; it takes effect after restarting Kimi Code.

> In fullscreen, click a folded block to open or close it.

> Add a clickable "Jump to bottom" indicator to the fullscreen TUI.
