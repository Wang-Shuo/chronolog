# 7 other changes in Kimi Code 0.8.0

**Kimi Code** · 2026-06-02 · Other changes · Digest · [Official source](https://github.com/MoonshotAI/kimi-code/blob/main/docs/en/release-notes/changelog.md) · from [[Releases/Kimi Code/kimi-code-2026-06-02-0-8-0-0208d31a|Kimi Code 0.8.0 (2026-06-02)]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Use `/goal ` in the TUI when you want Kimi to keep working on one task across turns. For example:

> Kimi shows the goal in the TUI and keeps progress visible while it works. Use `/goal status`, `/goal pause`, `/goal resume`, `/goal cancel`, and `/goal replace ` to manage the goal. This feature is still experimental. Try it and tell us what would make it more useful.

> Add background automatic upgrades, which can be disabled in tui.toml.

> Allow glob searches to target explicit absolute paths outside the workspace.

> Normalize glob patterns before brace expansion to prevent incorrect path matching.

> Prevent modified keyboard release sequences from appearing after exiting the CLI.

> Replace chalk named color with theme-aware hex in session-directory warning.

Source: https://github.com/MoonshotAI/kimi-code/blob/main/docs/en/release-notes/changelog.md
