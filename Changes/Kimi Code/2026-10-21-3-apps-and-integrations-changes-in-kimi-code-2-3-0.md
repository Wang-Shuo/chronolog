# 3 Apps and Integrations changes in Kimi Code 2.3.0

**Kimi Code** · 2026-10-21 · [[Themes/apps-integrations|Apps and Integrations]] · Digest · [Official source](https://github.com/MoonshotAI/kimi-code/blob/main/docs/en/release-notes/changelog.md) · from [[Releases/Kimi Code/kimi-code-2026-10-21-2-3-0-5e4838a5|Kimi Code 2.3.0 (2026-10-21)]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Plugin skills are now invoked by qualified name `:`, so same-named skills from different plugins no longer shadow each other; bare-name invocation no longer works.

> Remote control now supports streaming, and the limit is raised from 10 MiB to 100 MiB.

> Hooks now run in the session's project directory instead of the server startup directory.

Source: https://github.com/MoonshotAI/kimi-code/blob/main/docs/en/release-notes/changelog.md
