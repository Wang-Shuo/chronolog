# 3 Apps and Integrations changes in Kimi Code 0.6.0

**Kimi Code** · 2026-05-29 · [[Themes/apps-integrations|Apps and Integrations]] · Digest · [Official source](https://github.com/MoonshotAI/kimi-code/blob/main/docs/en/release-notes/changelog.md) · from [[Releases/Kimi Code/kimi-code-2026-05-29-0-6-0-a089212f|Kimi Code 0.6.0 (2026-05-29)]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Install plugins directly from GitHub repository URLs, and surface each install's origin and trust level (kimi-official, curated, third-party) in the plugin manager.

> Restrict plugin trust badges to Kimi-hosted plugin CDN URL patterns.

> Align the datasource plugin with the generic two-tool workflow.
