# Add sticky user message summaries in fullscreen mode

**Kimi Code** · 2026-10-14 · [[Themes/interface-experience|Interface Experience]] · [Official source](https://github.com/MoonshotAI/kimi-code/blob/main/docs/en/release-notes/changelog.md) · from [[Releases/Kimi Code/kimi-code-2026-10-14-2-2-0-c9b38331|Kimi Code 2.2.0 (2026-10-14)]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> Add sticky user message summaries in fullscreen mode: when a user message scrolls out of view, a one-line summary stays on screen, and clicking it jumps back to the original message. Fullscreen mode is enabled via the TUI mode setting in `/settings`, or `tui_mode = "fullscreen"` in `~/.kimi-code/tui.toml`.
>
