# 3 Developer Workflow changes in Kimi Code 0.16.0

**Kimi Code** · 2026-06-16 · [[Themes/developer-workflow|Developer Workflow]] · Digest · [Official source](https://github.com/MoonshotAI/kimi-code/blob/main/docs/en/release-notes/changelog.md) · from [[Releases/Kimi Code/kimi-code-2026-06-16-0-16-0-340aad9e|Kimi Code 0.16.0 (2026-06-16)]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Add a built-in `kimi vis` command that launches the session visualizer in your browser, pointed at your local sessions. Supports `--port`/`--host`, `--no-open`, and `kimi vis ` deep-links.

> Stop Anthropic-compatible providers from reading ambient Anthropic shell credentials and custom headers.

> Reduce the maximum height of the `/btw` side panel from half to one-third of the terminal.
