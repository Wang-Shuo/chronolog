# 3 other changes in Kimi Code 2.0.1

**Kimi Code** · 2026-09-18 · Other changes · Digest · [Official source](https://github.com/MoonshotAI/kimi-code/blob/main/docs/en/release-notes/changelog.md) · from [[Releases/Kimi Code/kimi-code-2026-09-18-2-0-1-07e33833|Kimi Code 2.0.1 (2026-09-18)]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Remove the system-prompt rule that forbade all file access outside the working directory.

> Providers can read their API key from a named environment variable via [`api_key_env`](https://github.com/MoonshotAI/kimi-code/blob/main/docs/en/configuration/providers.md) in `config.toml`.

> Stop workspace file watchers from scanning an unbounded project root, and add `[watch] enabled` / `KIMI_CODE_WATCH` to disable watching entirely. See [`watch`](https://github.com/MoonshotAI/kimi-code/blob/main/docs/en/configuration/config-files.md#watch) for details.

Source: https://github.com/MoonshotAI/kimi-code/blob/main/docs/en/release-notes/changelog.md
