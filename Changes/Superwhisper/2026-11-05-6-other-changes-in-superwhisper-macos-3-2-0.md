## Changes in this digest

> Ability to resume a finished meeting to continue recording

> Updates now install automatically, with reminders when an update is waiting

> Mini mode pill now drags more smoothly and snaps into place

> Missed dictations are kept on the clipboard with a notification so nothing is lost

> Empty dictations no longer count toward WPM and time saved
