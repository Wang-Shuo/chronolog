# 3 Model Support changes in Superwhisper Windows 1.6.11

**Superwhisper** · 2026-10-29 · [[Themes/model-support|Model Support]] · Digest · [Official source](https://superwhisper.com/changelog?platform=windows) · from [[Releases/Superwhisper/superwhisper-2026-10-29-windows-1-6-11-e14d8258|Superwhisper Windows 1.6.11]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Clearer notices when a model can't run on hardware. On ARM, Whisper, Cohere Transcribe, and S1-mini explain they aren't available and point to Parakeet or a cloud model.

> Organization-managed custom models now show an organization icon and a short explanation instead of a delete button

> BYOK custom models now blocked when your organization turns off cloud models. Local models, models your organization provides, and local Ollama still work

Source: https://superwhisper.com/changelog?platform=windows
