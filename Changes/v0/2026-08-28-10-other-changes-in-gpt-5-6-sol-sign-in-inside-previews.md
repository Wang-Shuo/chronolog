# 10 other changes in GPT-5.6 Sol, sign-in inside previews…

**v0** · 2026-08-28 · Other changes · Digest · [Official source](https://v0.app/changelog#2026-08-28) · from [[Releases/v0/v0-2026-08-28-2026-08-28-1fac4f32|GPT-5.6 Sol, sign-in inside previews, and zero-config AI Gateway for generated apps]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> A new chat started inside a project begins from that project's own source, whether a GitHub branch, a managed repository, or the production deployment, so v0 has the code from the first message.

> View revision history for your custom skills, including file paths, authors, timestamps, and text diffs.

> The Pull Changes flow reruns the full preview pipeline and restarts the dev server, so dependency, config, and port changes no longer leave a stale preview.

> The publish popover keeps polling for deployment detail and streams live progress instead of getting stuck on Building until a reload, and no longer shows a red error tile on the first publish.

> Starting a chat from the home composer reliably creates a new chat instead of queueing into the previous chat's stream, pasting into an unfocused composer no longer repeats the text, and removing an attachment cancels its in-flight upload.

> Redesigned the settings surface.

> Environment variable requests appear above the composer like questions and approvals, with collapse and reopen that keep the values you entered.

> Download ZIP shows a native Save As dialog where the browser supports it.

> Floating surfaces such as dropdowns, popovers, and menus use a single hairline border so open surfaces stand out, especially in dark mode.

> Console log rows drop the [SERVER] badge and the trailing Z on timestamps.

Source: https://v0.app/changelog#2026-08-28
