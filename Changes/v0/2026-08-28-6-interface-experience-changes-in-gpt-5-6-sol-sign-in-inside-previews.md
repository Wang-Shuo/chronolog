# 6 Interface Experience changes in GPT-5.6 Sol, sign-in inside previews…

**v0** · 2026-08-28 · [[Themes/interface-experience|Interface Experience]] · Digest · [Official source](https://v0.app/changelog#2026-08-28) · from [[Releases/v0/v0-2026-08-28-2026-08-28-1fac4f32|GPT-5.6 Sol, sign-in inside previews, and zero-config AI Gateway for generated apps]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> When a VM dev server fails to boot or install, a compact error bar appears beneath the preview and opens the console log to the exact error when you click it, and the preview keeps its navigation and retry actions in the error state.

> Mid-response updates no longer make the task and deployment UI act as though streaming had ended, new sidebar rows show the generated chat title, and layout shifts in the chat header and preview popover on load are gone.

> Project icons are sourced from Vercel's avatar API again after the old favicon endpoint was removed, fixing letter-fallback icons across the sidebar, library, breadcrumbs, and settings.

> Opening the design-mode font picker no longer corrupts fonts in the rendered app.

> Drag chats into Favorites in the sidebar, and the web-based code editor in the VM panel is available to everyone.

> Sidebar polish: the main nav moved into the scrollable area, navigating to a project expands it, restricted chats show a lock on hover, and the Chats and Projects pages use the page scrollbar.

Source: https://v0.app/changelog#2026-08-28
