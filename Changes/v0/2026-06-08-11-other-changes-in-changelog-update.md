# 11 other changes in Changelog update

**v0** · 2026-06-08 · Other changes · Digest · [Official source](https://v0.app/changelog#2026-06-08) · from [[Releases/v0/v0-2026-06-08-2026-06-08-4f50e6b2|Changelog update]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Design Mode adds a floating toolbar, a layers viewer, and a measure overlay for checking spacing, plus a shortcut to delete the selected element.

> The design systems library has been rebuilt with a new layout, and v0 generates higher-quality output when working from a design system.

> v0 can now generate SVGs with a built-in skill.

> v0 accepts .tgz files as attachments.

> v0 now signs the commits it pushes to GitHub. Commits show as verified, and repositories that require signed commits accept them.

> Queued prompts no longer get stuck after a chat finishes, and the chat keeps its place while you're scrolled to the bottom.

> Snapshots appear without needing a page reload.

> Member search now matches by display name.

> Guest scope names no longer get truncated.

> Documentation header links no longer 404.

> Navigating between chats, settings, design systems, and your library is now instant.

Source: https://v0.app/changelog#2026-06-08
