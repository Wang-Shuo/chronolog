# 4 Account and Access changes in GPT-5.6 Sol, sign-in inside previews…

**v0** · 2026-08-28 · [[Themes/account-access|Account and Access]] · Digest · [Official source](https://v0.app/changelog#2026-08-28) · from [[Releases/v0/v0-2026-08-28-2026-08-28-1fac4f32|GPT-5.6 Sol, sign-in inside previews, and zero-config AI Gateway for generated apps]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Apps v0 generates connect to AI features through Vercel AI Gateway with zero-config authentication, covering text, structured output, embeddings, reranking, images, video, speech, and transcription, instead of asking you for provider or Gateway API keys.

> Sign in with Vercel from inside a VM preview: the preview and the app share an origin so the session sticks, and sign-in opens in a new top-level window when the preview is embedded.

> A "Team or password" visibility option lets a published app require Vercel team sign-in while still allowing access by password.

> Sessions recover more reliably: an invalid or revoked token returns a clear sign-in error instead of a 500, SSO status refreshes when you return to the window, logging out revokes the session server-side, and a cookie-refresh race that could break auth is fixed.
