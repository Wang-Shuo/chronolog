# 4 Collaboration changes in GPT-5.6 Sol, sign-in inside previews…

**v0** · 2026-08-28 · [[Themes/collaboration|Collaboration]] · Digest · [Official source](https://v0.app/changelog#2026-08-28) · from [[Releases/v0/v0-2026-08-28-2026-08-28-1fac4f32|GPT-5.6 Sol, sign-in inside previews, and zero-config AI Gateway for generated apps]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Git auto-push is restored for chats on team-owned projects and for legacy project links that were failing with metadata-mismatch errors.

> The Production Deployment card shows the selected custom domain for teams with a custom deployment suffix, and the publish flow falls back to a .vercel.app domain when a team's preview-suffix entitlement is off.

> Expired team SSO triggers reauthentication when you publish or open a project instead of surfacing a raw SAML error, and Open in v0 shows an actionable error when a linked GitHub base branch is missing.

> Redesigned the header share popover into a centered Invite dialog you can open for any chat, with team sharing defaulting to edit and a View only switch.
