# 16 other changes in Slash commands, the Shopify…

**v0** · 2026-07-21 · Other changes · Digest · [Official source](https://v0.app/changelog#2026-07-21) · from [[Releases/v0/v0-2026-07-21-2026-07-21-009a4b0a|Slash commands, the Shopify integration, and a Snowflake reliability pass]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Attached skills appear as inline chips in the composer, with the same draft persistence, undo/redo, and drag-to-reorder as file attachments.

> v0 plays a sound when it finishes responding while the window is not focused, controlled by a Sound Notifications toggle in Settings that is on by default.

> VM-backed chats can publish even when the chat has no deployable blocks.

> Generated chat titles and project names focus on product identity instead of implementation details.

> The first-publish wizard is simpler: visibility comes before domains, the final action reads Publish, and project creation stays on a stable loading step until it is ready.

> The Import Design System panel opens as a full-height side panel with inline Add buttons, and pasted files attach directly to the drawer.

> Duplicating a chat no longer produces a broken copy that fails its first build.

> Environment variables added in v0 reach published apps on teams that enforce Sensitive Environment Variables.

> The publish popover shows the subdomain you chose while the deployment builds instead of the raw deployment URL.

> The stop button is visibly disabled during the send window before the response starts streaming.

> A stray YubiKey touch no longer submits its one-time password as a chat message, and large encoded message parts no longer render as raw text.

> The Add button in Domains settings links to the correct Vercel project.

> Organizations no longer need to set a spend limit for chats to work.

> Provider text streams in steady small deltas instead of arriving in uneven bursts.

> Demo links accept a loadingBackground parameter to set the background shown while the generated app loads.

> Personal upgrades default to Premium.

Source: https://v0.app/changelog#2026-07-21
