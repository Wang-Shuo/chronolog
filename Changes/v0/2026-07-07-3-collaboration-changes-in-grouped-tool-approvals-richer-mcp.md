## Changes in this digest

> v0's deploy button and GitHub import respect your team's Vercel deployment policies, hiding disallowed repositories and blocking production deploys your team forbids.

> Design Systems: set a team default (including Design Systems 2.0 skills and built-in examples) and choose team or personal scope when saving a design system from the save card.

> Auto-push for team-owned chats no longer fails silently, so edits reliably reach the GitHub working branch.
