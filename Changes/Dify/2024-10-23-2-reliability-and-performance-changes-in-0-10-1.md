## Changes in this digest

> **HTTP Node Improvements**: Enhanced JSON handling and simplified request management to boost the stability and security of the HTTP Node by @laipz8200 in [#9616](https://github.com/langgenius/dify/pull/9616), and fixed the handling of empty and string data inputs for consistent performance by @laipz8200 in [#9579](https://github.com/langgenius/dify/pull/9579).

> **Improved Iteration Handling**: Made iterators more robust by gracefully handling empty scenarios, as addressed by @laipz8200 in [#9565](https://github.com/langgenius/dify/pull/9565).
