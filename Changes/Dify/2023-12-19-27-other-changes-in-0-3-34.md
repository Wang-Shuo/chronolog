# 27 other changes in 0.3.34

**Dify** · 2023-12-19 · Other changes · Digest · [Official source](https://github.com/langgenius/dify/releases/tag/0.3.34) · from [[Releases/Dify/dify-2023-12-19-0-3-34-github-134420185-925cc49c|v0.3.34]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Annotation Reply, see details: [Link](https://docs.dify.ai/advanced/annotation-reply)

> Dify Knowledge supports `unstructured.io` as the file extraction solution.

> SaaS services now support replacing the logo of WebApp after subscribing.

> **Annotation Reply**

> The annotation function can support direct replies to related questions, so we need to assign values to previously unstored questions for the table ` message_annotations`.

> **Unstructured.io Support**

> Due to the support of this feature, we have added four new formats of text parsing( msg , eml, ppt, pptx ) and optimized two text parsing formats (text, markdown) in our [SAAS erviroment](https://dify.ai/).

> **For localhost you need to do below actions to support unstructured.io**

> `docker pull` from unstructured's image repository.

> Once pulled, you can launch the container

> In our docker-compose.yaml, add two new environment variables for the `api` and `worker` services.

> Restart the Dify‘s services
