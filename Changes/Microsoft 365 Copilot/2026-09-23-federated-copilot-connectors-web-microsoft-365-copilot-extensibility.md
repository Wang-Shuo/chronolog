# Federated Copilot Connectors [Web] (Microsoft 365 Copilot extensibility)

**Microsoft 365 Copilot** · 2026-09-23 · [[Themes/apps-integrations|Apps and Integrations]] · Launch · [Official source](https://learn.microsoft.com/en-us/microsoft-365/copilot/release-notes#september-23-2026) · from [[Releases/Microsoft 365 Copilot/microsoft-365-copilot-2026-09-23-2026-09-23-6719e501|Microsoft 365 Copilot updates — 2026-09-23]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> Microsoft is announcing the General Availability (GA) of federated Copilot connectors for Microsoft 365 Copilot. Federated Copilot connectors enable users to securely connect Copilot to popular third-party sources and retrieve data in real time using the Model Context Protocol (MCP). These connectors do not store or index customer data in Microsoft services; access occurs in real time using the user’s identity, while administrators retain full governance and control through the Microsoft 365 admin center. With GA, federated Copilot connectors will be supported in Researcher, Microsoft 365 Chat, and when editing with Copilot in Excel, enabling users to bring external data directly into their workflows.
>
> Source: https://learn.microsoft.com/en-us/microsoft-365/copilot/release-notes#september-23-2026
