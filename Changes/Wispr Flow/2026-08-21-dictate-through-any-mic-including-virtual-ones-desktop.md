# Dictate Through Any Mic, Including Virtual Ones (Desktop)

**Wispr Flow** · 2026-08-21 · [[Themes/mobile-desktop|Mobile and Desktop]] · Launch · [Official source](https://wisprflow.ai/whats-new#august-21-2026) · from [[Releases/Wispr Flow/wispr-flow-2026-08-21-2026-08-21-07917b7e|Wispr Flow updates — 2026-08-21]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> Flow now lets you pick virtual and routing audio devices, like Krisp, NVIDIA Broadcast, BlackHole, or VDI redirects, as your dictation mic. If you run your voice through a noise-suppression tool or work in a virtual desktop session, you can finally point Flow at exactly the mic you want.
>
> Virtual inputs live behind a "Show other devices" expander, so nothing changes if you don't use them, and Flow won't auto-select a loopback device on you. Automatic mic selection stays safely on your real, physical microphones.
>
> Find it: Settings > Microphone, or the mic switcher on the Flow bar.
>
> Help Center: Using Wispr Flow Discreetly (Microphone Guide)
>
> Source: https://wisprflow.ai/whats-new#august-21-2026
