# Shortcuts & Controls (Desktop)

**Wispr Flow** · 2026-08-21 · [[Themes/mobile-desktop|Mobile and Desktop]] · Launch · [Official source](https://wisprflow.ai/whats-new#august-21-2026) · from [[Releases/Wispr Flow/wispr-flow-2026-08-21-2026-08-21-07917b7e|Wispr Flow updates — 2026-08-21]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> A clear "Done" button in Shortcuts: The Shortcuts dialog now has a primary Done button, so you always know when you're finished. Your shortcuts still save automatically the moment you set them, Done just closes the dialog.
>
> Hands-free made simpler: Double-tapping your Push-to-talk hotkey has always toggled Hands-free mode, and now the Shortcuts editor shows you a live hint built from your own keys so you don't have to guess. The dedicated Hands-free shortcut is also fully optional now: delete it and it stays gone.
>
> Help Center: Use Flow hands-free
>
> Source: https://wisprflow.ai/whats-new#august-21-2026
