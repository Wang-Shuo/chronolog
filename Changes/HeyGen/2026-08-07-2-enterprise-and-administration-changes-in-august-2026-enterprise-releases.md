**HeyGen** · 2026-08-07 · [[Themes/enterprise-admin|Enterprise and Administration]] · Digest · [Official source](https://heygen.noticeable.news/publications/august-2026-enterprise-releases) · from [[Releases/HeyGen/heygen-2026-08-07-https-heygen-noticeable-news-publications-august-2026-enterprise-ee1eb69b|August 2026 Enterprise Releases]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> We've enhanced sub-workspace resource management by allowing parent workspace admins to reclaim allocated resources from sub-workspaces back to the parent workspace.

> Parent workspace admins can allocate resources to sub-workspaces as before. If a sub-workspace no longer needs its allocated resources, admins can now return the unused allocation back to the parent workspace and reassign it where it's needed.
