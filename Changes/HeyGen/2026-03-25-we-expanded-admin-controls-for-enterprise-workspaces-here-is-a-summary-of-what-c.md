# We expanded admin controls for Enterprise workspaces

**HeyGen** · 2026-03-25 · [[Themes/enterprise-admin|Enterprise and Administration]] · [Official source](https://heygen.noticeable.news/publications/new-admin-controls-for-enterprise) · from [[Releases/HeyGen/heygen-2026-03-25-https-heygen-noticeable-news-publications-new-admin-controls-for-9d316a4b|New admin controls for Enterprise]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> We expanded admin controls for Enterprise workspaces. Here is a summary of what changed:
>
> Access and invitations: Admins can now control who creates public invite links, restrict sub-workspace access to admins only, and set default sharing permissions for new videos, assets, and projects.
>
> Feature settings: Admins can restrict custom avatar creation, AI-generated avatar creation, public avatar availability, and Brand Kit creation.
>
> All changes apply going forward and will not affect existing access, invite links, downloads, or shares. Available on the Enterprise plan.
>
> Source: https://heygen.noticeable.news/publications/new-admin-controls-for-enterprise
