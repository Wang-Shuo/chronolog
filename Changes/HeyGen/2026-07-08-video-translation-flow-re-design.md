# Video Translation Flow Re-Design

**HeyGen** · 2026-07-08 · [[Themes/multimodal|Multimodal Input]] · Launch · [Official source](https://heygen.noticeable.news/publications/july-2026-enterprise-releases) · from [[Releases/HeyGen/heygen-2026-07-08-https-heygen-noticeable-news-publications-july-2026-enterprise-r-27a9b7ed|July 2026 Enterprise Releases]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> The Video Translation page has a refreshed design with a number of layout changes. Notable ones below:
>
> New entry point - Translate is no longer in the left nav bar. It now lives under Apps → Translate Videos in All Apps
>
> Cleaner engine selector - the old Audio-only / Speed / Precision toggle has been simplified into a single model selector. Audio-only remains its own option; Speed and Precision are both lip-sync modes, so pick whichever you were using before
>
> Advanced settings are now a modal - previously a toggle on the main page, advanced settings (dynamic duration, collections, remove background sound, source transcript, brand cluster input) now open in a dedicated modal via a button at the bottom of the settings panel
>
> Local voice file has moved - if you upload your own voice file, it now appears in its own spot and replaces the output language selector (since language selection is no longer relevant when using a local voice)
>
> Video trim is on the thumbnail - the trim control has moved to sit directly on the video thumbnail rather than as a separate element
>
> Source: https://heygen.noticeable.news/publications/july-2026-enterprise-releases
