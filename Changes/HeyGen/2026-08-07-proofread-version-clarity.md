# Proofread version clarity

**HeyGen** · 2026-08-07 · [[Themes/editor-experience|Editor Experience]] · Launch · [Official source](https://heygen.noticeable.news/publications/august-2026-enterprise-releases) · from [[Releases/HeyGen/heygen-2026-08-07-https-heygen-noticeable-news-publications-august-2026-enterprise-ee1eb69b|August 2026 Enterprise Releases]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> What it is : Full version tracking for Proofread. Version history gets one-click restore and clear labels (e.g. "Version 3 (Auto-Saved)", "Restored from Version 2"), and versions now surface throughout the editor: a save indicator, a version badge on the generated result, and stale results that stay viewable instead of being locked.
>
> What users experience : As they edit, the header shows exactly what's saved — "Saved as version X on \<date/time>" next to the save icon — and any earlier version can be reviewed and restored with one click, with the pre-restore state kept as its own version so nothing is ever lost. The Result tab shows a "Version X" badge telling them which saved version their current video was generated from; if the script has changed since, a "Stale" badge appears (with a tooltip suggesting regeneration) but the old result stays viewable for comparison instead of being disabled.
>
> Source: https://heygen.noticeable.news/publications/august-2026-enterprise-releases
