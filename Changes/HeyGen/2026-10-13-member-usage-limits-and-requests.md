# Member usage limits and requests

**HeyGen** · 2026-10-13 · [[Themes/enterprise-admin|Enterprise and Administration]] · Policy · [Official source](https://heygen.noticeable.news/publications/october-2026-enterprise-web-releases) · from [[Releases/HeyGen/heygen-2026-10-13-https-heygen-noticeable-news-publications-october-2026-enterpris-4784ae14|October 2026 Enterprise Web Releases]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> Admins can now set how much each member can use, and members can ask for more without leaving HeyGen.
>
> For admins : a new Settings → Member Requests page has two parts. Open requests lists every request with the member's note, so you can Raise limit or Decline in one click. Member limits sets one limit for every active member, and shows how much each person has used this period. You get a notification when someone sends a request.
>
> For members: Usage & History shows your limit and how much you've used. Select Request more , pick an amount and add a short note. If a video would go over your limit, the same request opens automatically. When your admin approves or declines, you get an in-app notification.
>
> For admins (add to the admin paragraph above): When a member asks for more, you get an in-app notification. Open it to review the request in Member Requests , then approve or decline in one click.
>
> Source: https://heygen.noticeable.news/publications/october-2026-enterprise-web-releases
