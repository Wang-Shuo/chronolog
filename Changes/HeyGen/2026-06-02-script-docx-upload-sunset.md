# Script .docx upload SUNSET

**HeyGen** · 2026-06-02 · [[Themes/enterprise-admin|Enterprise and Administration]] · Policy · [Official source](https://heygen.noticeable.news/publications/june-2026-enterprise-releases) · from [[Releases/HeyGen/heygen-2026-06-02-https-heygen-noticeable-news-publications-june-2026-enterprise-r-c322a0ce|June 2026 Enterprise Releases]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> Direct .docx script upload is being retired. Starting June 1, 2026, uploading a .docx script will return a clear sunset message with a documented migration path: paste your script content directly, or upload it as a .txt or .md file instead. This now applies to all workspaces, including Enterprise, which were previously on the legacy upload path. Scripts already imported are unaffected.
>
> Source: https://heygen.noticeable.news/publications/june-2026-enterprise-releases
