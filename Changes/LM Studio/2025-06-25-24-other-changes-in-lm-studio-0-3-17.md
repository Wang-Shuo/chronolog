# 24 other changes in LM Studio 0.3.17

**LM Studio** · 2025-06-25 · Other changes · Digest · [Official source](https://lmstudio.ai/changelog/lmstudio/lmstudio-v0.3.17) · from [[Releases/LM Studio/lm-studio-2025-06-25-0-3-17-d6975d83|LM Studio 0.3.17]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Added a Chat Appearance setting to display message generation stats on last message only, in tooltips only, or on all applicable messages

> Token count now includes system prompt & tool definitions

> Be mindful: LLMs may generate untrusted URLs. Always verify links before clicking.

> When download panel is open in a new window, add an option to pin it on top of other windows (right click the body)

> Adds the following languages, thanks to our community localizers!

> Malayalam (ml) [@prasanthc41m](https://github.com/prasanthc41m)

> Thai (th) [@gnoparus](https://github.com/gnoparus)

> Bosnian (bs) [@0haris0](https://github.com/0haris0)

> Bulgarian (bg) [@DenisZekiria](https://github.com/DenisZekiria)

> Hungarian (hu) [@Mekemoka](https://github.com/Mekemoka)

> Bengali (bn) [@AbiruzzamanMolla](https://github.com/AbiruzzamanMolla)

> Catalan (ca) [@Gopro3010](https://github.com/Gopro3010)

> Finnish (fi) [@reinew](https://github.com/reinew)

> Greek (gr) [@ilikecatgirls](https://github.com/ilikecatgirls)

> Romanian (ro) [@alexandrughinea](https://github.com/alexandrughinea)

> Swedish (sv) [@reinew](https://github.com/reinew)

> Added thinking block preview 'vignette', with an option to disable in chat appearance settings

> [Windows][ROCm] Strix Halo (AMD Ryzen AI PRO 300 series) support

> [Windows] Add CPU name to hardware page

> To reduce new user confusion, the "change role" and "insert" buttons will now be hidden by default on new installs. You can right click the send button to toggle them on or off.

> Improved full-sized DeepSeek-R1 tool calling reliability

> Button to pop out downloads panel to a new window.

> New Theme: **Solarized Dark**.

> Set it in Settings > General or by pressing `[⌘/Ctrl K + T]`

Source: https://lmstudio.ai/changelog/lmstudio/lmstudio-v0.3.17
