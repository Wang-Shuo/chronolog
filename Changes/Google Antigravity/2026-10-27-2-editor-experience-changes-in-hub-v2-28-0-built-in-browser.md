# 2 Editor Experience changes in HUB v2.28.0 — Built-in browser…

**Google Antigravity** · 2026-10-27 · [[Themes/editor-experience|Editor Experience]] · Digest · [Official source](https://antigravity.google/releases?tab=hub&version=2.28.0) · from [[Releases/Google Antigravity/google-antigravity-2026-10-27-rel-hub-2-28-0-7ce90829|HUB v2.28.0 — Built-in browser and attachments of any file type]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Antigravity now has a built-in browser. Web pages open in a browser tab in the side panel, and the panel widens when a page opens so sites are less likely to switch to their narrow mobile layout.

> Diffs now highlight the exact words and characters that changed within a line, including in edits that span several lines, and added text is easier to see in dark mode.

Source: https://antigravity.google/releases?tab=hub&version=2.28.0
