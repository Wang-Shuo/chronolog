# 3 Interface Experience changes in HUB v2.15.0 — Custom agent controls…

**Google Antigravity** · 2026-09-18 · [[Themes/interface-experience|Interface Experience]] · Digest · [Official source](https://antigravity.google/releases?tab=hub&version=2.15.0) · from [[Releases/Google Antigravity/google-antigravity-2026-09-18-rel-hub-2-15-0-48b37e09|HUB v2.15.0 — Custom agent controls and keyboard navigation]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> The project picker above the message box now reads "No Project" when you are working outside of a project, instead of "New Conversation".

> Improved performance when switching between conversations in the sidebar.

> The close-window shortcut now closes the dialog on top, such as settings, instead of the conversation behind it, and Escape inside an open menu now closes just the menu rather than the whole dialog.

Source: https://antigravity.google/releases?tab=hub&version=2.15.0
