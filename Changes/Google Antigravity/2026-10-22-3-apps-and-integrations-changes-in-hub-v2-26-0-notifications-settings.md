# 3 Apps and Integrations changes in HUB v2.26.0 — Notifications settings…

**Google Antigravity** · 2026-10-22 · [[Themes/apps-integrations|Apps and Integrations]] · Digest · [Official source](https://antigravity.google/releases?tab=hub&version=2.26.0) · from [[Releases/Google Antigravity/google-antigravity-2026-10-22-rel-hub-2-26-0-335d6d26|HUB v2.26.0 — Notifications settings, docked question prompts, and conversation palette filters]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Installed MCP servers on a plugin's page now include a Configure button so you can fill in or update their declared variables without turning the plugin off and on again.

> When installing a plugin that conflicts with an existing one, the conflict dialog now shows preview cards for both plugins and offers a single Replace action.

> Suggested prompts on a plugin's page now display the plugin's logo and automatically install or enable the plugin when selected.

Source: https://antigravity.google/releases?tab=hub&version=2.26.0
