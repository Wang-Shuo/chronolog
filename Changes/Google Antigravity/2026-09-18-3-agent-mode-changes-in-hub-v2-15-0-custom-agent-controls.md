# 3 Agent Mode changes in HUB v2.15.0 — Custom agent controls…

**Google Antigravity** · 2026-09-18 · [[Themes/agent-mode|Agent Mode]] · Digest · [Official source](https://antigravity.google/releases?tab=hub&version=2.15.0) · from [[Releases/Google Antigravity/google-antigravity-2026-09-18-rel-hub-2-15-0-48b37e09|HUB v2.15.0 — Custom agent controls and keyboard navigation]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Custom agents can now switch off the default prompt sections and default tools and add back only the tools they need.

> The custom agent you pick in the message box is remembered after a reload, and resets to the main agent if that agent is deleted or turned off.

> The agent now reports a clear error when it tries to read a binary file it cannot display, instead of returning unreadable content.

Source: https://antigravity.google/releases?tab=hub&version=2.15.0
