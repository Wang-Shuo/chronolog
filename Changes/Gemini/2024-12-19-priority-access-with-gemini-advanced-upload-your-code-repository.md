# Priority access with Gemini Advanced: Upload your code repository

**Gemini** · 2024-12-19 · [[Themes/context-window|Context Window]] · Launch · [Official source](https://gemini.google/us/release-notes/?hl=en) · from [[Releases/Gemini/gemini-2024-12-19-2024-12-19-a8e54125|Gemini updates — 2024-12-19]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> What: In September, we made it possible for you to upload multiple code files to get help understanding, modifying, or debugging your code within Gemini Advanced. Today, we're excited to announce yet another upgrade: you can now upload your code repository (up to 1 folder per conversation, with a maximum of 1,000 files and a maximum folder size of 100MB, can be uploaded at a time) directly from your device in one action. This means you'll get the same comprehensive code assistance, with the added benefit of Gemini Advanced understanding the full context of your project. The experience is available with Gemini Advanced as part of the Google One AI Premium Plan.
>
> Why: This improvement enables you to streamline your workflow and leverage the full power of Gemini Advanced's 1M token context window for more comprehensive and contextually relevant code analysis and debugging.
>
> Source: https://gemini.google/us/release-notes/?hl=en
