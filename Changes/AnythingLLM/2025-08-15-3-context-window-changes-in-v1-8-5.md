# 3 Context Window changes in v1.8.5

**AnythingLLM** · 2025-08-15 · [[Themes/context-window|Context Window]] · Digest · [Official source](https://github.com/Mintplex-Labs/anything-llm/releases/tag/v1.8.5) · from [[Releases/AnythingLLM/anythingllm-2025-08-15-v1-8-5-github-240123881-3d302e39|AnythingLLM v1.8.5 🎉  Mobile support + RAG improvements]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> When we first built AnythingLLM, the average context window was 4K - hardly anything to fit a full document. So we decided to always be RAG first. This has its drawbacks since RAG is _semantically_ dependent on asking questions about content in the document. This leads to poor results for "Summarize this document," only to be told by the document, "what are you talking about".

> \<img width="1394" height="906" alt="context-warning" src="https://github.com/user-attachments/assets/c28c24d9-a696-4ff6-8d77-7ca708592071" />

> You can also easily manage and see your context window to remove files that are no longer relevant, but retain the conversation history.
