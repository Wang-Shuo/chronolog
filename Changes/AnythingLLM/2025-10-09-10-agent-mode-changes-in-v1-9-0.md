# 10 Agent Mode changes in v1.9.0

**AnythingLLM** · 2025-10-09 · [[Themes/agent-mode|Agent Mode]] · Digest · [Official source](https://github.com/Mintplex-Labs/anything-llm/releases/tag/v1.9.0) · from [[Releases/AnythingLLM/anythingllm-2025-10-09-v1-9-0-github-253490461-30425365|AnythingLLM v1.9.0]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> When anythingllm first launched, the word "agent" was not in the vocabulary of the LLM world. Agents are quickly becoming the standard for building AI applications and also the core experience for interacting with LLMs.

> Agents can now real-time download and ingest files from the web (eg: link to PDF, excel, csv). Anything you would use a document can be read in real time by the agent from the web.

> Agent real-time API calling without agent flows

> Agent image understanding

> Ephemerally scrape/download any web-resource via agent or uploader

> update save file agent text by @timothycarambat in https://github.com/Mintplex-Labs/anything-llm/pull/4389

> Add User-Agent header on the requests sent by Generic OpenAI providers. by @angelplusultra in https://github.com/Mintplex-Labs/anything-llm/pull/4393

> Enable real-time agent tool call streaming for all providers by @timothycarambat in https://github.com/Mintplex-Labs/anything-llm/pull/4279

> Migrate OpenAI Agent to use ResponsesAPI by @timothycarambat in https://github.com/Mintplex-Labs/anything-llm/pull/4467

> Microsoft Foundry Local LLM provider & agent provider by @shatfield4 in https://github.com/Mintplex-Labs/anything-llm/pull/4435
