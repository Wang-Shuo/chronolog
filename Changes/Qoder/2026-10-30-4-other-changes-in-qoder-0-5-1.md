# 4 other changes in Qoder 0.5.1

**Qoder** · 2026-10-30 · Other changes · Digest · [Official source](https://changelog.qoder.com/app#0.5.1) · from [[Releases/Qoder/qoder-2026-10-30-0-5-1-5127d714|Qoder 0.5.1]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> **Projects and discussions**: Projects can now be associated with multiple repositories. Search organization members in discussions, with direct additions governed by each member's preferences. Improved mentions, message reactions, and key-message actions.

> **Worktrees**: Preserve required project configuration when creating worktrees. When carrying over local changes, keep them unstaged where possible for continued review.

> **Qoder Helper and feedback**: Qoder Helper can inspect relevant log excerpts when explicitly requested and provides clearer guidance for settings changes. Feedback can also be submitted from the recovery screen after a startup failure.

> **HarmonyOS foldables**: Added upper-and-lower workspace panels for supported foldables in a partially folded horizontal posture, with layout restoration when unfolding and folding again.

Source: https://changelog.qoder.com/app#0.5.1
