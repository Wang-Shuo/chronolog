<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> **Skill evolution suggestions**: After a conversation finishes, Qoder can suggest creating or updating Skills based on reusable experience. Accept a suggestion to open a separate conversation, then confirm the plan before any changes are made. Manage this feature in Settings → General.

> **Workspace indexing**: Choose whether to build an index when creating a local workspace, with access to information about how index data is handled.
