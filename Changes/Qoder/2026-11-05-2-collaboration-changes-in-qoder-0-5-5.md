# 2 Collaboration changes in Qoder 0.5.5

**Qoder** · 2026-11-05 · [[Themes/collaboration|Collaboration]] · Digest · [Official source](https://changelog.qoder.com/app#0.5.5) · from [[Releases/Qoder/qoder-2026-11-05-0-5-5-119bdeb6|Qoder 0.5.5]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> **HarmonyOS tap-to-share**: On supported HarmonyOS devices, transfer images and PDFs from a phone into the current local task or a new task draft, or send local files to the phone with tap-to-share.

> **Agent Teams**: Select members from the current device, the cloud, and other devices on the same account, enabling collaboration when required. Connected-device workspaces can use their associated teams. Leaders on other devices can participate in discussions; local tasks remain subject to the execution restrictions of the leader’s device.

Source: https://changelog.qoder.com/app#0.5.5
