# 2 Collaboration changes in Qoder 0.5.1

**Qoder** · 2026-10-30 · [[Themes/collaboration|Collaboration]] · Digest · [Official source](https://changelog.qoder.com/app#0.5.1) · from [[Releases/Qoder/qoder-2026-10-30-0-5-1-5127d714|Qoder 0.5.1]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> **Cross-device collaboration**: Use @ in a local task to reference a connected device's workspace and delegate tasks. View Agents on other devices, cached conversation history, and device update status. Remote models and browser sessions are managed per execution device.

> **Needs Me**: Review items that need a response, results that need your attention, and activity from tasks and available collaboration features in one inbox. Filter and search items, handle approvals, and review your history.

Source: https://changelog.qoder.com/app#0.5.1
