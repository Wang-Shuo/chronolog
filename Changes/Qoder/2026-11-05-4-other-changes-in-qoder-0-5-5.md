# 4 other changes in Qoder 0.5.5

**Qoder** · 2026-11-05 · Other changes · Digest · [Official source](https://changelog.qoder.com/app#0.5.5) · from [[Releases/Qoder/qoder-2026-11-05-0-5-5-119bdeb6|Qoder 0.5.5]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> **Local browser access for remote tasks**: Supported remote sessions can use an authorized connection to operate the controlling device’s Qoder built-in browser alongside remote execution.

> **Plan and Goal**: After reviewing a plan, choose Goal execution in supported tasks to continue working toward an explicit outcome.

> **Device connections**: Sets initial pairing permissions according to the account relationship and improves address validation and local-network diagnostics. Explicitly confirm before stopping remote work for an update, and reference cached conversations from offline devices in local tasks.

> **Diagnostics and feedback**: Improves Qoder Helper’s Hook timing diagnostics and troubleshooting for remote devices.

Source: https://changelog.qoder.com/app#0.5.5
