# 3 Apps and Integrations changes in Qoder 0.4.9

**Qoder** · 2026-10-22 · [[Themes/apps-integrations|Apps and Integrations]] · Digest · [Official source](https://changelog.qoder.com/app#0.4.9) · from [[Releases/Qoder/qoder-2026-10-22-0-4-9-ce83161d|Qoder 0.4.9]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> **WeCom integration**: After configuring the required plugin, chat with Qoder, start tasks, and receive replies in WeCom, keeping work conversations and task execution connected.

> **Qoder Helper**: Use local conversations to learn how to use Qoder, adjust supported app settings, manage Agents and connectors, and install extensions when requested.

> **Extension discovery**: The extension marketplace now includes New & noteworthy recommendations and Partner badges, making it easier to discover new extensions and identify capabilities from partners.

Source: https://changelog.qoder.com/app#0.4.9
