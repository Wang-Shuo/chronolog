# 3 other changes in Qoder 0.4.9

**Qoder** · 2026-10-22 · Other changes · Digest · [Official source](https://changelog.qoder.com/app#0.4.9) · from [[Releases/Qoder/qoder-2026-10-22-0-4-9-ce83161d|Qoder 0.4.9]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> **Open Qoder from a file**: Use your system's Open with option to open supported local files in Qoder. A new task draft includes the files as attachments, ready for you to add instructions and start working.

> **Recoverable side tasks (Experimental)**: Enable this under Settings → Experiments to retain newly created side tasks after closing their tabs or quitting Qoder, and continue them from the task monitor.

> **Network proxy**: Manual proxy configuration now supports bypass addresses, allowing direct connections to specified domains or IP addresses. Restart the app after saving for changes to take effect.

Source: https://changelog.qoder.com/app#0.4.9
