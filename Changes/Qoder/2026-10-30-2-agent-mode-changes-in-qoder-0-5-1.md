# 2 Agent Mode changes in Qoder 0.5.1

**Qoder** · 2026-10-30 · [[Themes/agent-mode|Agent Mode]] · Digest · [Official source](https://changelog.qoder.com/app#0.5.1) · from [[Releases/Qoder/qoder-2026-10-30-0-5-1-5127d714|Qoder 0.5.1]]

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> **Cloud Agent management**: Create, edit, and manage cloud Agents, configure their models, instructions, and resources, and manage Skills, MCP connections, and memory that can be synced to the cloud. Availability depends on account permissions and cloud service configuration.

> **Agent Teams**: Added a software development expert team template. Create a team of specialized research, development, testing, and review Agents with one click to collaborate on development tasks.
