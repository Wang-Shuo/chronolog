# 3 Apps and Integrations changes in Qoder 0.5.1

**Qoder** · 2026-10-30 · [[Themes/apps-integrations|Apps and Integrations]] · Digest · [Official source](https://changelog.qoder.com/app#0.5.1) · from [[Releases/Qoder/qoder-2026-10-30-0-5-1-5127d714|Qoder 0.5.1]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> **Codex data import**: Detect and selectively import Codex conversations, compatible local automations, memory, and supported Skill, MCP, and plugin configurations. Imported plugins start disabled; application-specific capabilities are excluded.

> **Excel plugin**: Added an Excel plugin to create, edit, and analyze spreadsheets through conversation, organize data, calculate formulas, and adjust formatting. Preview, manually edit, and save spreadsheets directly in Qoder.

> **Remote Control**: Added synchronization for task archiving and restoration, improved the display of plan approval details, and increased the transfer limit for individual artifact files to 100 MiB.

Source: https://changelog.qoder.com/app#0.5.1
