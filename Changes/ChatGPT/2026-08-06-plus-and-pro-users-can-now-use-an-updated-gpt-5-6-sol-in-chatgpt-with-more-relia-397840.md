# Updates to GPT‑5.6 in ChatGPT

**ChatGPT** · 2026-08-06 · [[Themes/model-support|Model Support]] · [Official source](https://help.openai.com/en/articles/6825453-chatgpt-release-notes) · from [[Releases/ChatGPT/chatgpt-2026-08-06-updates-to-gpt-5-6-in-chatgpt-29572055|Updates to GPT‑5.6 in ChatGPT]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> Plus and Pro users can now use an updated GPT‑5.6 Sol in ChatGPT with more reliable facts, more focused answers, and a new slider to choose how much thought ChatGPT puts into a response.
>
> GPT‑5.6 Luna will become the default model for Free and Go users this week. Starting next week, they’ll also have unlimited text chats and access to a new Think button for harder questions (subject to abuse guardrails). Limits will still apply for file uploads, images and other tools.
>
> This release applies to the chat experience in ChatGPT. Work and Codex are not changing as part of this release.
>
> Source: https://help.openai.com/en/articles/6825453-chatgpt-release-notes
