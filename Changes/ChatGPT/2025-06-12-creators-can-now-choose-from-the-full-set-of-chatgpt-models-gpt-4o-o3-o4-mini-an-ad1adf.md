# Creators can now choose from the full set of ChatGPT models…

**ChatGPT** · 2025-06-12 · [[Themes/model-support|Model Support]] · [Official source](https://help.openai.com/en/articles/6825453-chatgpt-release-notes#expanded-model-support-for-custom-gpts) · from [[Releases/ChatGPT/chatgpt-2025-06-12-expanded-model-support-for-custom-gpts-55f4555f|Expanded Model Support for Custom GPTs]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> Creators can now choose from the full set of ChatGPT models (GPT-4o, o3, o4-mini and more) when building Custom GPTs—making it easier to fine-tune performance for different tasks, industries, and workflows. Creators can also set a recommended model to guide users.Key details:
>
> GPTs without Custom Actions can use the model picker to select from all models available to the user.
>
> GPTs with Custom Actions currently support GPT-4o and 4.1
>
> Source: https://help.openai.com/en/articles/6825453-chatgpt-release-notes#expanded-model-support-for-custom-gpts
