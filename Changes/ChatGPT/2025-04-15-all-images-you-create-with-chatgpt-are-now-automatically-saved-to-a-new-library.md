# All images you create with ChatGPT are now automatically saved to a new Library…

<!-- chronolog:begin region="description" -->
ChatGPT — ChatGPT Image Library: All images you create with ChatGPT are now automatically saved to a new Library in the sidebar, giving you one place to browse, revisit, and reuse your work without digging through past conversations. The Library is rolling out today on Web, iOS, and Android for Free, Plus, and Pro users (Enterprise / Edu support coming soon). For now, it displays images generated with 4o Image Generation while we backfill older creations, and you can remove an image by deleting the conversation where it was made.
<!-- chronolog:end -->
