**Claude Code** · 2026-05-21 · [[Themes/reliability-performance|Reliability and Performance]] · Digest · [Official source](https://github.com/anthropics/claude-code/releases/tag/v2.1.147) · from [[Releases/Claude Code/claude-code-2026-05-21-v2-1-147-github-327133263-73928fcd|v2.1.147]]

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Pinned background sessions (`Ctrl+T` in `claude agents`) now stay alive when idle, are restarted in place to apply Claude Code updates, and are shed under memory pressure only after non-pinned sessions

> Improved auto-updater: retries transient network failures, reports specific error categories and OS error codes on failure, and shows the current version when an update fails

> Improved diff rendering performance for large file edits
