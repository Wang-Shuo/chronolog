## Changes in this digest

> We're serving new features from the kitchen as they're ready. Today: a high protein entrée and a couple desserts.

> Nested database filters 🔬 Create more specific database views with powerful filters. Combine AND and OR logic and nest filter groups up to three layers deep. Here are a few filters you can create now that weren't possible before:

> Notes where (Type = Standup OR Weekly Sync) AND were created within a week

> Projects where Effort = Low AND (Impact = High OR Medium) Learn how to use (nested filters) with this guide →

> ⚠️ Use :warning to call attention to an important note

> 🔥 Use :fire to denote an urgent task

> ⭐ Use a :star (or five!) to give something a rating Learn all the shortcuts here →

> New database entries now inherit all the multi-select tags when an AND filter is applied to the database view. Before, only one multi-select tag was inherited, so new entries were immediately filtered out.
