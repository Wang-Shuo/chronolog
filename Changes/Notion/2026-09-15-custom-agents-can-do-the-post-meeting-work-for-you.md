<!-- chronolog:begin region="evidence" -->
> Every call ends with the same chores: Write the recap, file the action items, ping the people who weren’t there. Now Custom Agents can handle post-meeting work automatically.
>
> Choose which meetings matter, then let a Custom Agent pick up the work as soon as each summary is ready. It gets the transcript and summary, so it can write the status update, file the action items, or send customer feedback to the right database. Available on Business and Enterprise plans. Learn more →
