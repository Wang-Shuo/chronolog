# 2 other changes in June 4, 2020

**Notion** · 2020-06-04 · Other changes · Digest · [Official source](https://www.notion.com/releases/2020-06-04) · from [[Releases/Notion/notion-2020-06-04-https-www-notion-com-releases-2020-06-04-25932080|June 4, 2020]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> The No Date dropdown in Calendar View now respects any filters applied to the database view

> Clicking the + New button now opens preview view if there are conflicting filters applied in the database view (e.g. if you're trying to add a new entry in the Completed column of a Board View where a filter Status = In Progress is enabled)
