**Notion** · 2026-09-15 · [[Themes/agent-mode|Agent Mode]] · Launch · [Official source](https://www.notion.com/releases/2026-09-15) · from [[Releases/Notion/notion-2026-09-15-https-www-notion-com-releases-2026-09-15-bb814e7c|Notion 3.7: Agent skills for your whole team]]

<!-- chronolog:begin region="evidence" -->
> Big workflows are rarely one job. Now a Custom Agent can call other Custom Agents as sub-agents , each with its own instructions, context, access, and model. Learn more →
>
> A Mobile App PM agent can send bug reports to a triage agent and metrics questions to a reporting agent, then bring the answers back into one Slack update. The primary agent decides when to delegate and uses each response to finish the original work. Remote runs its IT help desk on five agents this way and saves $500k a year.
