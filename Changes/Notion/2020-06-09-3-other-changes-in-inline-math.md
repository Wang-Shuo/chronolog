# 3 other changes in Inline math 🧮

**Notion** · 2020-06-09 · Other changes · Digest · [Official source](https://www.notion.com/releases/2020-06-09) · from [[Releases/Notion/notion-2020-06-09-https-www-notion-com-releases-2020-06-09-270e31ab|Inline math 🧮]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Insert math equations inline ➕➖✖️➗ Display beautifully formatted math equations inline next to your text. Just surround your KaTeX formula with $$ on either side to quickly turn it into an equation. (e.g. $$e=mc^2$$ becomes $e=mc^2$) This has been one of our top feature requests for a while now! We hope this makes Notion an even better place for notes, homework, technical documentation, or any project that needs a fraction or equation. Learn how to use inline math and see FAQs →

> Newly created database views now use the view type as the default name (e.g. the default name for a new board view is now Board View instead of Untitled View )

> Improved formatting for Number property values formatted as currency, such as Yuan and Ruble

Source: https://www.notion.com/releases/2020-06-09
