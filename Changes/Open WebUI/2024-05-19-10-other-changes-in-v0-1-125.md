# 10 other changes in v0.1.125

**Open WebUI** · 2024-05-19 · Other changes · Digest · [Official source](https://github.com/open-webui/open-webui/releases/tag/v0.1.125) · from [[Releases/Open WebUI/open-webui-2024-05-19-v0-1-125-github-156427993-5af04c15|v0.1.125]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> **🔄 Updated UI**: Chat interface revamped with chat bubbles. Easily switch back to the old style via settings > interface > chat bubble UI.

> **🐍 Python Code Execution**: Execute Python code locally in the browser with libraries like 'requests', 'beautifulsoup4', 'numpy', 'pandas', 'seaborn', 'matplotlib', 'scikit-learn', 'scipy', 'regex'.

> **💾 Persistent Settings**: Settings now saved as config.json for convenience.

> **🩺 Health Check Endpoint**: Added for Docker deployment.

> **↕️ RTL Support**: Toggle chat direction via settings > interface > chat direction.

> **🌐 Language Updates**: Ukrainian, Turkish, Arabic, Chinese, Serbian, Vietnamese updated; Punjabi added.

> 👏 Massive thanks to our incredible contributors for their hard work and dedication to making this release possible:
