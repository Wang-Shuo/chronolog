# 5 other changes in v0.2.4

**Open WebUI** · 2024-06-04 · Other changes · Digest · [Official source](https://github.com/open-webui/open-webui/releases/tag/v0.2.4) · from [[Releases/Open WebUI/open-webui-2024-06-04-v0-2-4-github-158723630-a8af45db|v0.2.4]]

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> **👤 Improved Account Pending Page**: The account pending page now displays admin details by default to avoid confusion. You can disable this feature in the admin settings if needed.

> **🌐 HTTP Proxy Support**: We have enabled the use of the 'http_proxy' environment variable in OpenAI and Ollama API calls, making it easier to configure network settings.

> **🌍 Enhanced Translation**: Improvements have been made to translations.

> 👏 Massive thanks to our incredible contributors for their hard work and dedication to making this release possible:

> @aguvener, @cheahjs, @justinh-rahb, @mindspawn
