# Opening up the in-house search API

**DeepSeek API** · 2026-10-17 · [[Themes/search-browsing|Search and Browsing]] · Launch · [Official source](https://api-docs.deepseek.com/updates/#date-2026-10-17) · from [[Releases/DeepSeek API/deepseek-api-2026-10-17-2026-10-17-2905e67c|DeepSeek API updates — 2026-10-17]]

<!-- chronolog:begin region="evidence" -->
> DeepSeek's web and API search capabilities are powered by our in-house DeepSeek search engine, which reliably handles hundreds of millions of search requests from around the world every day. DeepSeek Search is an AI-native general-purpose search engine that indexes hundreds of billions of web pages, supports multilingual search, and returns highly relevant, authoritative, and timely results in real time. It filters SEO spam, GEO manipulation, and low-quality AIGC through strict detection mechanisms, ensuring authoritative and trustworthy information for users and LLMs. For usage details, see the Search & Fetch guide .
