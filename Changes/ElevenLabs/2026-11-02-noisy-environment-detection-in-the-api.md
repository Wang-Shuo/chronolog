# Noisy environment detection in the API

**ElevenLabs** · 2026-11-02 · [[Themes/voice|Voice and Audio]] · Launch · [Official source](https://elevenlabs.io/docs/changelog/2026/11/2) · from [[Releases/ElevenLabs/elevenlabs-2026-11-02-2026-11-02-7efe9660|ElevenLabs updates — 2026-11-02]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> **ElevenAgents** noisy environment detection can now be configured through the API and CLI. Set `conversation_config.turn.noisy_environment_detection` to `true` and the agent speaks `noisy_environment_message` once, without interruption, when it hears other people speaking in the caller's background, asking them to move somewhere quieter. Add a translated message for each additional language in `language_presets`. The setting is available for voice agents in Enterprise workspaces; see [Noisy environment detection](https://elevenlabs.io/docs/eleven-agents/customization/conversation-flow#noisy-environment-detection).
