# Workspaces

**ElevenLabs** · 2026-06-29 · [[Themes/model-support|Model Support]] · Launch · [Official source](https://elevenlabs.io/docs/changelog/2026/6/29) · from [[Releases/ElevenLabs/elevenlabs-2026-06-29-2026-06-29-7be10e9c|ElevenLabs updates — 2026-06-29]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> **Third-party API key disabling policy**: Added [Set workspace third-party disabling policy](https://elevenlabs.io/docs/api-reference/api-keys/set-third-party-disabling-policy) (`POST /v1/workspaces/api-keys/third-party-disabling`) for workspace-wide control over whether API key holders can self-disable keys via the third-party disable endpoint. Workspace API key create, patch and response models add optional `third_party_disable_allowed` (boolean).
>
> **Bearer auth connection updates**: [Update workspace auth connection](https://elevenlabs.io/docs/api-reference/workspace/auth-connections/update) request union adds `UpdateBearerAuthRequest` for bearer token credential updates.
>
> **Workspace permissions**: Permission enums add `conversation_privacy_manage` and `synthid_detector`. Workspace group models add optional `scim_group` (string).
>
> Source: https://elevenlabs.io/docs/changelog/2026/6/29
