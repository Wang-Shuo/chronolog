<!-- chronolog:begin region="evidence" -->
> [@elevenlabs/client@1.26.0](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Fclient%401.26.0), [@elevenlabs/react@1.16.0](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Freact%401.16.0), [@elevenlabs/react-native@1.2.28](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Freact-native%401.2.28) and [@elevenlabs/types@0.24.0](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Ftypes%400.24.0) - Added realtime Speech to Text transcript editing through `transcriptEdit`, the `edited_transcript` event and React's `onEditedTranscript` callback. React now forwards `filterBackgroundAudio` to realtime sessions. The client also exports `MessagePayload` and uses stable response IDs to prevent duplicate agent replies.
>
> [@elevenlabs/convai-widget-core@0.18.3](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Fconvai-widget-core%400.18.3) and [@elevenlabs/convai-widget-embed@0.18.3](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Fconvai-widget-embed%400.18.3) - Added image previews and download links for agent message attachments, including attachment-only replies. Stable response IDs prevent duplicate replies, and text-only conversations now use a stop control with an **End chat** tooltip.
>
