# Agents Platform

**ElevenLabs** · 2025-03-10 · [[Themes/agent-mode|Agent Mode]] · Launch · [Official source](https://elevenlabs.io/docs/changelog/2025/3/10) · from [[Releases/ElevenLabs/elevenlabs-2025-03-10-2025-03-10-fbc82651|ElevenLabs updates — 2025-03-10]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> **HIPAA compliance**: Agents Platform is now [HIPAA compliant](https://elevenlabs.io/docs/eleven-agents/legal/hipaa) on appropriate plans, when a BAA is signed, zero-retention mode is enabled and appropriate LLMs are used. For access please [contact sales](https://elevenlabs.io/contact-sales)
>
> **Cascade LLM**: Added dynamic dispatch during the LLM step to other LLMs if your default LLM fails. This results in higher latency but prevents the turn failing.
>
> **Better error messages**: Added better error messages for websocket failures.
>
> **Audio toggling**: Added ability to select only user or agent audio in the conversation playback.
>
> Source: https://elevenlabs.io/docs/changelog/2025/3/10
