# Music

**ElevenLabs** · 2026-03-02 · [[Themes/voice|Voice and Audio]] · Launch · [Official source](https://elevenlabs.io/docs/changelog/2026/3/2) · from [[Releases/ElevenLabs/elevenlabs-2026-03-02-2026-03-02-97fa6f5d|ElevenLabs updates — 2026-03-02]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> **Upload audio**: New [Upload music](https://elevenlabs.io/docs/api-reference/music/upload) endpoint (`POST /v1/music/upload`) accepts a `multipart/form-data` request with an audio file. Optionally extracts a composition plan from the uploaded audio and returns a `MusicUploadResponse` with a `song_id`.
>
> **Phonetic name support**: Added `use_phonetic_names` parameter to [Generate music](https://elevenlabs.io/docs/api-reference/music/compose), [Generate music detailed](https://elevenlabs.io/docs/api-reference/music/compose-detailed), and [Stream music](https://elevenlabs.io/docs/api-reference/music/stream) endpoints.
>
> **Song ID in responses**: Music generation responses now surface the `song_id` field, making it easier to reference generated songs in subsequent API calls.
>
> Source: https://elevenlabs.io/docs/changelog/2026/3/2
