# Agents Platform

**ElevenLabs** · 2025-06-01 · [[Themes/agent-mode|Agent Mode]] · Launch · [Official source](https://elevenlabs.io/docs/changelog/2025/6/1) · from [[Releases/ElevenLabs/elevenlabs-2025-06-01-2025-06-01-b48800e7|ElevenLabs updates — 2025-06-01]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> **Multi-voice support for agents**: Enable ElevenLabs agents to [dynamically switch between different voices](https://elevenlabs.io/docs/eleven-agents/customization/voice/multi-voice-support) during conversations for multi-character storytelling, language tutoring, and role-playing scenarios.
>
> **Claude Sonnet 4 support**: Added [Claude Sonnet 4 as a new LLM option](https://elevenlabs.io/docs/eleven-agents/customization/llm#anthropic) for conversational agents, providing enhanced reasoning capabilities and improved performance.
>
> **Genesys Cloud integration**: Introduced AudioHook Protocol integration for seamless connection with [Genesys Cloud contact center platform](https://elevenlabs.io/docs/eleven-agents/phone-numbers/c-caa-s-integrations/genesys).
>
> **Force delete knowledge base documents**: Added [`force` parameter](https://elevenlabs.io/docs/api-reference/knowledge-base/delete#request.query.force.force) to knowledge base document deletion, allowing removal of documents even when used by agents.
>
> **Multimodal widget**: Added text input and text-only mode defaults for better user experience with [improved widget configuration](https://elevenlabs.io/docs/eleven-agents/customization/widget).
>
> Source: https://elevenlabs.io/docs/changelog/2025/6/1
