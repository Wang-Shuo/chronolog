<!-- chronolog:begin region="evidence" -->
> [v2.45.0](https://github.com/elevenlabs/elevenlabs-js/releases/tag/v2.45.0) - Added `keyterms` (string array, max 50 keyterms of up to 20 chars each) and `noVerbatim` (boolean) options on the Scribe realtime client. `keyterms` are sent as repeated query parameters on the WebSocket URL to bias transcription, and `noVerbatim` removes filler words and disfluencies. Both fields are also added to the typed `Config` interface for the `session_started` echo. Also includes the April 27, 2026 Fern regeneration ([#376](https://github.com/elevenlabs/elevenlabs-js/pull/376)).
>
> [v2.44.0](https://github.com/elevenlabs/elevenlabs-js/releases/tag/v2.44.0) - Fern regeneration for the April 21, 2026 API schema, picking up the `trust_context` field, `pre_tool_speech` mode, and MCP response timeout configuration.
>
