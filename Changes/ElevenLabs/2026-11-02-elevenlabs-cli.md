<!-- chronolog:begin region="evidence" -->
> [v1.9.0](https://github.com/elevenlabs/cli/releases/tag/v1.9.0) - `agents workflow diagram` draws an agent workflow in the terminal, or prints it as Mermaid with `--format mermaid` or `--format mermaid-md`. `agents graph` shows how agents, tools, tests, knowledge base documents and handoffs connect across the agents in `agents.json`, and `--uses` lists the agents that reference a given tool or document. Both commands read local files only. Regenerated against the latest API.
>
> [v1.8.0](https://github.com/elevenlabs/cli/releases/tag/v1.8.0) - Request `User-Agent` headers include how the CLI was installed (`install/`, such as npx, Homebrew or the installer). Pass `--telemetry off`, or set `ELEVENLABS_TELEMETRY=off` or `DO_NOT_TRACK=1`, to drop these tags. Regenerated against the latest API.
