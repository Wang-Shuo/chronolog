# Removed Endpoints

**ElevenLabs** · 2026-02-23 · [[Themes/voice|Voice and Audio]] · Launch · [Official source](https://elevenlabs.io/docs/changelog/2026/2/23) · from [[Releases/ElevenLabs/elevenlabs-2026-02-23-2026-02-23-19067983|ElevenLabs updates — 2026-02-23]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> The following legacy voice generation endpoints have been removed:
>
> `GET /v1/voice-generation/generate-voice/parameters` - Voice Generation Parameters
>
> `POST /v1/voice-generation/generate-voice` - Generate A Random Voice
>
> `POST /v1/voice-generation/create-voice` - Create A Previously Generated Voice
>
> Use the [Voice Design](https://elevenlabs.io/docs/api-reference/text-to-voice/design) and [Voice Remix](https://elevenlabs.io/docs/api-reference/text-to-voice/remix) endpoints instead.
>
> Source: https://elevenlabs.io/docs/changelog/2026/2/23
