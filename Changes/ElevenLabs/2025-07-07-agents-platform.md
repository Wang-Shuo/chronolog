# Agents Platform

**ElevenLabs** · 2025-07-07 · [[Themes/agent-mode|Agent Mode]] · Launch · [Official source](https://elevenlabs.io/docs/changelog/2025/7/7) · from [[Releases/ElevenLabs/elevenlabs-2025-07-07-2025-07-07-2ce7bb7f|ElevenLabs updates — 2025-07-07]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> **HIPAA Compliance**: [Gemini 2.5 Flash is now available for HIPAA customers](https://elevenlabs.io/docs/eleven-agents/legal/hipaa), providing enhanced AI capabilities while maintaining strict healthcare compliance standards.
>
> **Post-call Audio**: Added support for returning call audio in [post-call webhooks](https://elevenlabs.io/docs/eleven-agents/workflows/post-call-webhooks), enabling comprehensive conversation analysis and quality assurance workflows.
>
> **Enhanced Widget**: Added additional [text customization options](https://elevenlabs.io/docs/eleven-agents/customization/widget) including start chat button text, chatting status text, and input placeholders for text-only and new conversations.
>
> **Agent Transfers**: Improved [agent transfer capabilities](https://elevenlabs.io/docs/eleven-agents/customization/tools/system-tools/agent-transfer) with transfer delay configuration, custom transfer messages, and control over transferred agent first message behavior.
>
> **SIP Trunk Enhancements**: Added support for separate inbound and outbound [SIP trunk configurations](https://elevenlabs.io/docs/eleven-agents/phone-numbers/sip-trunking) with enhanced access control and transfer options.
>
> Source: https://elevenlabs.io/docs/changelog/2025/7/7
