# Packages

**ElevenLabs** · 2026-10-26 · [[Themes/voice|Voice and Audio]] · Launch · [Official source](https://elevenlabs.io/docs/changelog/2026/10/26) · from [[Releases/ElevenLabs/elevenlabs-2026-10-26-2026-10-26-ca7c552d|ElevenLabs updates — 2026-10-26]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> [@elevenlabs/client@1.29.0](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Fclient%401.29.0) and [@elevenlabs/react@1.19.0](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Freact%401.19.0) - Added the `onAudioAlignmentPlayback` callback, called with `{ event_id, alignment }` when an aligned audio chunk starts playing, for syncing text with speech. It is not called on WebRTC connections.
>
> [@elevenlabs/client@1.30.0](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Fclient%401.30.0) - Added the opt-in `stripAudioTags` session option, which removes audio tags such as `[laughs]` from agent messages passed to `onMessage` and `onAgentResponseCorrection`, and exports the `stripAudioTags` helper. Stripped text no longer lines up with `onAudioAlignment` timings.
>
> [@elevenlabs/client@1.31.0](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Fclient%401.31.0), [@elevenlabs/types@0.26.0](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Ftypes%400.26.0) and [@elevenlabs/react@1.20.0](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Freact%401.20.0) - Added `overrides.tts.modelId` for a per-conversation TTS model override. Realtime Speech to Text emits `RealtimeEvents.AUDIO_STARTED` once the first microphone audio frame is sent, and `useScribe` in microphone mode reports `connected` only from that point.
>
> [@elevenlabs/convai-widget-core@0.21.0](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Fconvai-widget-core%400.21.0) and [@elevenlabs/convai-widget-embed@0.21.0](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Fconvai-widget-embed%400.21.0) - Voice call transcripts are revealed in step with the agent's speech, and an interrupted reply keeps only what was said. Resuming a persistent text conversation no longer asks the user to accept the terms again.
>
> [@elevenlabs/convai-widget-core@0.21.1](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Fconvai-widget-core%400.21.1), [0.21.3](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Fconvai-widget-core%400.21.3) and [0.21.4](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Fconvai-widget-core%400.21.4) - Text chat shows typing dots while the agent prepares its reply. Rich content carousels show a page indicator, stay clickable after the conversation moves on, and appear in voice calls while the agent is still speaking. On screens narrower than 768px the chat opens fullscreen; add `mobile-fullscreen="false"` to the embed to keep the compact layout.
>
> [@elevenlabs/react-native@1.2.31](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Freact-native%401.2.31), [1.2.32](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Freact-native%401.2.32) and [1.2.33](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Freact-native%401.2.33) - Updated to the latest `@elevenlabs/client` and `@elevenlabs/react` releases.
>
> Source: https://elevenlabs.io/docs/changelog/2026/10/26
