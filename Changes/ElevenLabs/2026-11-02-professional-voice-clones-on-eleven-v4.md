# Professional Voice Clones on Eleven v4

**ElevenLabs** · 2026-11-02 · [[Themes/voice|Voice and Audio]] · Launch · [Official source](https://elevenlabs.io/docs/changelog/2026/11/2) · from [[Releases/ElevenLabs/elevenlabs-2026-11-02-2026-11-02-7efe9660|ElevenLabs updates — 2026-11-02]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> **Text to Speech** Professional Voice Clone fine-tuning for Eleven v4 and Eleven v4 Turbo is now available to every workspace. To train an existing clone, hover over it in [My Voices](https://elevenlabs.io/app/voice-lab) and click the plus button next to Eleven v4. Requests for a clone fine-tuned on v4 now use the `clone_strength` saved in the voice's settings when the request sets neither `clone_strength` nor `use_pvc_as_ivc`, so you no longer need to pass it on every call. See [Eleven v4](https://elevenlabs.io/docs/overview/capabilities/text-to-speech/eleven-v4#voice-cloning).
