# 3 Pricing Model changes in ElevenLabs updates — 2026-11-02

**ElevenLabs** · 2026-11-02 · [[Themes/pricing-model|Pricing Model]] · Digest · [Official source](https://elevenlabs.io/docs/changelog/2026/11/2) · from [[Releases/ElevenLabs/elevenlabs-2026-11-02-2026-11-02-7efe9660|ElevenLabs updates — 2026-11-02]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> **Architect charging**: Architect usage is now billed from workspace credits as its own line item, separate from agents' minutes and LLM cost. Billing is rolling out gradually; the composer in the dashboard shows when it applies to your workspace. See [Pricing and usage](https://elevenlabs.io/docs/eleven-agents/operate/architect/pricing).

> **Realtime pricing**: Workspace pricing tables list Realtime API audio (`eleven_realtime_v1_audio`) and the Eleven Realtime v1 Mini and Max token rates.

> **Preview conversation discount**: The discount on conversations started from the agent tester applies only to workspaces on 2022 pricing. On 2026 pricing, `charging.dev_discount` is `false`.

Source: https://elevenlabs.io/docs/changelog/2026/11/2
