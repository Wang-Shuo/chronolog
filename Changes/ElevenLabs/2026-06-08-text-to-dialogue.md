# Text to Dialogue

**ElevenLabs** · 2026-06-08 · [[Themes/enterprise-admin|Enterprise and Administration]] · Launch · [Official source](https://elevenlabs.io/docs/changelog/2026/6/8) · from [[Releases/ElevenLabs/elevenlabs-2026-06-08-2026-06-08-4f50e6b2|ElevenLabs updates — 2026-06-08]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> **Zero retention mode**: [Convert text to dialogue](https://elevenlabs.io/docs/api-reference/text-to-dialogue/convert), [Stream text to dialogue](https://elevenlabs.io/docs/api-reference/text-to-dialogue/stream), [Convert text to dialogue with timestamps](https://elevenlabs.io/docs/api-reference/text-to-dialogue/convert-with-timestamps) and [Stream text to dialogue with timestamps](https://elevenlabs.io/docs/api-reference/text-to-dialogue/stream-with-timestamps) add optional `enable_logging` query parameter (boolean, default `true`). Set `enable_logging=false` to use zero retention mode with no history or request stitching. Zero retention mode is available to enterprise customers only.
