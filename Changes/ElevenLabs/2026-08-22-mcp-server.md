# MCP server

**ElevenLabs** · 2026-08-22 · [[Themes/apps-integrations|Apps and Integrations]] · Policy · [Official source](https://elevenlabs.io/docs/changelog/2026/8/22) · from [[Releases/ElevenLabs/elevenlabs-2026-08-22-2026-08-22-fba2ac96|ElevenLabs updates — 2026-08-22]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> **Local MCP server deprecated**: The local [ElevenLabs MCP server](https://github.com/elevenlabs/elevenlabs-mcp) and [MCP player](https://github.com/elevenlabs/elevenlabs-mcp-player) are deprecated in favor of the [hosted MCP server](https://elevenlabs.io/docs/eleven-agents/operate/hosted-mcp). Both repositories are archived and will no longer receive updates. The hosted server is available at `https://api.elevenlabs.io/v1/mcp`, signs in with your ElevenLabs account through OAuth and requires no local installation or API key. See the [hosted MCP server documentation](https://elevenlabs.io/docs/eleven-agents/operate/hosted-mcp) for setup instructions for Claude, Cursor and other MCP clients.
>
> Source: https://elevenlabs.io/docs/changelog/2026/8/22
