# Voices

**ElevenLabs** · 2026-07-27 · [[Themes/voice|Voice and Audio]] · Launch · [Official source](https://elevenlabs.io/docs/changelog/2026/7/27) · from [[Releases/ElevenLabs/elevenlabs-2026-07-27-2026-07-27-29809f38|ElevenLabs updates — 2026-07-27]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> **Voice accents**: Added `GET /v1/voices/accents` to list the accents available in the shared voice library. Results can be filtered by `language` and `model_id`, and each accent returns its `accent`, `language`, `code` and human-readable `name`. The `accent` value can be passed to the `accent` query parameter on [Get shared voices](https://elevenlabs.io/docs/api-reference/voices/voice-library/get-shared) to filter shared voices.
>
