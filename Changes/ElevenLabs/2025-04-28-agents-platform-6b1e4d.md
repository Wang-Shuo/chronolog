# Agents Platform

**ElevenLabs** · 2025-04-28 · [[Themes/agent-mode|Agent Mode]] · Launch · [Official source](https://elevenlabs.io/docs/changelog/2025/4/28) · from [[Releases/ElevenLabs/elevenlabs-2025-04-28-2025-04-28-49480de5|ElevenLabs updates — 2025-04-28]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> **Custom Dashboard Charts**: The Agents Platform dashboard can now be extended with custom charts displaying the results of evaluation criteria over time. See the new [GET](https://elevenlabs.io/docs/api-reference/workspace/dashboard/get) and [PATCH](https://elevenlabs.io/docs/api-reference/workspace/dashboard/update) endpoints for managing dashboard settings.
>
> **Call History Filtering**: Added the ability to filter the call history by start date using the new `call_start_before_unix` parameter in the [List Conversations](https://elevenlabs.io/docs/eleven-agents/api-reference/conversations/list#request.query.call_start_before_unix) endpoint. [Try it here](https://elevenlabs.io/app/agents/history).
>
> **Server Tools**: Added option of making PUT requests in [server tools](https://elevenlabs.io/docs/eleven-agents/customization/tools/server-tools)
>
> **Transfer to number**: Added call forwarding functionality to support forwarding to operators, see docs [here](https://elevenlabs.io/docs/eleven-agents/customization/tools/system-tools/transfer-to-number)
>
> **Language detection**: Fixed an issue where the [language detection system tool](https://elevenlabs.io/docs/eleven-agents/customization/tools/system-tools/language-detection) would trigger on a user replying yes in non-English language.
>
> Source: https://elevenlabs.io/docs/changelog/2025/4/28
