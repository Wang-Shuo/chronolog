<!-- chronolog:begin region="evidence" -->
> [@elevenlabs/client@1.4.0](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Fclient%401.4.0) - Added `keyterms` (`string[]`) and `noVerbatim` (`boolean`) options to the Scribe realtime API. `keyterms` are sent as repeated WebSocket query parameters and can include up to 50 terms of up to 20 characters each. `noVerbatim` removes filler words, false starts, and disfluencies from transcripts. Also fixed a case where interruptions could cut off agent audio that arrived less than 2 seconds after the interruption.
>
> [@elevenlabs/types@0.10.0](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Ftypes%400.10.0) - Added shared types for Scribe realtime `keyterms` and `noVerbatim`.
>
> [@elevenlabs/react@1.3.0](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Freact%401.3.0), [@elevenlabs/react-native@1.1.4](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Freact-native%401.1.4), [@elevenlabs/convai-widget-core@0.11.7](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Fconvai-widget-core%400.11.7), and [@elevenlabs/convai-widget-embed@0.11.7](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Fconvai-widget-embed%400.11.7) - Updated to the latest client package, including Scribe realtime options and the agent audio interruption fix.
>
> [@elevenlabs/react@1.2.2](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Freact%401.2.2) - Patch release that includes the Scribe realtime options, the agent audio interruption fix, and an automatic random user ID when none is set.
>
