# Agents Platform

**ElevenLabs** · 2025-04-07 · [[Themes/agent-mode|Agent Mode]] · Launch · [Official source](https://elevenlabs.io/docs/changelog/2025/4/7) · from [[Releases/ElevenLabs/elevenlabs-2025-04-07-2025-04-07-0e7ab415|ElevenLabs updates — 2025-04-07]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> **Document type filtering**: Added support for filtering knowledge base documents by their [type](https://elevenlabs.io/docs/api-reference/knowledge-base/list#request.query.types) (file, URL, or text).
>
> **Non-audio agents**: Added support for conversational agents that don't output audio but still send response transcripts and can use tools. Non-audio agents can be enabled by removing the audio [client event](https://elevenlabs.io/docs/eleven-agents/customization/events/client-events).
>
> **Improved agent templates**: Updated all agent templates with enhanced configurations and prompts. See more about how to improve system prompts [here](https://elevenlabs.io/docs/eleven-agents/best-practices/prompting-guide).
>
> **Fixed stuck exports**: Fixed an issue that caused exports to be stuck for extended periods.
>
> Source: https://elevenlabs.io/docs/changelog/2025/4/7
