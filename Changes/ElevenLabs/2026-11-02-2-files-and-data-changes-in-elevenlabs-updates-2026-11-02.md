# 2 Files and Data changes in ElevenLabs updates — 2026-11-02

**ElevenLabs** · 2026-11-02 · [[Themes/file-data|Files and Data]] · Digest · [Official source](https://elevenlabs.io/docs/changelog/2026/11/2) · from [[Releases/ElevenLabs/elevenlabs-2026-11-02-2026-11-02-7efe9660|ElevenLabs updates — 2026-11-02]]

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> **Knowledge base**: [Update document](https://elevenlabs.io/docs/api-reference/knowledge-base/update) accepts `enable_auto_sync`, `auto_remove` and `minimum_frequency_days`, and the dashboard can edit these auto-sync settings after a document is created, optionally applying folder settings to existing documents. Sitemap crawls accept `exclude_patterns`, with an **Exclude patterns** field in the sitemap step of the URL dialog. Website crawls deduplicate pages by canonical URL, and Google Drive auto-sync pauses when the Drive token is rejected and resumes after you reconnect. See [Knowledge base](https://elevenlabs.io/docs/eleven-agents/customization/knowledge-base).

> **Word uploads**: Audiobook projects can be created from Word `.docx` files as well as EPUB and PDF.
