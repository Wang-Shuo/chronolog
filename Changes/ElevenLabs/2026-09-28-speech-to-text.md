<!-- chronolog:begin region="evidence" -->
> **Transcript editing**: Batch and realtime transcription now accept a natural-language edit instruction of up to 2,000 characters. Batch responses return the result in `edited_transcript`, while realtime sessions emit an `edited_transcript` event.
