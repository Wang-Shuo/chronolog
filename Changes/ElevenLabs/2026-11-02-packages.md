> [@elevenlabs/client@1.34.0](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Fclient%401.34.0), [@elevenlabs/types@0.28.0](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Ftypes%400.28.0) and [@elevenlabs/react@1.21.0](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Freact%401.21.0) - `Scribe.connect()` and `useScribe()` accept `entityRedaction` and `entityRedactionMode`, and dispatch the `redacted_transcript` message after each committed transcript. `useScribe()` adds an `onRedactedTranscript` callback and sets `redactedText` on the matching entry in `committedTranscripts`. `stripAudioTags` removes audio tags written in any language, not only tags in English letters.

> [@elevenlabs/convai-widget-core@0.24.0](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Fconvai-widget-core%400.24.0) - With `persistent-session` enabled, a voice call can be resumed after a page navigation. The next page shows the conversation so far with "Resume talking?", and resuming starts a new conversation that continues from those turns, skipping the greeting if the agent allows first message overrides.
>
> [@elevenlabs/client@1.32.0](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Fclient%401.32.0) - Self-hosted worklets (`workletPaths`) are checked against the installed client version. A worklet copied from another release fails at session start with an error that names the worklet and path. Re-copy the files from `@elevenlabs/client/worklets/*` when upgrading.
>
> [@elevenlabs/client@1.32.1](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Fclient%401.32.1) - Fixes the start of the agent's first message playing too fast and too high when the browser cannot use the agent's sample rate. Voice sessions wait for the output resampler and fail with an error if it cannot be created.
>
> [@elevenlabs/client@1.33.0](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Fclient%401.33.0), [@elevenlabs/types@0.27.0](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Ftypes%400.27.0) and [@elevenlabs/convai-widget-core@0.23.0](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Fconvai-widget-core%400.23.0) - Added a `cloneStrength` TTS override to the client and an `override-clone-strength` attribute to the widget. History rows of resumed persistent text conversations can carry `rich_content`, and the widget replays it.
>
> [@elevenlabs/react@1.20.3](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Freact%401.20.3) - `useScribe` with `autoConnect` keeps a single open session under React StrictMode.
>
> [@elevenlabs/convai-widget-core@0.22.0](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Fconvai-widget-core%400.22.0) - Added the `transcript-speech-sync` attribute; set it to `false` to show the agent's full message at once in voice calls. Carousel cards accept an optional `rating` from 0 to 5 and `review_count`.
>
> [@elevenlabs/convai-widget-core@0.21.6](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Fconvai-widget-core%400.21.6) and [0.22.2](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Fconvai-widget-core%400.22.2) - Voice calls show typing dots when the agent takes more than a second to start replying, or "Thinking..." under the avatar when the transcript is off. Partially revealed markdown links show their text instead of `[blocked]`, carousel arrows no longer flicker, and carousel images use a 4:5 ratio.
>
> [@elevenlabs/react@1.20.1](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Freact%401.20.1), [1.20.2](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Freact%401.20.2), [@elevenlabs/react-native@1.2.34](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Freact-native%401.2.34), [1.2.35](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Freact-native%401.2.35), [1.2.36](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Freact-native%401.2.36), [1.2.37](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Freact-native%401.2.37), [@elevenlabs/convai-widget-core@0.22.1](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Fconvai-widget-core%400.22.1), [0.24.1](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Fconvai-widget-core%400.24.1) and [@elevenlabs/convai-widget-embed@0.21.6](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Fconvai-widget-embed%400.21.6) to [0.24.1](https://github.com/elevenlabs/packages/releases/tag/%40elevenlabs%2Fconvai-widget-embed%400.24.1) - Updated to the latest `@elevenlabs/client` and widget releases.
