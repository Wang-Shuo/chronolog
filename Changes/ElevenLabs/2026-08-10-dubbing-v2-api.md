# Dubbing v2 API

**ElevenLabs** · 2026-08-10 · [[Themes/voice|Voice and Audio]] · Launch · [Official source](https://elevenlabs.io/docs/changelog/2026/8/10) · from [[Releases/ElevenLabs/elevenlabs-2026-08-10-2026-08-10-3c63678b|ElevenLabs updates — 2026-08-10]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> Dubbing v2 is now available through the API. It translates audio and video into more than 90 languages while preserving each speaker's voice, tone and pacing.
>
> The new project-based API keeps source transcripts and translations as editable JSON. Create a project from a file or URL, add one or more target languages, edit individual transcript segments or translations, then regenerate only the regions that changed. Follow the [Dubbing quickstart](https://elevenlabs.io/docs/eleven-api/guides/cookbooks/dubbing) to create your first dub.
>
> Source: https://elevenlabs.io/docs/changelog/2026/8/10
