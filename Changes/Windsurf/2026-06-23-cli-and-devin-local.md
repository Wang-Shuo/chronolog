# CLI and Devin Local

**Windsurf** · 2026-06-23 · [[Themes/developer-workflow|Developer Workflow]] · Launch · [Official source](https://docs.devin.ai/desktop/changelog#v3-3-18) · from [[Releases/Windsurf/windsurf-2026-06-23-v3-3-18-b3edad75|v3.3.18]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> On Windows, `bash` now resolves to Git Bash instead of the WSL launcher stub.
>
> Subagents can now be configured with a default model.
>
> The MCP registry cache is now warmed during startup, so MCP servers are ready sooner.
>
> Injected context is no longer included in auto-generated session titles.
>
> Added an `attribution` option to the Devin Local [config file](https://docs.devin.ai/cli/reference/configuration/config-file.md); set it to `false` to suppress Devin mentions in commit messages.
>
