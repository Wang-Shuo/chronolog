# 3 Agent Mode changes in v3.11.212

**Windsurf** · 2026-10-23 · [[Themes/agent-mode|Agent Mode]] · Digest · [Official source](https://docs.devin.ai/desktop/changelog#v3-11-212) · from [[Releases/Windsurf/windsurf-2026-10-23-v3-11-212-ce285b20|v3.11.212]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Agent edits are saved without running format-on-save or code actions. Enable "Run save actions on agent edits" to restore the previous behavior.

> Saving agent environment variables restarts the affected local agent, so new sessions use the updated values.

> The "System notifications" switch in Devin settings now turns agent notifications on and off.
