<!-- chronolog:begin region="evidence" -->
> Added support for connecting to MCP servers on protocol revision 2026-07-28 (`server/discover`, no `initialize`).
>
> Enterprise admins can now set an **Extension marketplace URL** in the Devin Desktop team settings. When set, Devin Desktop searches for and installs extensions from that marketplace only. See [Admin controls](https://docs.devin.ai/desktop/controls.md).
>
> Improved performance for very large or deeply nested folders.
>
> Replaced folder and git-@ mention system with a faster integration while removing the code context @-mention category.
>
> The model picker remembers the variant you last used for each model family, instead of resetting to the family default.
>
> **\[Private Preview]** Devin Desktop can now connect to remote MCPs configured in Devin Cloud. Only enterprise-level MCPs will be reached.
>
