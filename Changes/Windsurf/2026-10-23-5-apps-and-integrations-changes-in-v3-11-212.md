# 5 Apps and Integrations changes in v3.11.212

**Windsurf** · 2026-10-23 · [[Themes/apps-integrations|Apps and Integrations]] · Digest · [Official source](https://docs.devin.ai/desktop/changelog#v3-11-212) · from [[Releases/Windsurf/windsurf-2026-10-23-v3-11-212-ce285b20|v3.11.212]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Configured MCP servers can be @-mentioned.

> Plugins can declare `platforms: [cloud]` or `platforms: [local]`; Devin Desktop only activates plugins that apply locally.

> MCP servers from every configured registry can be installed, not only those from the first registry.

> MCP tool calls that need approval in Devin Local show their Allow / Reject controls.

> `remoteEnv`, `customizations.vscode.settings`, extensions, `forwardPorts` and `shutdownAction` apply.

Source: https://docs.devin.ai/desktop/changelog#v3-11-212
