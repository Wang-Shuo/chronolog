<!-- chronolog:begin region="evidence" -->
> Improved performance for loading Devin Cloud sessions.
>
> Devin Cloud sessions now show the server-side send queue, kept in sync with the web app; Cmd/Ctrl+Enter queues the next message on the server.
>
> Multi-user (Slack) sessions now show each participant's name above their messages.
>
> A "Copy link" action was added to cloud session menus.
>
> A "Remote ACP is disconnected" banner with a Reconnect action now appears when the Cloud connection drops.
