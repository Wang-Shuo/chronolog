<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> In Remote-SSH and Remote-WSL windows, the Agent Window folder picker correctly sets the session's working directory. It lists the window's remote folders and no longer offers local ones.

> In Remote-SSH and Remote-WSL windows, file links in the Agent Window (citations, diffs, settings and plugins) now open from the remote machine.
