# 2 Interface Experience changes in v3.11.212

**Windsurf** · 2026-10-23 · [[Themes/interface-experience|Interface Experience]] · Digest · [Official source](https://docs.devin.ai/desktop/changelog#v3-11-212) · from [[Releases/Windsurf/windsurf-2026-10-23-v3-11-212-ce285b20|v3.11.212]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Devin no longer opens files in the background when it edits them. Turn "Auto-open edited files" back on in Devin Settings → Editor → User Interface to restore this.

> Agent diff zones are off by default, so agent edits are applied directly to files. Re-enable them in Devin Settings → Editor → User Interface → Agent diff zones.

Source: https://docs.devin.ai/desktop/changelog#v3-11-212
