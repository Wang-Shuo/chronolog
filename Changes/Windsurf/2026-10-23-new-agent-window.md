# New Agent Window

**Windsurf** · 2026-10-23 · [[Themes/agent-mode|Agent Mode]] · Launch · [Official source](https://docs.devin.ai/desktop/changelog#v3-11-212) · from [[Releases/Windsurf/windsurf-2026-10-23-v3-11-212-ce285b20|v3.11.212]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> The Agent Window now runs the same interface as the Devin web app: the sessions sidebar, session view, Automations, Review, Wiki, settings, and Command Palette (⌘K) match app.devin.ai, and follow your Devin Desktop theme.
>
> Drag a session from the sidebar onto an open session to view up to 8 sessions side by side.
>
> Group sidebar sessions by workspace, with a "+" on each group to start a session in that folder.
>
> Start a child session from any session's "More" menu.
>
> Sessions grouped into Spaces now appear under a parent session in the sidebar.
>
> Files, changes, and terminals in every session:
>
> A Files view shows a local session's working directory or a cloud session's machine as a file tree next to the editor.
>
> The Changes tab now works for local sessions, with per-file diffs and a "Since last seen" scope.
>
> **Terminal** in a session's add-tab menu opens a terminal on the session's machine, or a local shell in the session's folder.
>
> `Cmd/Ctrl+O` opens a local file in the Agent Window, and `Cmd/Ctrl+Shift+F` searches the text of the session's files.
>
> Files open in the Agent Window's editor support code actions and rename.
>
> Cloud sessions:
>
> The **IDE** button in the top right opens a Remote SSH window on the session's machine.
>
> App previews open in a Preview tab, with a URL bar, port switching, device sizes, and an element picker.
>
> Cloud sessions connected to your machine read unsaved edits from open editors.
>
> Code scan sessions show a scan badge and open their Findings view beside the chat.
>
> Customizations and settings now match the same UI as Devin Cloud.
>
> New shortcuts: `Cmd/Ctrl+.` cycles the agent mode, `Cmd/Ctrl+[` and `Cmd/Ctrl+]` go back and forward, `Cmd/Ctrl+Shift+L` copies a link to the session, and `Cmd/Ctrl+Shift+E` marks a session done. Typing anywhere focuses the composer.
>
> Source: https://docs.devin.ai/desktop/changelog#v3-11-212
<!-- chronolog:end -->
