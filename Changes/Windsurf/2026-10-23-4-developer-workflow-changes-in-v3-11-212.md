# 4 Developer Workflow changes in v3.11.212

**Windsurf** · 2026-10-23 · [[Themes/developer-workflow|Developer Workflow]] · Digest · [Official source](https://docs.devin.ai/desktop/changelog#v3-11-212) · from [[Releases/Windsurf/windsurf-2026-10-23-v3-11-212-ce285b20|v3.11.212]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> The command palette searches the content of Local sessions, not only their titles.

> `Ctrl+Shift+C` copies in terminals again, and the Send Terminal to Chat shortcut works on Windows and Linux.

> New **Dev Containers: Rebuild Container** and **Rebuild Container Without Cache** commands; a Rebuild prompt when `devcontainer.json`, the Dockerfile or the Compose file changes; a **Reopen in Container** prompt when you open a folder with a Dev Container configuration.

> Slim images without `curl`, `wget` or `procps` work, and a Dev Container window is trusted when its host folder is trusted.

Source: https://docs.devin.ai/desktop/changelog#v3-11-212
