# 2 Developer Workflow changes in v3.11.216

**Windsurf** · 2026-10-24 · [[Themes/developer-workflow|Developer Workflow]] · Digest · [Official source](https://docs.devin.ai/desktop/changelog#v3-11-216) · from [[Releases/Windsurf/windsurf-2026-10-24-v3-11-216-5e8fa8fb|v3.11.216]]

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> On Windows, `devin` is available in a new terminal (PowerShell, Command Prompt, Windows Terminal and Git Bash) right after **Install Devin CLI**, without signing out first. On macOS and Linux, running **Install Devin CLI** again refreshes the link instead of failing.

> Devin Local sessions no longer crash when a terminal command prints an inline image (sixel, iTerm2 or kitty).

Source: https://docs.devin.ai/desktop/changelog#v3-11-216
