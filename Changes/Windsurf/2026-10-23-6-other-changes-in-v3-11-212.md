# 6 other changes in v3.11.212

**Windsurf** · 2026-10-23 · Other changes · Digest · [Official source](https://docs.devin.ai/desktop/changelog#v3-11-212) · from [[Releases/Windsurf/windsurf-2026-10-23-v3-11-212-ce285b20|v3.11.212]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Pressing Enter while Devin is working steers the running turn; `Cmd/Ctrl+Enter` queues the message until the turn ends.

> Worktrees are no longer deleted automatically once a repository has more than 19 of them.

> Long sessions stay responsive while replies stream, and scrolling long transcripts is smoother.

> Markdown files of a cloud session open as a rendered preview again.

> Dev Containers:

> `onCreateCommand`, `updateContentCommand`, `postCreateCommand`, `postStartCommand` and `postAttachCommand` from `devcontainer.json`, Features and image metadata now run, and dotfiles are installed from `remote.devinDevContainers.dotfiles.*`.

Source: https://docs.devin.ai/desktop/changelog#v3-11-212
