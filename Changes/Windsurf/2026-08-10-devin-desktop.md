# Devin Desktop

**Windsurf** · 2026-08-10 · [[Themes/mobile-desktop|Mobile and Desktop]] · Launch · [Official source](https://docs.devin.ai/desktop/changelog#v3-7-16) · from [[Releases/Windsurf/windsurf-2026-08-10-v3-7-16-bb404410|v3.7.16]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> "Restart to Update" now asks for confirmation when local agents are still working and says how many will be stopped; cloud sessions keep running.
>
> The old "Plugins" section for IDE extension marketplaces has been renamed to "Extensions".
>
> Hide Cascade-specific configuration and customization options when Cascade is disabled for your team.
>
> Visual polish for the Agent Command Center: left-aligned titlebar, unsaved-changes indicator on file tabs, no more Cmd+P open/close flicker, aligned PR icons in Quick Open, full-width sidebar title renaming, and dragged session tabs that pick up their session name.
>
> Starting an agent in a new worktree that fails now surfaces the git error instead of quietly running in your workspace.
>
> **Terminal: Create New Terminal in Editor Area** now works inside worktrees.
>
> Codemaps and MCP configuration files now open from the remote machine when connected over WSL, SSH, or a dev container.
>
> Teams plan members no longer see quota warning banners they cannot act on.
>
> Source: https://docs.devin.ai/desktop/changelog#v3-7-16
