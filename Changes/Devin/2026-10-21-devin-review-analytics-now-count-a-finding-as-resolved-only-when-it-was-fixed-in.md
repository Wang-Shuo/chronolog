# Devin Review analytics now count a finding as resolved only when it was fixed…

**Devin** · 2026-10-21 · Other changes · [Official source](https://docs.devin.ai/release-notes/2026) · from [[Releases/Devin/devin-2026-10-21-2026-10-21-0cb42267|Devin updates — 2026-10-21]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> Devin Review analytics now count a finding as resolved only when it was fixed in code, by a later push or by Devin. Findings dismissed by a reviewer and duplicates no longer count, so resolved numbers will be lower.
>
