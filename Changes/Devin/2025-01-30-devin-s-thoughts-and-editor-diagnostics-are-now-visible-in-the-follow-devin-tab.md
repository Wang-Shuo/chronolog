# **Devin's thoughts and editor diagnostics are now visible**

**Devin** · 2025-01-30 · [[Themes/editor-experience|Editor Experience]] · [Official source](https://docs.devin.ai/release-notes/2025) · from [[Releases/Devin/devin-2025-01-30-2025-01-30-a3d58baf|Devin updates — 2025-01-30]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> **Devin's thoughts and editor diagnostics are now visible**: In the Follow Devin tab, you'll now see:
>
> each action Devin took (e.g. "Edited github.py")
>
> Devin's thoughts explaining *why* the action was taken (e.g. "There was a type error….the fix involves XYZ")
>
> any editor diagnostics errors present after the action was taken (in red)
>
> Source: https://docs.devin.ai/release-notes/2025
