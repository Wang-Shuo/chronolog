**Devin** · 2026-06-19 · [[Themes/enterprise-admin|Enterprise and Administration]] · Launch · [Official source](https://docs.devin.ai/release-notes/2026) · from [[Releases/Devin/devin-2026-06-19-2026-06-19-ff036602|Devin updates — 2026-06-19]]

> A new "User only" option is available in the "Open PRs as" setting. When selected, Devin will only create PRs under the user's identity and will fail if their Git account is not connected.
