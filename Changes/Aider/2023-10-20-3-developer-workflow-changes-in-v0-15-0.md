# 3 Developer Workflow changes in v0.15.0

**Aider** · 2023-10-20 · [[Themes/developer-workflow|Developer Workflow]] · Digest · [Official source](https://github.com/Aider-AI/aider/releases/tag/v0.15.0) · from [[Releases/Aider/aider-2023-10-20-v0-15-0-github-126041111-86576afe|v0.15.0]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Added support for `.aiderignore` file, which instructs aider to ignore parts of the git repo.

> New `--commit` cmd line arg, which just commits all pending changes with a sensible commit message geneated by gpt-3.5.

> `/run` and `/git` now accept full shell commands, like: `/run (cd subdir; ls)`

Source: https://github.com/Aider-AI/aider/releases/tag/v0.15.0
