# 2 Editor Experience changes in v0.16.0

**Aider** · 2023-10-29 · [[Themes/editor-experience|Editor Experience]] · Digest · [Official source](https://github.com/Aider-AI/aider/releases/tag/v0.16.0) · from [[Releases/Aider/aider-2023-10-29-v0-16-0-github-127097099-e52ac334|v0.16.0]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Switched from "edit block" to "search/replace block", which reduced malformed edit blocks. [Benchmarked](https://aider.chat/docs/benchmarks.html) at 66.2%, no regression.

> Improved handling of malformed edit blocks targetting multiple edits to the same file. [Benchmarked](https://aider.chat/docs/benchmarks.html) at 65.4%, no regression.

Source: https://github.com/Aider-AI/aider/releases/tag/v0.16.0
