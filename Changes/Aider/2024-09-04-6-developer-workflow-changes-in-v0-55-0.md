# 6 Developer Workflow changes in v0.55.0

**Aider** · 2024-09-04 · [[Themes/developer-workflow|Developer Workflow]] · Digest · [Official source](https://github.com/Aider-AI/aider/releases/tag/v0.55.0) · from [[Releases/Aider/aider-2024-09-04-v0-55-0-github-173466209-522ef089|Aider v0.55.0]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> New `/settings` command to show active settings.

> Sanity check the git repo and exit gracefully on problems.

> Disabled built in linter for typescript.

> Adopted setuptools_scm to provide `vX.Y.Z.dev` version naming with git hashes.

> Added --verbose debug output for shell commands.

> Refuse to make git repo in $HOME, warn user.

Source: https://github.com/Aider-AI/aider/releases/tag/v0.55.0
