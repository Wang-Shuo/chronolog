# Background Agent (Preview)

**Cursor** · 2025-05-15 · [[Themes/agent-mode|Agent Mode]] · Launch · [Official source](https://cursor.com/changelog/0-50) · from [[Releases/Cursor/cursor-2025-05-15-0-50-https-cursor-com-changelog-0-50-dc290998|Simplified Pricing, Background Agent and Refreshed Inline Edit]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> In early preview, rolling out gradually: Cursor agents can now run in the background! To try it, head to Settings > Beta > Background Agent.
>
> This allows you to run many agents in parallel and have them tackle bigger tasks. The agents run in their own remote environments. At any point, you can view the status, send a follow-up, or take over.
>
> We’re curious to hear what you think. While it is still early, we’ve found background agents useful internally for fixing nits, doing investigations, and writing first drafts of medium-sized PRs. Read more at cursor.com/docs/background-agent.
>
> Source: https://cursor.com/changelog/0-50
