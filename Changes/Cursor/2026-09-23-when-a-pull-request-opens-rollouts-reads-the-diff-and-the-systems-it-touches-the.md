# Monitoring plans

**Cursor** · 2026-09-23 · [[Themes/developer-workflow|Developer Workflow]] · Launch · [Official source](https://cursor.com/changelog/rollouts-and-security-reviewer) · from [[Releases/Cursor/cursor-2026-09-23-rollouts-and-security-review-https-cursor-com-changelog-rollouts-b860a5fb|Rollouts and Security Review]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> When a pull request opens, Rollouts reads the diff and the systems it touches, then writes a monitoring plan as a PR comment. The plan lists the risks it identified, the effect the change is meant to have, the signals it will check, and any gaps in instrumentation that would make the change hard to verify. Edit the plan in the PR and Rollouts uses your version.
>
> Source: https://cursor.com/changelog/rollouts-and-security-reviewer
