# 3 Apps and Integrations changes in CLI Improvements and Mermaid ASCII…

**Cursor** · 2026-02-18 · [[Themes/apps-integrations|Apps and Integrations]] · Digest · [Official source](https://cursor.com/changelog/cli-feb-18-2026) · from [[Releases/Cursor/cursor-2026-02-18-cli-improvements-and-mermaid-ascii-diagrams-https-cursor-com-cha-a75d36c7|CLI Improvements and Mermaid ASCII Diagrams]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> AI code attribution is now preserved by Cursor Blame when formatters like Prettier, Biome, or pre-commit hooks rewrite code.

> When an MCP server's credentials expire mid-session, the agent can now re-authenticate on demand instead of failing silently.

> If you skip approving an MCP server, it stays disabled for the rest of the session rather than prompting you repeatedly.
