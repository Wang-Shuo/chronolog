# 3 Editor Experience changes in 3.1

**Cursor** · 2026-04-13 · [[Themes/editor-experience|Editor Experience]] · Digest · [Official source](https://cursor.com/changelog/3-1) · from [[Releases/Cursor/cursor-2026-04-13-3-1-https-cursor-com-changelog-3-1-27a51313|Tiled Layout and Upgraded Voice Input in the Agents Window]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Cmd-K now shows fewer, more relevant agent results, capped to the recent matching set (i.e., items that match your query and are from a recent subset).

> Limited local diff fetches to reduce CPU/network spikes and lag in SCM views.

> Large edits stream more smoothly now after cutting dropped frames by ~87%.
