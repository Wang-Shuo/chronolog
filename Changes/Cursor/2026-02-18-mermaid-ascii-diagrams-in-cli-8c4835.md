# Mermaid ASCII diagrams in CLI

**Cursor** · 2026-02-18 · [[Themes/developer-workflow|Developer Workflow]] · Launch · [Official source](https://cursor.com/changelog/cli-feb-18-2026) · from [[Releases/Cursor/cursor-2026-02-18-cli-improvements-and-mermaid-ascii-diagrams-https-cursor-com-cha-a75d36c7|CLI Improvements and Mermaid ASCII Diagrams]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> Mermaid code blocks now render inline as ASCII diagrams in your CLI conversation. Flowcharts, sequence diagrams, state machines, class diagrams, and ER diagrams can all be displayed directly in the terminal.
>
> Ctrl+O allows you to switch between the rendered diagram and the original mermaid source to see both representations.
>
> Source: https://cursor.com/changelog/cli-feb-18-2026
