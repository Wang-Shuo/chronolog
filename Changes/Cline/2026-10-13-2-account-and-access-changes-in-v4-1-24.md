# 2 Account and Access changes in v4.1.24

**Cline** · 2026-10-13 · [[Themes/account-access|Account and Access]] · Digest · [Official source](https://github.com/cline/cline/releases/tag/v4.1.24) · from [[Releases/Cline/cline-2026-10-13-v4-1-24-github-411804449-05899922|v4.1.24]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> A 404 from a stale or retired model id is no longer shown as a sign-in problem. Cline shows the real error instead of the logged-out card.

> Errors in the Cline output log keep their details. Production builds used to drop them, so a line like "Cline OAuth login failed:" showed no reason.

Source: https://github.com/cline/cline/releases/tag/v4.1.24
