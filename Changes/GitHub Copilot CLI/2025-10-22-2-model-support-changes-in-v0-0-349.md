# 2 Model Support changes in v0.0.349

**GitHub Copilot CLI** · 2025-10-22 · [[Themes/model-support|Model Support]] · Digest · [Official source](https://github.com/github/copilot-cli/releases/tag/v0.0.349) · from [[Releases/GitHub Copilot CLI/github-copilot-cli-2025-10-22-v0-0-349-github-256506800-cc17172c|0.0.349]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> The model can now call multiple tools in parallel. Each tool must be confirmed in advance. This behavior can be disabled with the `--disable-parallel-tools-execution` flag

> Added the temp directory to the paths that the model has access to by default. This can be disabled with the `--disallow-temp-dir` flag (fixes https://github.com/github/copilot-cli/issues/306)

Source: https://github.com/github/copilot-cli/releases/tag/v0.0.349
