<!-- chronolog:begin region="evidence" -->
> **Realtime Director is a new tool for directing live AI video with prompts.** Type a prompt and the video stream updates as it plays, so you can steer scenes in real time instead of waiting on renders.
>
> Prompts are the only input for now. Each new prompt takes over the live stream.
>
> Set a first-frame reference image to control how the stream starts.
>
> Finished videos save to your Assets automatically.
>
> Try it at [krea.ai/realtime-director](https://www.krea.ai/realtime-director), or see the [Realtime guide](https://www.krea.ai/docs/user-guide/features/realtime.md) for how realtime generation works.
