# Krea 3 API sizing and billing updates

**Krea** · 2026-10-27 · [[Themes/pricing-model|Pricing Model]] · Pricing · [Official source](https://www.krea.ai/docs/changelog) · from [[Releases/Krea/krea-2026-10-27-2026-10-27-agent-builds-custom-nodes-gpt-6-1-terra-in-agent-node-195cc82a|Agent builds custom nodes, GPT-6.1 Terra in Agent, Nodes projects shared with your organization, 4K Krea 3 output in the API, personal and service API tokens, API errors reference, searchable Nodes chats, and fixes]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> Every request needs `resolution` or both `width` and `height`. Omitting both returns `Provide resolution or width and height.`
>
> Unsupported fields such as `model`, `steps`, and `fast` return a `422` with `Unrecognized key`.
>
> With `ultra`, the first four reference images cost $0.07 each and any others $0.02 each, whatever their size.
>
> Source: https://www.krea.ai/docs/changelog
