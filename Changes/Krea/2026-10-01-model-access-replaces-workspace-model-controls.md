# Model Access replaces workspace model controls

**Krea** · 2026-10-01 · [[Themes/model-support|Model Support]] · Launch · [Official source](https://www.krea.ai/docs/changelog) · from [[Releases/Krea/krea-2026-10-01-2026-10-01-model-access-moves-to-manage-with-organization-wide-r-c0b68d19|Model Access moves to Manage with organization-wide rules]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> **Choose which models people can use across your whole organization from one page.** Model Access now lives in [Manage](https://www.krea.ai/manage/model-access) and replaces the controls in Workspace Settings. It's available on Business and Enterprise plans.
>
> Set rules for the organization, for each workspace, and for individual members.
>
> Pick **Approved models only** to approve each model before anyone can use it, or **All models except blocked** to make new models available right away.
>
> Blocks override approvals. A workspace can only narrow what the organization allows.
>
> Members can open Model Access to see which models they can use and why a model is blocked.
>
> Source: https://www.krea.ai/docs/changelog
