# Changes for existing model access rules

**Krea** · 2026-10-01 · [[Themes/model-support|Model Support]] · Launch · [Official source](https://www.krea.ai/docs/changelog) · from [[Releases/Krea/krea-2026-10-01-2026-10-01-model-access-moves-to-manage-with-organization-wide-r-c0b68d19|Model Access moves to Manage with organization-wide rules]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> **Your existing rules carried over, and every blocked model stayed blocked.** A few behaviors changed:
>
> Blocks now override member approvals.
>
> Changing default access now keeps member rules.
>
> Switching to **Approved models only** starts with zero approvals.
>
> Downgrading your plan now pauses enforcement until you upgrade.
>
> Some workspaces that let certain members use a blocked model switched to **Approved models only**. Access stayed the same, and new models now need approval in those workspaces.
>
> Source: https://www.krea.ai/docs/changelog
