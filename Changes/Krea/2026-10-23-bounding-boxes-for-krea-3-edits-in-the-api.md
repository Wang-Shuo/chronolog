# Bounding boxes for Krea 3 edits in the API

**Krea** · 2026-10-23 · [[Themes/editor-experience|Editor Experience]] · Launch · [Official source](https://www.krea.ai/docs/changelog) · from [[Releases/Krea/krea-2026-10-23-2026-10-23-bounding-boxes-for-krea-3-edits-in-the-api-and-more-t-9e027604|Bounding boxes for Krea 3 edits in the API, and more time to migrate legacy thinking modes]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> **Pass `regions` to point Krea 3 at specific areas of your reference images.** Each box can carry its own `note`, so you can give different instructions for different parts of an image.
>
> Coordinates run from 0 to 1 as a fraction of image width and height.
>
> Up to 24 regions per request.
>
> Refer to a box with `@label` in your prompt or in another box's note.
>
> `prompt` is optional when at least one box has a note.
>
> Requires `thinking_mode: "high"`.
>
> Source: https://www.krea.ai/docs/changelog
