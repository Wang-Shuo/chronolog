# Krea 3 API in early access

**Krea** · 2026-10-15 · [[Themes/image-generation|Image Generation]] · Launch · [Official source](https://www.krea.ai/docs/changelog) · from [[Releases/Krea/krea-2026-10-15-2026-10-15-krea-3-api-in-early-access-with-zero-data-retention-a-30f7359e|Krea 3 API in early access, with Zero Data Retention and renamed thinking modes]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> **Edit images with plain-language instructions through the API.** Krea 3 is a fast image editing model. Describe what should change and what should stay the same, and Krea 3 returns the edit in seconds. It also handles text-to-image generation.
>
> Combine up to 8 reference images in one request.
>
> Pick the `fast` thinking mode for everyday edits, or `high` for complex, multi-step edits.
>
> Turn on regional edits to change only part of an image and keep the rest pixel-exact. This lets you chain edits without quality loss.
>
> Output at 1K or 2K. Pricing starts at \$0.03 per 1K image.
>
> The API is open to workspaces in the Krea 3 beta. To request access, contact [sales@krea.ai ↗](mailto:sales@krea.ai).
>
> Source: https://www.krea.ai/docs/changelog
