# Seedance Studio

**Krea** · 2026-08-27 · [[Themes/multimodal|Multimodal Input]] · Launch · [Official source](https://www.krea.ai/docs/changelog) · from [[Releases/Krea/krea-2026-08-27-2026-08-27-seedance-studio-for-directing-images-and-video-4ebbf651|Seedance Studio for directing images and video]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> **Camera, Scene, and Color controls** in Video mode — set focal length and aperture, add lens looks, and pick camera movement, scene style, structure, performance, lighting, and color palette from visual tiles that preview on hover.
>
> **Custom looks** — upload a reference image and Studio turns it into editable direction notes, so you can reuse a visual language without attaching the image to every generation.
>
> **Custom color palettes** — extract colors from an image or build a palette from hex values, then apply it as a color grade.
>
> **Annotations** — draw or place comments on a reference or a blank canvas when a prompt alone is not precise enough.
>
> **3D camera control** — build a simple 3D scene, set camera keyframes with position, aim, focal length, timing, and easing, then attach the rendered path as a video reference.
>
> **Project feed** — every result gets an `@` tag you can mention in your next prompt, and you can reuse a result's prompt, model, references, and settings.
>
> Source: https://www.krea.ai/docs/changelog
