<!-- chronolog:begin region="evidence" -->
> **Generate Seedance videos through the Krea API with your Krea API token.** No separate ByteDance key is needed.
>
> Supported models: Seedance 2.5, Seedance 2.0, Seedance 2.0 Fast, and Seedance 2.0 Mini.
>
> Create videos from text, animate an image with `start_image`, or guide generation with image, video, and audio references.
>
> Requests use your workspace's API balance, not app compute.
>
> Source: https://www.krea.ai/docs/changelog
