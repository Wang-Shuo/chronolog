# Wan 3.0

**Krea** · 2026-08-28 · [[Themes/voice|Voice and Audio]] · Launch · [Official source](https://www.krea.ai/docs/changelog) · from [[Releases/Krea/krea-2026-08-28-2026-08-28-wan-3-0-in-the-video-tool-plus-the-veo-2-and-veo-3-su-97dd9c72|Wan 3.0 in the Video tool, plus the Veo 2 and Veo 3 sunset]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> **Alibaba's Wan 3.0 video model is now available in the Video tool and the API.** Generate a clip from a text prompt, animate a start image, or guide the output with reference images, videos, and audio.
>
> Generates at 480p, 720p, or 1080p.
>
> Attach reference media, or set start and end frames. A single job accepts one or the other, not both.
>
> Prompt expansion is on by default and rewrites your prompt for better results. Set `enablePromptExpansion` to `false` in the API to skip it and reduce generation time.
>
> API pricing is $0.075 per second at 480p, $0.15 per second at 720p, and \$0.30 per second at 1080p.
>
> Pick Wan 3.0 in the [Video tool](https://www.krea.ai/video), or see the [Video guide](https://www.krea.ai/docs/user-guide/features/video.md) for how the tool works.
>
> Source: https://www.krea.ai/docs/changelog
