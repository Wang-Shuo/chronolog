# Krea Agent is open on every plan

**Krea** · 2026-09-10 · [[Themes/agent-mode|Agent Mode]] · Launch · [Official source](https://www.krea.ai/docs/changelog) · from [[Releases/Krea/krea-2026-09-10-2026-09-10-krea-agent-is-open-on-every-plan-with-launch-week-fre-c69cf3e5|Krea Agent is open on every plan, with launch-week free credits]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> **Krea Agent is now available to everyone, including Free.** Write a brief and the agent plans the job, picks the models, generates and edits images, video and audio, and files the results in a shared context library. No invitation or access code required.
>
> Open it at [krea.ai/agent](https://www.krea.ai/agent), from the product switcher, in [Slack](https://www.krea.ai/slack), or through [Krea for ChatGPT](https://www.krea.ai/plugins/chatgpt).
>
> Every plan gets the context library, skills and integrations. Paid plans unlock more effort tiers and the ability to pin a specific orchestrating model. Routines and custom agents are on Enterprise.
>
> Generations cost the same compute units they would in the Image or Video tool. There is no separate agent balance.
>
> Source: https://www.krea.ai/docs/changelog
