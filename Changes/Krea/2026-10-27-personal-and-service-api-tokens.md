# Personal and service API tokens

**Krea** · 2026-10-27 · [[Themes/context-window|Context Window]] · Launch · [Official source](https://www.krea.ai/docs/changelog) · from [[Releases/Krea/krea-2026-10-27-2026-10-27-agent-builds-custom-nodes-gpt-6-1-terra-in-agent-node-195cc82a|Agent builds custom nodes, GPT-6.1 Terra in Agent, Nodes projects shared with your organization, 4K Krea 3 output in the API, personal and service API tokens, API errors reference, searchable Nodes chats, and fixes]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> **Create a personal or service API token from [krea.ai/app/api/tokens](https://www.krea.ai/app/api/tokens).**
>
> **Personal tokens** run as you, with your workspace role and your styles. Any member can create one.
>
> **Service tokens** run as a separate service user. Only owners and admins can create them, and they keep working if their creator leaves.
>
> Owners and admins see every token in the workspace, with 30-day spend per service token.
>
> Styles trained in the app aren't available to service tokens unless shared with the workspace.
>
> Source: https://www.krea.ai/docs/changelog
