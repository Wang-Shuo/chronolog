# Turn Agent on or off with Access Controls

**Krea** · 2026-11-04 · [[Themes/agent-mode|Agent Mode]] · Launch · [Official source](https://www.krea.ai/docs/changelog) · from [[Releases/Krea/krea-2026-11-04-2026-11-04-access-controls-with-agent-rules-11bfb83f|Access Controls with Agent rules]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> **Admins on Business and Enterprise plans can now choose who can use Krea Agent.** Set rules for the organization, a workspace, or individual members on the new **Capabilities** tab.
>
> Pick **Everyone except blocked** or **Allowed members only**. An organization block overrides a workspace allow.
>
> A block covers Agent on the web, iOS, Slack, the API, and MCP, plus Ad Studio chat, 3D Studio, and the Nodes agent.
>
> Blocked members see who to contact. API and MCP requests return HTTP 403.
>
> Under **Allowed members only**, allow yourself before you save, or you lose Agent access too.
>
> Source: https://www.krea.ai/docs/changelog
