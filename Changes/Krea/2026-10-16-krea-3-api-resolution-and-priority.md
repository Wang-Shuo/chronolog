# Krea 3 API resolution and priority

**Krea** · 2026-10-16 · [[Themes/apps-integrations|Apps and Integrations]] · Launch · [Official source](https://www.krea.ai/docs/changelog) · from [[Releases/Krea/krea-2026-10-16-2026-10-16-krea-3-becomes-the-default-image-model-an-mcp-balance-e1c97e46|Krea 3 becomes the default image model, an MCP balance check, Topaz Starlight Fast 3, FLUX 3 Video in 2K and 4K, a faster Agent, and Krea 3 API resolution, priority, and an SDK example]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> **Omit `resolution` and the output is 1K.** Send `1K` or `2K`. Lowercase `1k` and `2k` are also accepted. `priority` is `low`, `normal` (the default), or `high`. `low` queues behind other work. Set `width` and `height` together, and do not combine them with `aspect_ratio` or `resolution`. The overview also includes a Node.js example for `@krea-ai/sdk`.
>
> Source: https://www.krea.ai/docs/changelog
