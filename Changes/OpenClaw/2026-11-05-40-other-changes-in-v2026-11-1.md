# 40 other changes in v2026.11.1

**OpenClaw** · 2026-11-05 · Other changes · Digest · [Official source](https://docs.openclaw.ai/releases/2026.11.1) · from [[Releases/OpenClaw/openclaw-2026-11-05-v2026-11-1-7d3de823|v2026.11.1]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> This patch release adds no new features. It fixes accepted messages being refused, failed Doctor inspections reported as successful, and Gateway configuration writes getting stuck.

> Sets private permissions on installer-created directories and eligible Linux service state directories.

> Preserves supported session and composer settings in new-conversation links when opening the Control UI.

> Shortens routine chat restart notices while keeping useful status for interrupted recovery.

> Adds more specific readiness messages when starting the managed Gateway service, such as when the service stays stopped or the health check times out.

> Prevents Doctor from importing altered legacy text with malformed UTF-8, preserves the original bytes for recovery, and continues independent migrations. See state migration recovery .

> Preserves invalid legacy heartbeat hours during Doctor migration and identifies the value to correct before retrying.

> Enables recovery to use a fresh Doctor if migration fails for updates from versions 2026.10.7 through 2026.10.9. You may still need to start the Gateway manually.

> Allows an update to finish with a named channel warning when the Gateway core is verified ready, even if a channel is unavailable.

> Repairs an unsupported Node runtime for services Doctor owns without overwriting unrelated service settings.

> Allows an update to restart a service it stopped after a recoverable Doctor failure, including a suspended Windows task.

> Unblocks later updates by clearing a verified abandoned cancelled update and settling its pending package publication during update repair.

> Recovers conversations from stores split by older relative paths with Doctor. Stop the Gateway before running openclaw doctor --fix for an affected store.

> Reduces rereading of unchanged eligible SQLite databases during updates and Doctor runs.

> Changes recovery guidance for an older Gateway service that cannot read newer configuration to recommend a newer installation or a matching verified backup.

> Reports the resources keeping a Gateway open after successful cleanup and lets it finish shutting down on non-Windows systems when exiting successfully.

> Allows configured trusted proxies to check Gateway startup and readiness without extra headers.

> Adds remote attachment links with their captions to Google Chat messages. Local files and native uploads are not supported by this change.

> Checks the recipient on Synology Chat send receipts, including each part of a split message.

> Prevents Twitch messages aimed at unsupported direct-message targets from going to the default channel.

> Preserves readable text from unsupported Zalo events, and reports when a stopped Nostr account cannot send a pairing notification.

> Preserves the previous copy for recovery if publishing a skill and rolling it back both fail.

> Preserves the address of a page that failed to load in Mac tabs so you can retry, with the error and retry text available in supported languages.

> Delivers eligible missed messages to resumed Claude CLI conversations and prevents earlier background results from replacing a later answer.

> Preserves compatible Codex thread history across turns and can recover an answer after a transient retry without rerunning completed tools.

> Reports a missing original Codex thread when a conversation has saved history instead of silently starting over.

> Waits briefly for confirmation that Codex has picked up a steering message you already sent when a tool is about to interrupt a turn. Unconfirmed messages are not automatically sent again.

> Updates recovery instructions after an output limit or transcript resume to respect your original constraints, use recorded results, and check unknown outcomes before retrying.

> Stops CLI-backed scheduled runs from starting more work after cancellation at the next cancellation check. Work already dispatched may still finish.

> Prevents scheduled-run cleanup from removing an expired parent session while a descendant is still active.

> Keeps computer-use results compatible with independently updated nodes that include cursor coordinates.

> Prevents delayed GitHub publication reports from appearing in a conversation after it has been reset.

> Stops Discord attachment and sticker downloads from inheriting broad browser private-network permissions. If your CDN resolves to a private address, add its hostname to browser.ssrfPolicy.allowedHostnames .

> Blocks ClawHub archive downloads and redirects to private origins outside the configured registry and codeload origins. If your archive is hosted on another private origin, move it to your configured registry or codeload origin.

> Blocks ClickClack cross-origin redirects to private HTTP addresses. Set apiBaseUrl to the final private API origin if your setup relies on one.

> Removes trust in chains relying only on the emSign ECC G3 root from the secret egress proxy. Restart the Gateway to apply the change.

> Reduces work during repeated workspace captures by reusing eligible unchanged file hashes without reopening the files; recently changed files are still checked.

> Recovers available long replies for waiting sessions_send calls and indicates when a reply may have been truncated.

> Preserves the requested absolute working directory for new bridge-owned ACP sessions.

> Keeps unrelated work moving while session transcripts rebuild, and helps interrupted child launches and session recovery finish.

Source: https://docs.openclaw.ai/releases/2026.11.1
