# 3 Search and Browsing changes in v2026.9.4

**OpenClaw** · 2026-09-11 · [[Themes/search-browsing|Search and Browsing]] · Digest · [Official source](https://docs.openclaw.ai/releases/2026.9.4) · from [[Releases/OpenClaw/openclaw-2026-09-11-v2026-9-4-6cdeafb2|v2026.9.4]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> In Settings , removing an earlier list item no longer throws away unfinished text in another item. Correct and save that text before leaving the page, since unfinished drafts are not kept after a reload. Number buttons also stop skipping the first allowed value, and Web search clearly stays off when the person managing OpenClaw has disabled it.

> More labels and help text are translated in Settings, plugin browsing, Files, and cloud-worker controls. Settings also uses available translations when you search for a field, making it easier to find an option in your chosen language.

> Finding something new for your Claw is easier, whether you browse plugins or ask for a recommendation in chat. You can review and set up plugins in the browser, while cloud workers gain ways to reuse project setup, keep a computer ready for your next session, and choose Windows or macOS when your provider supports them.

Source: https://docs.openclaw.ai/releases/2026.9.4
