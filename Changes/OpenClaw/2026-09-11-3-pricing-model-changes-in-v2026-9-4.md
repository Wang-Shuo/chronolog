# 3 Pricing Model changes in v2026.9.4

**OpenClaw** · 2026-09-11 · [[Themes/pricing-model|Pricing Model]] · Digest · [Official source](https://docs.openclaw.ai/releases/2026.9.4) · from [[Releases/OpenClaw/openclaw-2026-09-11-v2026-9-4-6cdeafb2|v2026.9.4]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> New xAI setups use Grok 4.6, as do xAI web search, X search, and code-execution tools when you have not chosen a model for them. Your explicit choices stay in place, but the new tool default can change cost or availability for your account. If an older subscription setup still uses the retired Auto choice, run openclaw doctor --fix or select an available model yourself.

> Ready workers let your next matching session use an already running computer while OpenClaw prepares a replacement. Eligible Linux projects get one spare per project and profile by default, with a shared limit of four. These computers cost money until deletion is confirmed. Set a profile's Ready workers value to zero to disable its spares, or the shared Prepared pool limit to zero to remove unused spares without stopping active sessions.

> Prepared capacity trades waiting for ongoing cost. Conceptual illustration, not a screenshot. Workers cost money until deletion is confirmed. Removing unused spares does not stop active sessions.

Source: https://docs.openclaw.ai/releases/2026.9.4
