<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Preserves empty or inherited group allowlists during Doctor repair and avoids unnecessary configuration conflicts when only plugin migration guidance changes.

> Preserves configured secret references for eligible default Slack, Mattermost, Nextcloud Talk and Zalo accounts alongside named accounts.

> Applies current tool permissions and grants to configured MCP tools in managed Claude CLI turns .

> Avoids repeatedly copying installed managed native plugin binaries during Gateway startup.

> Adds startup repair for managed plugin links after an external reinstall.
