# 8 other changes in v2026.10.5

**OpenClaw** · 2026-10-18 · Other changes · Digest · [Official source](https://docs.openclaw.ai/releases/2026.10.5) · from [[Releases/OpenClaw/openclaw-2026-10-18-v2026-10-5-fdda4c73|v2026.10.5]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Skill Workshop lets you review how a learned skill has changed and use Undo to restore an earlier version. Its library brings editing, version comparisons, and archive/restore into the same place, so you can inspect and revise the procedures your assistant learns.

> A published conversation now opens at its normal chat address. Anyone with the link can read the transcript without signing in; signed-in readers use the same link with their existing permissions.

> Recovery fixes help interrupted chats resume after restart and return delegated results to the parent conversation. Stop also reaches a request's running commands and queued follow-ups, while long chats need less repeated preparation before replies and searches.

> The first import of an old Telegram message queue skips entries older than 24 hours, including unprocessed ones. Review anything you still need before importing.

> Installers and updates recover through more interrupted handoffs, while Doctor and Gateway startup give clearer recovery steps when preparation fails. Scheduled workspace cleanup no longer stops unexpectedly on paired nodes.

> Downgrading across SQLite schema 24 → 25 requires the matching pre-upgrade backup; restoring it loses later writes. Preserve the original data and follow Doctor's intermediate-upgrade guidance for retired state formats.

> Existing Kubernetes deployments with a read-only root need a writable cache when updating the image. See the container setup guidance .

> Approval and delivery fixes keep delayed requests tied to the person and conversation that started them. More diagnostic output masks credentials, and graphical pairing keeps them out of launcher arguments.

Source: https://docs.openclaw.ai/releases/2026.10.5
