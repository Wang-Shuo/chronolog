# 4 Automation and Scheduling changes in v2026.10.10

**OpenClaw** · 2026-11-03 · [[Themes/automation-scheduling|Automation and Scheduling]] · Digest · [Official source](https://docs.openclaw.ai/releases/2026.10.10) · from [[Releases/OpenClaw/openclaw-2026-11-03-v2026-10-10-c26ff355|v2026.10.10]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Open an older run directly from automation history, or search delivery error text to find a failed run.

> Automation history now returns distinct run IDs for scheduled and on-exit runs whose IDs were missing from history responses.

> Automation history and alerts now distinguish a job that ran from a result that could not be delivered. If a one-time job fails and will not run again, the notice tells you to use Run Now or reschedule it.

> Paused or failure-disabled Dreaming jobs now stay stopped during routine recovery, and an empty diary sweep writes no entry. To resume a stopped job, run openclaw cron enable \<job-id> .

Source: https://docs.openclaw.ai/releases/2026.10.10
