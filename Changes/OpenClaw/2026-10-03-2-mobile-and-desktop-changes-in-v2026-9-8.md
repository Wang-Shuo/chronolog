# 2 Mobile and Desktop changes in v2026.9.8

**OpenClaw** · 2026-10-03 · [[Themes/mobile-desktop|Mobile and Desktop]] · Digest · [Official source](https://docs.openclaw.ai/releases/2026.9.8) · from [[Releases/OpenClaw/openclaw-2026-10-03-v2026-9-8-0844d8d3|v2026.9.8]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Update recovery. Repairing an update now keeps the plugins you allowed and enabled. A fresh Doctor run can finish pending upgrade confirmations and clear warnings for completed work. For Windows 2026.9.4 recovery, back up first and follow the separate-terminal recovery instructions , using the original service account and installation settings. #162959 , backported by @RomneyDa , with work by @VACInc , @obviyus and @ericcaiwx-star .

> macOS updates. Updating through npm now handles two different paths to the same installation, including the moment when npm has removed the old files but not yet replaced them. #163481 , backporting #163479 , with work by @vincentkoc .

Source: https://docs.openclaw.ai/releases/2026.9.8
