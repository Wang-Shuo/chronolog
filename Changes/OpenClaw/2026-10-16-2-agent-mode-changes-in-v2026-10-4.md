# 2 Agent Mode changes in v2026.10.4

**OpenClaw** · 2026-10-16 · [[Themes/agent-mode|Agent Mode]] · Digest · [Official source](https://docs.openclaw.ai/releases/2026.10.4) · from [[Releases/OpenClaw/openclaw-2026-10-16-v2026-10-4-c8c204e0|v2026.10.4]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Tlon group-DM permissions. Unverified group-DM author claims no longer gain owner commands, approval/admin actions or elevated tool permissions. A group member can still pose as an allowed sender to chat with the agent, and replies go to the impersonated sender's private conversation. After approving a pending DM saved before updating, ask the sender to resend it .

> Agent messages and follow-ups. Fixed a launch failure that could stop a message to another agent or a subagent follow-up before it produced a reply.

Source: https://docs.openclaw.ai/releases/2026.10.4
