**OpenClaw** · 2026-10-12 · [[Themes/developer-workflow|Developer Workflow]] · Digest · [Official source](https://docs.openclaw.ai/releases/2026.10.2) · from [[Releases/OpenClaw/openclaw-2026-10-12-v2026-10-2-9abf70fc|v2026.10.2]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Code Mode tasks. Long Code Mode tasks can keep using tools when a model reuses an earlier request number. Node-command errors also explain how to run a shell command on the intended computer. #165210 , thanks to @steipete .

> Rosetta worktree and process checks. Intel OpenClaw running under Rosetta on Apple silicon uses Git for worktrees and avoids the crashing native process check. Maintenance that needs that process inspection still requires native arm64 Node. #165088 , thanks to @steipete .
