# 5 Interface Experience changes in v2026.9.4

**OpenClaw** · 2026-09-11 · [[Themes/interface-experience|Interface Experience]] · Digest · [Official source](https://docs.openclaw.ai/releases/2026.9.4) · from [[Releases/OpenClaw/openclaw-2026-09-11-v2026-9-4-6cdeafb2|v2026.9.4]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Mac installation no longer gets stuck in the affected Homebrew Bash setups, and people building their own Docker image can get past the missing-file error that stopped installation. Linux instructions now explain which user account should run OpenClaw so it finds the right settings, while installation help makes clear when it will start or restart the background service. For people who manage their own terminal settings, supported command-completion entries are also preserved instead of being added again.

> Searching for appearance narrows navigation to the real theme and accent controls. Published 2026.9.4 interface with fictional Harbor data; no live task execution.

> The mention picker keeps suggestions available while you refine a search, making it easier to choose someone for a shared chat. Agent pictures now load in the picker and Settings on token-protected connections, and changing an agent's name or emoji updates an open chat without losing your draft.

> Opening the command palette no longer blurs the conversation behind it, so you can refer to a message while choosing an action. Copying a reply gives a compact green check, GitHub links avoid empty preview popups, and the first reply no longer triggers confetti. On Mac, use Command+B, Command+F, and Command+K for the sidebar, conversation search, and command palette; the Control versions are left for text editing. Windows and Linux keep Control for these shortcuts.

> Search and the sidebar show which conversation is busy, and a failed refresh keeps the conversations you already loaded. On folding phones, model settings and background tasks stay clear of the fold.

Source: https://docs.openclaw.ai/releases/2026.9.4
