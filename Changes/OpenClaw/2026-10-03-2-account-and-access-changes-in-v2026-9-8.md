# 2 Account and Access changes in v2026.9.8

**OpenClaw** · 2026-10-03 · [[Themes/account-access|Account and Access]] · Digest · [Official source](https://docs.openclaw.ai/releases/2026.9.8) · from [[Releases/OpenClaw/openclaw-2026-10-03-v2026-9-8-0844d8d3|v2026.9.8]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Changing connection settings. Work already underway can finish when you change connection settings , provided the user still has access. Removing access still stops that work. Changing the sign-in method or how OpenClaw listens for connections still needs a restart; see the proxy setup guidance . #163174 , backported by @RomneyDa from #160909 .

> Desktop app access. If you use Codex Computer Use with an API key, checking access to desktop apps no longer stops to ask for an unrelated browser sign-in. Controlling the browser still requires its own sign-in. Sources and credits .

Source: https://docs.openclaw.ai/releases/2026.9.8
