# 32 other changes in v2026.10.8

**OpenClaw** · 2026-10-27 · Other changes · Digest · [Official source](https://docs.openclaw.ai/releases/2026.10.8) · from [[Releases/OpenClaw/openclaw-2026-10-27-v2026-10-8-9d674f40|v2026.10.8]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> This is a patch release with no new features. It fixes problems that could stop OpenClaw from installing, updating, starting or delivering replies, alongside smaller app, channel and provider fixes.

> Deleting several conversations in the Control UI no longer repeatedly starts the same background archive process.

> Chat recovery notices no longer say a Gateway restart interrupted a turn when another cause is possible.

> Future updates can finish when OpenClaw itself passes verification but a channel is offline, with a warning for the affected channel.

> Standalone Doctor starts cancelling prolonged original-state capture after ten minutes and gives Gateway status and start commands if restoration fails. Work already underway may take longer to settle.

> Feishu quick-action and confirmation cards can be delivered with their buttons again.

> Feishu streaming cards can keep the text written before a tool call when the answer continues afterward.

> Deeply nested Tlon messages no longer hold up later group messages and DMs. Excessively nested text can be truncated, and events too deeply nested to store are dropped rather than replayed.

> Tlon can reconnect after a silent stream interruption and replay unacknowledged messages.

> iMessage now attempts to recover a stalled Messages bridge after a send times out. The failed send is not automatically retried, so check delivery before resending.

> An unexpectedly stopped channel can restart even if its previous run is cancelled while waiting to retry.

> Twitch replies now resolve supported channel address forms to the intended channel.

> Zalo can process text retained in unsupported incoming events, including URL previews. Events without usable text need to be resent.

> Ordinary Matrix room messages now follow the configured reply visibility and silence policies.

> Google Chat now delivers remote attachments as web links, including replies containing only media. This does not add local-file or native attachment uploads.

> A channel image that was temporarily unreadable can be retried on a later conversation turn once it becomes readable. Images already marked permanently suppressed are not repaired.

> X accounts with capitalized configuration keys can be selected and managed in the Control UI, including their allowlists and guest settings.

> GPT-Live Talk sessions can deliver speech or transcripts when the provider responds before microphone input, instead of closing at startup.

> Session titles can complete on affected custom Zhipu and Z.AI GLM endpoints that reject a request to turn thinking off. Title failures also produce a clearer warning.

> Rate-limited profiles now follow the provider's retry timing instead of accumulating long local lockouts. A rate limit without retry timing leaves the profile available for the next turn.

> Native Codex turns no longer receive a false stall interruption while a host tool call or output handling is still in progress.

> Stopping the first Claude CLI chat turn can preserve its native conversation for the next turn when its transcript has been saved.

> Codex now gives submitted follow-ups and child results a short chance to be acknowledged before a tool ends the turn, reducing uncertain delivery. Unconfirmed input is not replayed automatically.

> An accepted heartbeat response now ends its tool turn instead of continuing into duplicate calls or a timeout.

> A disconnected FaceTime call releases the bridge so another authorized call can come through without restarting the Gateway.

> Codex parent conversations can resume after all native children finish, including their follow-ups, even while their results await delivery.

> A Codex parent conversation can continue after an interrupted native child stops, without discarding the resumable assignment.

> Tailscale Serve and Funnel access can recover automatically after the managed route is lost, including after a Tailscale restart.

> Delayed sessions_send replies can recover the full available answer instead of silently delivering only a preview. If the full answer is unavailable, the preview includes guidance for getting the rest.

> A new human message can continue an eligible interrupted child session after a Gateway restart. The interrupted task is not automatically replayed.

> Conversations blocked by a stale restart-recovery source can accept new messages without a reset, while retaining their history and showing an interruption notice.

> A stopped conversation blocked by an orphaned restart-recovery record can accept another message without losing its transcript.

Source: https://docs.openclaw.ai/releases/2026.10.8
