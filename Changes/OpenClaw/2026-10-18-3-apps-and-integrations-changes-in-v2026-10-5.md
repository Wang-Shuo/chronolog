# 3 Apps and Integrations changes in v2026.10.5

**OpenClaw** · 2026-10-18 · [[Themes/apps-integrations|Apps and Integrations]] · Digest · [Official source](https://docs.openclaw.ai/releases/2026.10.5) · from [[Releases/OpenClaw/openclaw-2026-10-18-v2026-10-5-fdda4c73|v2026.10.5]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Replies, media, progress cards, and queued follow-ups reach the right Slack, Telegram, Discord, and other conversations through more reconnects and handoffs. Phone-call tasks can carry a brief, accept instructions during the call, and return an outcome report.

> Plugin reloads and connection fixes help tools and external coding agents keep working as settings change. Skills marked for macOS also appear in new sessions on compatible Macs.

> Plugin authors need to replace the deprecated session-header link helper before January 12, 2027 , and migrate temporary private SDK imports before January 15, 2027 . See the SDK migration guidance .

Source: https://docs.openclaw.ai/releases/2026.10.5
