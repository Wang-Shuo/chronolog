<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> GPT-6.1 Sol. Support for GPT-6.1 Sol was still incomplete in this release. These changes prepared for it. #161400 , #163132 , backported by @RomneyDa .

> Local models on Windows. When required Microsoft files are missing, managed llama.cpp setup can add them beside your local model server so it can start. If startup still fails, rerun setup or configure a compatible server manually. #163093 and its backport #163128 , both by @RomneyDa .
