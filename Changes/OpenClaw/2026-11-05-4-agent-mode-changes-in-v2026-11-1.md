# 4 Agent Mode changes in v2026.11.1

**OpenClaw** · 2026-11-05 · [[Themes/agent-mode|Agent Mode]] · Digest · [Official source](https://docs.openclaw.ai/releases/2026.11.1) · from [[Releases/OpenClaw/openclaw-2026-11-05-v2026-11-1-7d3de823|v2026.11.1]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Waits for your allowed agents to load in Android Chat and reports when none can be found.

> Restores Claude CLI Agent and Workflow tools for eligible managed turns when explicitly enabled. They remain off by default and unavailable in restricted, delegated, workspace-only or explicitly capped runs.

> Adds GitHub reconnect guidance that can direct you to the current agent’s Tools settings in a supported Control UI session when tool policy allows it. Otherwise it gives you manual settings guidance. You still authorize the connection yourself.

> Includes linked Codex or Agents API connections when preparing to delete conversations with no saved messages.

Source: https://docs.openclaw.ai/releases/2026.11.1
