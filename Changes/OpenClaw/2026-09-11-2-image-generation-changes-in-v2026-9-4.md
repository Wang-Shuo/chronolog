# 2 Image Generation changes in v2026.9.4

**OpenClaw** · 2026-09-11 · [[Themes/image-generation|Image Generation]] · Digest · [Official source](https://docs.openclaw.ai/releases/2026.9.4) · from [[Releases/OpenClaw/openclaw-2026-09-11-v2026-9-4-6cdeafb2|v2026.9.4]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> You can generate and edit images with GPT Image 2.5 Flare or Sunburst through OpenAI or fal, including custom sizes, higher quality settings, and transparent PNG or WebP output. Edits can use up to five reference images through OpenAI or sixteen through fal, and either route can return up to four images.

> GPT Image 2.5 Flare and Sunburst generation or editing. Conceptual illustration, not a screenshot. Either route can return up to 4 images. Default stays unchanged; no generated provider output is shown.

Source: https://docs.openclaw.ai/releases/2026.9.4
