# 4 Memory and Personalization changes in v2026.10.8

**OpenClaw** · 2026-10-27 · [[Themes/memory|Memory and Personalization]] · Digest · [Official source](https://docs.openclaw.ai/releases/2026.10.8) · from [[Releases/OpenClaw/openclaw-2026-10-27-v2026-10-8-9d674f40|v2026.10.8]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Doctor uses less retained memory while checking large fleets of agents.

> Doctor preserves specific recovery errors for agents affected by a missing deletion journal, and can continue other repairs when a memory-index import is deferred.

> The background session-archive process now releases its memory after five idle minutes and starts again when needed.

> Memory Wiki now preserves your handwritten Notes when an imported OKF concept disappears from a later import.
