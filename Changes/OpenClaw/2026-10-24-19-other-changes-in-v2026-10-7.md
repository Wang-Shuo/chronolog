# 19 other changes in v2026.10.7

**OpenClaw** · 2026-10-24 · Other changes · Digest · [Official source](https://docs.openclaw.ai/releases/2026.10.7) · from [[Releases/OpenClaw/openclaw-2026-10-24-v2026-10-7-78f358d7|v2026.10.7]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Doctor avoids unnecessary archive work when repairing many empty sessions and protects a transcript that received new content after the repair began.

> On Linux and FreeBSD, updates now identify a missing pacman or pkg executable and can continue the npm update path without telling you to repair a package database that is not there.

> An update rehearsal no longer tells you a LAN-bound Gateway is limited to loopback because of the rehearsal's temporary settings.

> Package updates made with this repaired updater keep database snapshots promised for manual recovery when Doctor later refuses automatic restoration.

> A settled Doctor repair no longer repeats the same legacy checks and notices after its initial inspection.

> Restoring a backup now retains supported older exec approval rules instead of replacing them with deny-all rules. Malformed rules remain denied.

> Package update reports now separate a completed activation from later maintenance warnings, and an eligible interrupted publication can finish before another update starts.

> R2 backup verification and restore now resume downloads after a retryable interruption instead of starting that download over.

> Post-activation Doctor now stops at its supplied time allowance instead of leaving an update waiting indefinitely.

> Claude CLI no longer delivers text rejected by a Stop hook when the final reply is rewritten or suppressed, including after tool use.

> Linux saved Gateway dashboards now keep their pairing when you switch between them or restart. Removing an address and saving it again starts a fresh pairing.

> Scheduled announcement wakes targeting an existing CLI chat now keep that chat's native conversation.

> Scheduled-job history cleanup no longer loads every saved result before deciding which runs need attention.

> Native computer control now recovers when a control session expires during use.

> An authorized reset can restore a Main session archived by restart recovery while keeping its session identity and transcript. The interrupted task is not replayed.

> After a delegated turn fails to recover from a restart, its conversation can accept a fresh authenticated message once no pending reply or run still owns the work.

> Independent database readers and borrowers now continue when another caller's database access is refused.

> Gateway shutdown now drains retained worker tunnels and workspace transfers even when the worker inventory has already retired.

> After you stop a conversation, a later message can continue in the same session even if old recovery records remain.

Source: https://docs.openclaw.ai/releases/2026.10.7
