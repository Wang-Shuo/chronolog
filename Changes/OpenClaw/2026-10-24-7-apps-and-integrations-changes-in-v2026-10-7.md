# 7 Apps and Integrations changes in v2026.10.7

**OpenClaw** · 2026-10-24 · [[Themes/apps-integrations|Apps and Integrations]] · Digest · [Official source](https://docs.openclaw.ai/releases/2026.10.7) · from [[Releases/OpenClaw/openclaw-2026-10-24-v2026-10-7-78f358d7|v2026.10.7]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Completed updates no longer repeat settled plugin migration warnings or tell you to wait for an update that has already finished.

> Doctor can finish a verified session import and plugin repair when an older retained import file is missing. It still warns you that the missing history cannot be recovered.

> Windows updates now handle both long and 8.3 short paths for plugins, so plugin capture works when Windows reports either form.

> Replies queued before a plugin reload can now use the current provider when they run, so follow-up and collected messages are delivered.

> Managed Claude CLI conversations now keep the parent's working context when child agents finish, with OpenClaw-configured MCP tools still available.

> Claude CLI now lists and calls MCP tools under the current access rules, and refuses calls made with an outdated grant.

> External TypeScript plugins now start without repeatedly resolving local .js imports that point to .ts helpers.

Source: https://docs.openclaw.ai/releases/2026.10.7
