## Changes in this digest

> The macOS Connection view now shows the connected Gateway version and offers an update or repair when needed, without offering a downgrade for a healthy newer Gateway.

> macOS Talk now speaks the complete reply from an accepted agent run even when a slow local model takes longer than the old app-side response window.
