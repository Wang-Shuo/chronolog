# 4 Context Window changes in v2026.10.6

**OpenClaw** · 2026-10-22 · [[Themes/context-window|Context Window]] · Digest · [Official source](https://docs.openclaw.ai/releases/2026.10.6) · from [[Releases/OpenClaw/openclaw-2026-10-22-v2026-10-6-56379f53|v2026.10.6]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> When automatic compaction fails, you now see the actual problem instead of outdated advice to reset the conversation.

> Older LM Studio context-limit errors now trigger the automatic compact-and-retry.

> Rate-limit retries now keep the conversation history needed to reuse the provider’s prompt cache, so you don’t pay for the same input again.

> Codex can now start answering after a context refresh while earlier background work is still finishing.

Source: https://docs.openclaw.ai/releases/2026.10.6
