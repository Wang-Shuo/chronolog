# 3 Editor Experience changes in v2026.10.10

**OpenClaw** · 2026-11-03 · [[Themes/editor-experience|Editor Experience]] · Digest · [Official source](https://docs.openclaw.ai/releases/2026.10.10) · from [[Releases/OpenClaw/openclaw-2026-11-03-v2026-10-10-c26ff355|v2026.10.10]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> A helper can tell you it finished without waiting for its token count; the completion report marks missing usage as unknown.

> Installed skills pick up external edits on refresh, keep more icons and homepages, and can retry safe reads after a paired computer briefly disconnects. If a skills directory has an unreadable or broken ignore file, it is skipped with a warning until you repair that file.

> Updates and rollback now leave more unrelated settings and checkout edits alone when a later step fails.

Source: https://docs.openclaw.ai/releases/2026.10.10
