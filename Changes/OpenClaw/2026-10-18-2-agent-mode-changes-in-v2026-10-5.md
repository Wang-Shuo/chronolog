# 2 Agent Mode changes in v2026.10.5

**OpenClaw** · 2026-10-18 · [[Themes/agent-mode|Agent Mode]] · Digest · [Official source](https://docs.openclaw.ai/releases/2026.10.5) · from [[Releases/OpenClaw/openclaw-2026-10-18-v2026-10-5-fdda4c73|v2026.10.5]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> The sidebar brings larger agent lists into readable rows, with search and pinning to keep the agents you use within reach. Subagents and Processes panels sit beside the parent conversation, so you can check delegated work, inspect recent command output, or stop a task without losing your place.

> Browser previews keep refreshing through more input activity, and ordinary tabs stay usable alongside extension pages. Cleanup leaves other agents' tabs alone, while desktop-tool discovery waits to start its helper until it is needed.
