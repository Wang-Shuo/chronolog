# 2 Memory and Personalization changes in v2026.10.7

**OpenClaw** · 2026-10-24 · [[Themes/memory|Memory and Personalization]] · Digest · [Official source](https://docs.openclaw.ai/releases/2026.10.7) · from [[Releases/OpenClaw/openclaw-2026-10-24-v2026-10-7-78f358d7|v2026.10.7]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Re-importing a Memory Wiki OKF bundle now preserves handwritten Notes inside its marked human Notes block. Handwritten text on older pages outside that block can still be replaced.

> Managed Claude CLI turns now use OpenClaw's tool surface. After upgrading, they stop loading Claude user settings, CLAUDE.md and rules, auto-memory, user hooks and plugins, Chrome, and Claude-only MCP servers. Existing conversations start one fresh native Claude session on their first turn after upgrading.

Source: https://docs.openclaw.ai/releases/2026.10.7
