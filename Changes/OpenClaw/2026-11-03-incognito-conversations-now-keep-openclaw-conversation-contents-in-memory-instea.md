# Incognito conversations now keep OpenClaw conversation contents in memory instead…

**OpenClaw** · 2026-11-03 · [[Themes/reliability-performance|Reliability and Performance]] · [Official source](https://docs.openclaw.ai/releases/2026.10.10) · from [[Releases/OpenClaw/openclaw-2026-11-03-v2026-10-10-c26ff355|v2026.10.10]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> Incognito conversations now keep OpenClaw conversation contents in memory instead of an Incognito database, and usage refresh uses less memory. That history expires within 24 hours or when OpenClaw restarts, whichever comes first; providers, tools, plugins and Codex diagnostics may still retain their own data.
