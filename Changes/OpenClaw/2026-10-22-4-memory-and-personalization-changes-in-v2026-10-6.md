# 4 Memory and Personalization changes in v2026.10.6

**OpenClaw** · 2026-10-22 · [[Themes/memory|Memory and Personalization]] · Digest · [Official source](https://docs.openclaw.ai/releases/2026.10.6) · from [[Releases/OpenClaw/openclaw-2026-10-22-v2026-10-6-56379f53|v2026.10.6]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Turning off the Control UI now frees its files from the Gateway’s memory. Requests already in progress can still finish.

> Memory Wiki no longer changes notes that aren’t valid UTF-8 when rewriting, pruning, or importing bundles. To process one, back up the original, convert a copy to UTF-8, and retry. Other readable notes are still processed.

> Memory Wiki status is faster for large vaults because it skips summary work it doesn’t need.

> Doctor now explains why memory indexing stopped when neither your main nor your backup embedding provider works.

Source: https://docs.openclaw.ai/releases/2026.10.6
