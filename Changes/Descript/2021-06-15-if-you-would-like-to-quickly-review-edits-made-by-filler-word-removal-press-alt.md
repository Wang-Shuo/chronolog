# Review and Restore Edit Boundaries

**Descript** · 2021-06-15 · [[Themes/voice|Voice and Audio]] · [Official source](https://feedback.descript.com/changelog/review-and-restore-edit-boundaries) · from [[Releases/Descript/descript-2021-06-15-6390c9a94a4a0d64fa5642dc-6181617c|Review and Restore Edit Boundaries]]

<!-- chronolog:begin region="evidence" -->
> If you would like to quickly review edits made by Filler Word removal, press Alt + D (Windows) / Option + D (MacOS) to move the playhead to the next clip and preview the edit. If you'd like to restore a particular edit to the way it was, press Alt + R (Windows) / Option + R (MacOS) and the deleted audio will be restored.
>
