# General Updates

**Descript** · 2023-12-05 · [[Themes/reliability-performance|Reliability and Performance]] · Launch · [Official source](https://feedback.descript.com/changelog/release-version-7821) · from [[Releases/Descript/descript-2023-12-05-656e26a9b35bd6ff6af3afdf-ae239196|Release Version 78.2.1]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> We added a [Correct all](https://help.descript.com/hc/en-us/articles/10119613609229-Correcting-your-transcript) button to the Correct popover modal for a faster way to update all instances of a word in your script. This option is still available from the Find menu as well.
>
> Using the [Add File](https://help.descript.com/hc/en-us/articles/10119645307789-Importing-and-transcribing-media-files) button within a Composition now automatically adds the file to the Script and initiates Transcription. If you add a file directly to the Media Library, using Insert into Script will also initiate transcription on that file.
>
> Source: https://feedback.descript.com/changelog/release-version-7821
