# Move projects to starred folders

**Descript** · 2024-07-16 · [[Themes/interface-experience|Interface Experience]] · Launch · [Official source](https://feedback.descript.com/changelog/release-version-94) · from [[Releases/Descript/descript-2024-07-16-6696a8f5b4bfbbdd0e357e35-249bec50|Release Version 94]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> We’re continuing the trend of incremental improvements to Drive view and Drive view organizational tools. This update adds a new sidebar header for [Starred folders](https://help.descript.com/hc/en-us/articles/10163813948685-Organize-your-drive-workspace-with-folders), and the ability to select Starred folders when moving projects.
>
> A new header has been added to the [Move panel](https://help.descript.com/hc/en-us/articles/10163774129165-Moving-projects-and-folders-on-a-drive), with a section for Starred folders so you can find these folders quickly for bulk or individual project moves.
>
> There is an additional dropdown to filter by Drive.
>
> Note: Starring a folder is now done by clicking the Folder icon in Drive view.
>
> Source: https://feedback.descript.com/changelog/release-version-94
