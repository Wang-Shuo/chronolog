# Auto-detect transcription language

**Descript** · 2025-01-28 · [[Themes/voice|Voice and Audio]] · Launch · [Official source](https://feedback.descript.com/changelog/release-version-107) · from [[Releases/Descript/descript-2025-01-28-67996a6a784b54ba407fc85a-9d4f49f2|Release Version 107]]

<!-- chronolog:begin region="evidence" -->
> Descript now automatically detects and [transcribes](https://help.descript.com/hc/en-us/articles/10249424286477-Automatic-transcription) the correct language of your audio, making it easier to work with content in different languages. When uploading new files, "Auto" is now the default language option in the transcription settings.
>
> Existing users who have already set their preferred transcription language won't be affected by this change. You can still manually select a specific language from the dropdown menu in the transcription settings, or set a specific default language in the general Settings menu.
>
> Source: https://feedback.descript.com/changelog/release-version-107
