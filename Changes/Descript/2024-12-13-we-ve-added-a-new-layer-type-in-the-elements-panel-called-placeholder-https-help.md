# Descript adds a new layer type in the Elements panel called…

**Descript** · 2024-12-13 · [[Themes/file-data|Files and Data]] · [Official source](https://feedback.descript.com/changelog/placeholder-layers-now-in-the-elements-panel) · from [[Releases/Descript/descript-2024-12-13-675c8a4951f7332560d208f4-f792ee86|Placeholder layers now in the Elements panel]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> We’ve added a new layer type in the Elements panel called [Placeholder](https://help.descript.com/hc/en-us/articles/32694053567629-Placeholder-Layers) layers. These layers are designed to be used with the [Replace media](https://help.descript.com/hc/en-us/articles/10165302607757-Canvas-tools) function we added a few weeks back, and are the perfect way to rough in your projects, templates, or layouts until you’re ready to swap in your final video or file.
>
> Like any other layer type, Placeholder layers have customizable properties, including access to opacity, borders, and animations from the Layers panel. It also includes one special property exclusive to the Placeholder layer type: *Placeholder notes*, where you can leave yourself a reminder about what this layer is going to be.
>
> Source: https://feedback.descript.com/changelog/placeholder-layers-now-in-the-elements-panel
