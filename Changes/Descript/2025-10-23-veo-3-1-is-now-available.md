# Veo 3.1 is now available

**Descript** · 2025-10-23 · [[Themes/video-generation|Video Generation]] · Launch · [Official source](https://feedback.descript.com/changelog/release-roundupoctober-23rd-2025) · from [[Releases/Descript/descript-2025-10-23-68faa249aae7b47cd5e72ea1-b70e43a4|Release roundup—October 23rd, 2025]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> We've upgraded to Veo 3.1 and Veo 3.1 [fast], Google's latest [video generation](https://help.descript.com/hc/en-us/articles/38621681243789-Generate-AI-video) models. These replace the previous Veo 3 and Veo 3 [fast] models.
>
> Veo 3.1 maintains the same pricing and capabilities as Veo 3, while delivering improved video quality. All existing generation features work the same way—just with better output quality from the upgraded model.
>
