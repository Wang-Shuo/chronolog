# Replace media on the Canvas toolbar

**Descript** · 2024-11-05 · [[Themes/file-data|Files and Data]] · Launch · [Official source](https://feedback.descript.com/changelog/release-version-102) · from [[Releases/Descript/descript-2024-11-05-672a4fac68acbe93f698bb4b-eff3b53e|Release Version 102]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> There is now an option to Replace media when using the [Canvas toolbar](https://help.descript.com/hc/en-us/articles/10165302607757-Canvas-tools). This is a quick way to swap out a layer, especially when you have a layer that was imported from a layout. You can select from Project files, Backgrounds, Stock Media, and more.
>
> You can also access this option from the right-click menu next on any Layer.
>
