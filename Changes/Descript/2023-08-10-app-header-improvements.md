# App header improvements**

**Descript** · 2023-08-10 · [[Themes/interface-experience|Interface Experience]] · Launch · [Official source](https://feedback.descript.com/changelog/version-70-release) · from [[Releases/Descript/descript-2023-08-10-64c1d8ac5108a209947a7b85-26767a6a|Version 70 Release]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> We’ve moved the [help menu](https://help.descript.com/hc/en-us/articles/10606567978381-Access-the-Help-Center-from-the-app) into the header so it’s no longer blocking your side panel, made it easier to see [who your project is shared with](https://help.descript.com/hc/en-us/articles/10255725180685-Project-access), simplified the [project name & composition menus](https://help.descript.com/hc/en-us/articles/10230989695373-Accessing-compositions-project-files-and-sequences#accessing-compositions), combined [app preferences](https://help.descript.com/hc/en-us/articles/10606771145869-App-settings) with user & drive settings into a single Settings modal, and re-organized the Descript menu to make everything a little easier to find.
>
> **Hiding the side panel:** You can now [show or hide the side panel](https://help.descript.com/hc/en-us/articles/13286878359565-Customize-the-editor#resizing-panels) using the icon from the header, or by using the keyboard shortcut (**Cmd-Shift-D** on macOS, and **Ctrl-Shift-D** on Windows).
>
> Source: https://feedback.descript.com/changelog/version-70-release
