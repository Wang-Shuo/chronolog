# Smart Transitions

**Descript** · 2025-02-11 · [[Themes/interface-experience|Interface Experience]] · Launch · [Official source](https://feedback.descript.com/changelog/release-version-108) · from [[Releases/Descript/descript-2025-02-11-67ab977b354800cdb65c181c-b474aa11|Release Version 108]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> With all the updates to working with Scenes and Layouts, we’ve added a new type of Transition animation that was created to save you mountains of time. [Smart transitions](https://help.descript.com/hc/en-us/articles/34011944399629-Smart-Transitions) apply automatically to all visual layers in a scene, and select appropriate crossfades, zooms, wipes etc. to the Scene transition. This transition effect comes applied automatically to some of our default layout packs, or you can add it manually from the Scene panel on the sidebar.
>
