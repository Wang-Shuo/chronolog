# Update layer order across scenes**

**Descript** · 2023-07-10 · [[Themes/context-window|Context Window]] · [Official source](https://feedback.descript.com/changelog/version-68-release) · from [[Releases/Descript/descript-2023-07-10-64ac412e0a49ed588306f998-b4887a52|Version 68 Release]]

> When you [change the layer order](https://help.descript.com/hc/en-us/articles/10249309329805-Layer-visibility-and-order#adjusting-layer-order-visual-only-) on a layer that spans multiple scenes, the layer order is now updated across all scenes. To do this, select the full layer from the timeline, and then update the layer order from the context menu.
