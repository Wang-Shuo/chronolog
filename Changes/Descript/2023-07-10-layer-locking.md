# Layer locking**

**Descript** · 2023-07-10 · [[Themes/context-window|Context Window]] · Launch · [Official source](https://feedback.descript.com/changelog/version-68-release) · from [[Releases/Descript/descript-2023-07-10-64ac412e0a49ed588306f998-b4887a52|Version 68 Release]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> It’s now easier to work with [Green Screen](https://help.descript.com/hc/en-us/articles/10327693275405-Green-Screen) or [Chroma Keyed layers](https://help.descript.com/hc/en-us/articles/10327650435085-Chroma-key) using layer locking. You can [lock a layer](https://help.descript.com/hc/en-us/articles/17461277756941) from its context menu or by using **Option/Alt-L**. This locks the layer's position and scale, and also prevents it from getting in the way while selecting other layers in the canvas.
>
