# Add layers to a selection with the new “+” button

**Descript** · 2023-09-18 · [[Themes/multimodal|Multimodal Input]] · Launch · [Official source](https://feedback.descript.com/changelog/release-version-73) · from [[Releases/Descript/descript-2023-09-18-65088b3d73cf3a09c09b31e6-b20a11ca|Release Version 73]]

<!-- chronolog:begin region="evidence" -->
> We’ve added a new “+” button to the [selection toolbar](https://help.descript.com/hc/en-us/articles/10164874052237-Selection-toolbar) in the script to make it easier than ever to add layers. Adding layers in video compositions will automatically add [scene boundaries](https://help.descript.com/hc/en-us/articles/10248940392461-Scene-boundaries) to the range if not already present.
