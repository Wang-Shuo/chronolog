# **Timeline reflects layer order**

**Descript** · 2023-05-31 · [[Themes/file-data|Files and Data]] · [Official source](https://feedback.descript.com/changelog/version-65-release) · from [[Releases/Descript/descript-2023-05-31-647676233b52ad094d8a2d93-3440a3c3|Version 65 Release]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> **Timeline reflects layer order**: [Layer order in the timeline](https://help.descript.com/hc/en-us/articles/10249309329805#Layer-order) now generally reflects the order of layers in the canvas, and extending layers across scenes preserves their relative layer orders. *The only thing to watch out for is if you have layers that switch order after the first scene they appear in, the timeline might not show the correct order after that first scene. *You can also expect to be able to re-order layers directly from the timeline soon.
>
> **Properties panel**: There are a number of changes to the [properties panel](https://help.descript.com/hc/en-us/articles/10327905838349-Properties-Panel) that should generally make it easier to work with. Some highlights:
>
> **New sliders**: We combined sliders and text inputs so you can drag or type in the same field more easily.
>
> **Style section for Captions**: [Captions now have a dedicated “Style” section](https://help.descript.com/hc/en-us/articles/10256391944333-Text-and-captions#style) where all customizations can be easily controlled in one place. We have also added the ability to customize borders separately for active and future words, making it easier to selectively add a border to specific text.
>
> **Live text changes**: We’ve removed the Live Text property, and added a single dropdown for text contents at the top of the text properties panel. Now, rather than treating live as a property you enable, we expose all the options for [text contents you can choose](https://help.descript.com/hc/en-us/articles/10256391944333-Text-and-captions#Set-text-layer-content) from this dropdown, including Freeform text, Captions and more.
>
> **Cleaner effects toggle**: Effects now [use a new toggle design](https://help.descript.com/hc/en-us/articles/10327783443213-Applying-and-adjusting-effects#removing-an-effect) that’s even clearer about whether the effect is enabled or not.
>
> Source: https://feedback.descript.com/changelog/version-65-release
