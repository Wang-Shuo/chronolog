# Batch exports now available for Translations

**Descript** · 2025-01-07 · [[Themes/editor-experience|Editor Experience]] · Launch · [Official source](https://feedback.descript.com/changelog/release-version-105) · from [[Releases/Descript/descript-2025-01-07-677d554eb70df614fe452c9a-10738fe7|Release Version 105]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> You can now export all of your [translated](https://help.descript.com/hc/en-us/articles/27177566394509-Translate) compositions in a batch process. We’ve added checkboxes to the Language selection list on the Export tab, so just select all the translated versions you’d like exported, and they’ll be automatically queued up and processed. A great time saver on the path to expanding your audience.
>
> Source: https://feedback.descript.com/changelog/release-version-105
