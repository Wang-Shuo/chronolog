# File upload limits

**Descript** · 2024-07-16 · [[Themes/file-data|Files and Data]] · Launch · [Official source](https://feedback.descript.com/changelog/release-version-94) · from [[Releases/Descript/descript-2024-07-16-6696a8f5b4bfbbdd0e357e35-249bec50|Release Version 94]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> Since we updated our pricing model a few weeks back, we are starting to implement [limit checks](https://help.descript.com/hc/en-us/articles/27841674958221-Understanding-AI-Limitations-Features-and-Usage-Tracking) for some features. Starting in v94, if you try to upload a file that is larger than what your plan allows, you’ll hit this screen with a prompt to upgrade for larger file uploads.
>
> The limits are laid out on our pricing page, but for easy reference, here are the maximum file sizes available at each tier:
>
> Hobbyist: 10GB
>
> Creator: 20GB
>
> Business: 50GB
>
> Note: these limits do not effect users on [Legacy plans](https://help.descript.com/hc/en-us/articles/27653385141517-Understanding-Your-Legacy-Plan).
>
> For full details on plans and pricing, visit our [pricing page](https://www.descript.com/pricing).
>
