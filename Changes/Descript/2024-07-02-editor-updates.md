# Editor updates

**Descript** · 2024-07-02 · [[Themes/editor-experience|Editor Experience]] · Launch · [Official source](https://feedback.descript.com/changelog/release-version-93) · from [[Releases/Descript/descript-2024-07-02-668418cb98cc7426793646c1-467c3990|Release Version 93]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> There’s only one small change within the Editor itself for version 93:
>
> The “Layout” setting (within the Layer settings menu) has been renamed to “Size and Position” to reduce confusion between it and the concept of [Layouts](https://help.descript.com/hc/en-us/articles/10119612485901-Using-layouts), which refer to elements within Templates. You’ll use the [Size and Position](https://help.descript.com/hc/en-us/articles/27197208246797-Layer-Panel) interface to do what it says on the label: adjust the size and position of any Layer within your canvas.
>
> Source: https://feedback.descript.com/changelog/release-version-93
