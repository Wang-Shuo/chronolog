# 8 other changes in Release roundup—October 12, 2026

**Descript** · 2026-10-13 · Other changes · Digest · [Official source](https://feedback.descript.com/changelog/release-roundupoctober-12-2026) · from [[Releases/Descript/descript-2026-10-13-6acd9a3948cc9979847dd5eb-0215acfe|Release roundup—October 12, 2026]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Some files upload fine and then lag or stutter in your project. When Descript spots a problem with a file, it now marks it with a badge. Right-click the file and choose Fix file issue, and Descript repairs it for you.

> When a local export can't find a piece of media, it says so instead of failing with no explanation.

> AAF export keeps clip gain in Pro Tools, no longer hangs on markers with parentheses, and handles media names that differ only in capitalization.

> Copy and paste now keeps your highlights.

> Smart transitions no longer add extra movement after a custom animation, and you can remove them again.

> You can remove the wordless media label from your script again.

> When a project won't load or is slow to load, the message tells you what's going on.

> When a member asks to upgrade, you now see what it costs before you approve.

Source: https://feedback.descript.com/changelog/release-roundupoctober-12-2026
