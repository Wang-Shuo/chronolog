# Instant recording playback

**Descript** · 2025-03-25 · [[Themes/interface-experience|Interface Experience]] · Launch · [Official source](https://feedback.descript.com/changelog/release-version-111) · from [[Releases/Descript/descript-2025-03-25-67e2f0e02b7c9f658ffc55c9-c954b6e3|Release Version 111]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> For users [on the Web](https://help.descript.com/hc/en-us/articles/16987605355277-Descript-for-Web), or the upgraded Desktop app, recordings will now be available for playback instantly when you hit stop. If you're not sure which version of the Desktop app you're using, you can check in the Settings menu under the Labs heading. If you're on the older version of the app, you'll see an option to Upgrade.
>
> There is also a new [Transcription](https://help.descript.com/hc/en-us/articles/10249424286477-Automatic-transcription) UI that appears after recording, which gives you a preview of the your script length with using grey word blocks a placeholders. We’ve also moved the progress meter to a more visible location. We are hoping to bring these updates over to the main Transcription experience when you import files in the near future.
>
> Source: https://feedback.descript.com/changelog/release-version-111
