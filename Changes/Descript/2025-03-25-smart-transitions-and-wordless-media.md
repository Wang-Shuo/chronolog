# Smart transitions, and Wordless media

**Descript** · 2025-03-25 · [[Themes/reliability-performance|Reliability and Performance]] · Launch · [Official source](https://feedback.descript.com/changelog/release-version-111) · from [[Releases/Descript/descript-2025-03-25-67e2f0e02b7c9f658ffc55c9-c954b6e3|Release Version 111]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> [Smart transitions](https://help.descript.com/hc/en-us/articles/34011944399629-Smart-Transitions) are now enabled by default for all scene-to-scene transitions. This feature automatically adds polished animations between your scenes, with improved stability for animated elements during transitions. You can disable this setting in the Settings menu → Advanced section if you prefer to set up transitions manually.
>
> Additionally, [Wordless media](https://help.descript.com/hc/en-us/articles/20391763004301-Wordless-media-in-your-script) is now disabled by default for all new projects. This is because we’ve encountered a larger number of errors caused by or related to Wordless media. While you can still enable this feature in settings, we're actively working on a new and improved version that will address previous issues.
>
> Source: https://feedback.descript.com/changelog/release-version-111
