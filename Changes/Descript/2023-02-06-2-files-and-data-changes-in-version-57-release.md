## Changes in this digest

> Right-clicking at a point in the Canvas with multiple layers reveals a new 'Select layer' dropdown menu to easily select the desired layer in the stack

> Moved [Aspect ratio & video settings](https://help.descript.com/hc/en-us/articles/12920160974477-Aspect-ratio-and-video-settings) from the Script to the top left of the Canvas. If you hover over the Canvas, the button will appear, and you can select Landscape, Square, Portrait, or Advanced.
