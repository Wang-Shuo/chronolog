# 2 Interface Experience changes in Version 17 Release

**Descript** · 2021-06-30 · [[Themes/interface-experience|Interface Experience]] · Digest · [Official source](https://feedback.descript.com/changelog/version-17-release) · from [[Releases/Descript/descript-2021-06-30-6390c9b14a4a0d64fa5643cc-82f9a4de|Version 17 Release]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> The keyboard shortcut for adding markers is now M (or command shift M). This is in anticipation of an upcoming feature allowing you to drop markers while recording.

> We've completed our reorganization of the editor toolbar. The new forward/back links are now in the toolbar instead of the sidebar, so they won't get hidden when the sidebar is collapsed. Project options and the link to return to your Drive view are now under the "D" logo in the upper left. The editor toolbar now also shows the name of the active asset (composition, sequence, or file).

Source: https://feedback.descript.com/changelog/version-17-release
