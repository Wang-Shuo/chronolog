# Descript for Web (Beta) adds Video, Audio, and GIF exports

**Descript** · 2024-01-10 · [[Themes/voice|Voice and Audio]] · Launch · [Official source](https://feedback.descript.com/changelog/release-version-80) · from [[Releases/Descript/descript-2024-01-10-659d7ecd3c8af3aabfb226c7-4effc43f|Release Version 80]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> We’ve enabled the ability to Export Video, Audio, and GIFs to our [Web editor Beta](https://help.descript.com/hc/en-us/articles/16987605355277-Introducing-Descript-for-web). If you haven’t tried the Web version of Descript yet, now’s the perfect time to try it out.
>
> Descript for Web allows you to use Descript’s most powerful features without downloading or installing the app. Because media is streamed, you don’t even need to store or download large files for playback, and users with hardware-based performance issues will likely have a much smoother experience.
>
> We do not always mention updates to currently-in-beta features in the Changelog, but the lack of media file exports has been a blocker for some users.
>
> As with all Beta features, you may encounter bugs or unexpected slowness. Please see our [Help Center](https://help.descript.com/hc/en-us/articles/16987605355277-Introducing-Descript-for-web) for full details and limitations.
>
> Source: https://feedback.descript.com/changelog/release-version-80
