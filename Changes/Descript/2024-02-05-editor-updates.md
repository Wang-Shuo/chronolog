# Editor Updates

**Descript** · 2024-02-05 · [[Themes/editor-experience|Editor Experience]] · Launch · [Official source](https://feedback.descript.com/changelog/release-version-82) · from [[Releases/Descript/descript-2024-02-05-65c137d6d6ef358051aaaf61-fc6df9e1|Release Version 82]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> We’ve added the ability to adjust the volume of Gap Clips with [Room Tone](https://help.descript.com/hc/en-us/articles/10255967999757-Room-tone) in Sequences. This will adjust the volume of all Room Tone clips within the Sequence.
>
> We’ve cleaned up the Speaker menu by removing the redundant text labeling AI speakers under the Add AI speaker to project header
>
> [Highlight colors](https://help.descript.com/hc/en-us/articles/13395324669837-Highlighting-text) have been renamed for simplicity and clarity:
>
> *Sand → Yellow*
>
> *Rose → Red*
>
> *Salmon → Orange*
>
> *Mint → Green*
>
> *Seaglass → Blue*
>
> *Violet → Purple*
>
> Added a Red Dot indicator when a Filter or Sort option is in use within the Media Library.
>
> Replacing a file with Studio Sound enabled will now retain your Intensity setting.
>
> Source: https://feedback.descript.com/changelog/release-version-82
