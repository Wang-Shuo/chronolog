# Housekeeping updates

**Descript** · 2024-03-04 · [[Themes/voice|Voice and Audio]] · Launch · [Official source](https://feedback.descript.com/changelog/release-version-84) · from [[Releases/Descript/descript-2024-03-04-65e60ab1e3ea7de031601850-e6977776|Release Version 84]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> Pasting video into an audio-only composition will ask if you'd like to convert the composition to video. If you intend to keep working in an audio-only state, you can just click the X to dismiss the prompt.
>
> A while back, we added a [Default setting for Publishing privacy](https://help.descript.com/hc/en-us/articles/10255817744653-Publish-content-with-Descript-web-links) to Drive Owner settings. This was defaulted to Public for new Drives. This has been changed so that new Drives will default to “Anyone with Link” also known as **Unlisted**.
>
> Source: https://feedback.descript.com/changelog/release-version-84
