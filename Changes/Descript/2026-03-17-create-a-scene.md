# Create a scene

**Descript** · 2026-03-17 · [[Themes/editor-experience|Editor Experience]] · Launch · [Official source](https://feedback.descript.com/changelog/release-roundupmarch-17th-2026) · from [[Releases/Descript/descript-2026-03-17-69b3257b60b225e10f6a3a28-246aeffc|Release roundup—March 17th, 2026]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> You can now generate media, add layers, and add layouts directly from the [Scene](https://help.descript.com/hc/en-us/articles/10248939749517-Scenes-overview) editor panel when your current scene is blank - the new blank slate for any scene includes helpful a lightweight overlay with three quick actions:
>
> **Generate media**: Opens the media generation panel so you can create an image or video to fill the scene.
>
> **Layout**: Opens the layout picker.
>
> **Layer**: Opens the add layer menu so you can upload or insert your own assets.
>
