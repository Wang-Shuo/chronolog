# **Layer list**: We’ve made a number of improvements to the [layer list…

**Descript** · 2023-08-22 · [[Themes/voice|Voice and Audio]] · [Official source](https://feedback.descript.com/changelog/release-version-71) · from [[Releases/Descript/descript-2023-08-22-64e51d957de238097a7bdd9c-4db80053|Release Version 71]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> **Layer list**: We’ve made a number of improvements to the [layer list in the properties panel](https://help.descript.com/hc/en-us/articles/10249309329805-Layer-visibility-and-order). You can now drag to re-arrange layers, see audio layers in the layer list, rename layers from the context menu, and mute or solo audio layers. We also now show the layer list when there is no selection in audio-only compositions.
>
