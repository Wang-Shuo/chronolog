# Updated shortcut modifier for playback speed changes**

**Descript** · 2023-07-10 · [[Themes/reliability-performance|Reliability and Performance]] · [Official source](https://feedback.descript.com/changelog/version-68-release) · from [[Releases/Descript/descript-2023-07-10-64ac412e0a49ed588306f998-b4887a52|Version 68 Release]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> We’ve updated the modifier key from **Option/Alt** to **Shift**. This better matches conventions from NLEs like Premiere, and frees up **Option-L/Alt-L** for layer locking.
>
> **Shift-J** - Decrease playback speed
>
> **Shift-K** - Reset playback speed
>
> **Shift-L** - Increase playback speed
>
> Source: https://feedback.descript.com/changelog/version-68-release
