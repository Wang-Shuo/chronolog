# Desktop Preview

**Descript** · 2024-07-09 · [[Themes/mobile-desktop|Mobile and Desktop]] · Launch · [Official source](https://feedback.descript.com/changelog/instant-performance-upgrades-with-descript-for-web-and-the-new-desktop-preview) · from [[Releases/Descript/descript-2024-07-09-668c7fa1b6ae080efebb9642-0f9361f0|Instant performance upgrades with Descript for Web and the new Desktop preview]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> We’re excited to announce a new pre-release version of the Descript Desktop app. This new version of our Desktop app brings all the benefits of Descript for Web into a local app package.
>
> [Click here](https://www.descript.com/download/desktop-app-preview) to Download the new Desktop Preview version of Descript, and [here](https://help.descript.com/hc/en-us/articles/10503599253773-Downloading-and-installing-Descript) for installation instructions.
>
> This new version of Descript will eventually replace the Desktop app, and you get started with it today. Say goodbye to “A new version of Descript is ready” prompts - in addition to all the benefits listed above, the new Desktop Preview will rarely require you to restart for updates.
>
> You can have both the regular Desktop app and the new Desktop Preview installed at the same time, and switch back and forth without causing compatibility issues.
>
> For both further information, and all current limitations for Descript for Web, and the Desktop preview, please visit our [Help Center](https://help.descript.com/hc/en-us/articles/16987605355277-Introducing-Descript-for-web).
>
> Source: https://feedback.descript.com/changelog/instant-performance-upgrades-with-descript-for-web-and-the-new-desktop-preview
