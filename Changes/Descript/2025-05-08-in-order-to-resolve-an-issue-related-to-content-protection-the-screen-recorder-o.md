# In order to resolve an issue related to content protection, the Screen recorder…

**Descript** · 2025-05-08 · [[Themes/multimodal|Multimodal Input]] · [Official source](https://feedback.descript.com/changelog/patch-release-11402) · from [[Releases/Descript/descript-2025-05-08-681d2b03beffecbf2187a957-d6019466|Patch Release 114.0.2]]

<!-- chronolog:begin region="evidence" -->
> In order to resolve an issue related to content protection, the Screen recorder on Windows will now show the screen recorder dock. This means that the option to Hide Recorder Dock will not function for the moment. This is a compromise solution as the bug was causing the final video to be blacked out in some cases. We are working on a fix for this in the next version, and apologize for any inconvenience this causes in the meantime.
