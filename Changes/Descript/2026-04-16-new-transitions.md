# New Transitions

**Descript** · 2026-04-16 · [[Themes/reliability-performance|Reliability and Performance]] · Launch · [Official source](https://feedback.descript.com/changelog/release-roundupapril-16th-2026) · from [[Releases/Descript/descript-2026-04-16-69e11a9bcbb8c43b6e38c002-bf103ab2|Release roundup—April 16th, 2026]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> We’ve refreshed the [Transitions](https://help.descript.com/hc/en-us/articles/10255989387661-Transitions) experience to make it faster to find the right look between scenes. Transitions now come with animated previews, and are organized into a new grid layout with thumbnail previews so you can see the effect before you apply it.
>
> **More transition options:** We expanded the library to 16 total transitions, adding:
>
> **Clock Wipe**
>
> **Shape Wipe**
>
> **Double Linear Wipe**
>
> **Move In & Out**
>
> **Push-Pull**
>
> We added a bulk apply option if you want to use the same transition across all scenes at once to quickly add consistent polish. Many of the new transitions come with additional customization controls so be sure to check the advanced settings.
>
> Just click the transition icon between scenes (or use the Properties panel) to open the new transitions panel.
>
> Source: https://feedback.descript.com/changelog/release-roundupapril-16th-2026
