# Simplified Script tools

**Descript** · 2023-10-16 · [[Themes/mobile-desktop|Mobile and Desktop]] · Launch · [Official source](https://feedback.descript.com/changelog/release-version-75) · from [[Releases/Descript/descript-2023-10-16-65243a48ec2dd97343eccd6b-ff9e32b2|Release Version 75]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> We’ve simplified [the Script](https://help.descript.com/hc/en-us/articles/10164874717709-Script-tools) into a single Write-mode which can be toggled on or off using *Command + E* or *Control + E* on Windows. Writing on any new line will automatically enter write mode for a more fluid workflow.
>
> [Correct Text](https://help.descript.com/hc/en-us/articles/10119613609229-Correcting-your-transcript) and Overdub are still quick to access by highlighting the Script and using the Toolbar, and by holding down [C (for correct) or D (for Overdub.)](https://help.descript.com/hc/en-us/articles/10164870880525-Text-correction-keyboard-shortcuts) Correct text mode is still accessible using *Option + C* or *Alt + C* on Windows to Toggle On / Off.
>
> Source: https://feedback.descript.com/changelog/release-version-75
