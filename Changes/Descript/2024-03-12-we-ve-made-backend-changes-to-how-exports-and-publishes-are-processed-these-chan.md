# Descript makes backend changes to how Exports and Publishes are processed

**Descript** · 2024-03-12 · [[Themes/interface-experience|Interface Experience]] · [Official source](https://feedback.descript.com/changelog/more-reliable-exports) · from [[Releases/Descript/descript-2024-03-12-65f0ac54061325f26b26a687-8250fa50|More Reliable Exports]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> We’ve made backend changes to how Exports and Publishes are processed. These changes are designed to greatly improve the reliability of exporting files, and reduce the occurrence of bugs related to:
>
> Skipped frames
>
> A/V sync Issues
>
> This upgrade is especially notable with variable framerate files, which include most screen recordings. With these changes, you should see frame-accurate results between in-app playback and exported files.
>
> **Note:** We have observed that this change does reduce export *speed* in some projects. We are working on improving this, but you may notice an increase in time-to-completion for some exports.
>
> Source: https://feedback.descript.com/changelog/more-reliable-exports
