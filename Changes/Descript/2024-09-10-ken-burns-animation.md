# Ken Burns animation

**Descript** · 2024-09-10 · [[Themes/presentation-creation|Presentation Creation]] · Launch · [Official source](https://feedback.descript.com/changelog/release-version-98) · from [[Releases/Descript/descript-2024-09-10-66e06c5b4399807e3d863d3a-f63d1366|Release Version 98 ]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> That smooth, documentary-style presentation for b-roll and still images is finally here. Put on your PBS hat and add the [Ken Burns animation](https://help.descript.com/hc/en-us/articles/30019934940301-Ken-Burns-Animation) to any visual media for a smooth zoom and pan.
>
> It comes with 8-directional settings and a center zoom option.
>
> A random zoom and pan setting will be selected when you initially apply the effect so you don’t necessarily have to choose them yourself if you just want to quickly spice up your background content.
>
> The zoom/pan can be set to:
>
> *In* - Zooms into the image
>
> *Out* - Zooms out on an image
>
> *None* - Image will only pan, with no zoom effect (this cannot be combined with the center-only zoom setting.)
>
> The Ken Burns effect has 3 speed settings:
>
> *Please note: this effect currently cannot be applied to a Script track, as it's designed specifically for images and b-roll.*
>
> Source: https://feedback.descript.com/changelog/release-version-98
