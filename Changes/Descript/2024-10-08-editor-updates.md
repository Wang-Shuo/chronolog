# Editor Updates**

**Descript** · 2024-10-08 · [[Themes/editor-experience|Editor Experience]] · Launch · [Official source](https://feedback.descript.com/changelog/release-version-100) · from [[Releases/Descript/descript-2024-10-08-670564dc958faa93e6166a33-dd601db4|Release Version 100]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> [Automatic multicam](https://help.descript.com/hc/en-us/articles/28736507904525-Automatic-multicam) has received major speed improvements, generating much faster. We have also removed the blocking modal and moved the progress indicator back to the sidebar.
>
> Preview playback for [stock media](https://help.descript.com/hc/en-us/articles/10165831753997-Stock-media) will now stop after you add it to a composition.
>
> File [conversion processes](https://help.descript.com/hc/en-us/articles/10165828232205-Project-file-actions) (Repair audio drift, split to mono, convert to mono, and normalize audio) are now available on the Web and Desktop preview versions of Descript.
>
> We’ve added some highlights and shading to sidebar options to help ease of use and clarity.
>
> Source: https://feedback.descript.com/changelog/release-version-100
