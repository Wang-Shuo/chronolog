# 7 other changes in Version 21 Release

**Descript** · 2021-08-24 · Other changes · Digest · [Official source](https://feedback.descript.com/changelog/version-21-release) · from [[Releases/Descript/descript-2021-08-24-6390c9bd4a4a0d64fa56454c-6699b120|Version 21 Release]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> We've removed the 7-day free trial on Pro accounts

> We've improved timeline vertical resizing behavior

> We've improved clip dragging behavior in the timeline. Clips no longer snap to the beginning, and multi-clip dragging preserves the pin offset

> [Studio Sound](https://help.descript.com/hc/en-us/articles/4405856365709-Studio-Sound-beta-) is now available in Early Access for all users, regardless of whether they signed up for the beta

> Studio Sound can now be used on files that were added to Descript prior to Studio Sound's launch

> When hovering over a clip, the thumbnail fades out

> Changed the home/end keyboard shortcuts to only navigate to the beginning / end of a composition when the timeline is active

Source: https://feedback.descript.com/changelog/version-21-release
