# Media Library files now transcribe automatically

**Descript** · 2026-03-17 · [[Themes/voice|Voice and Audio]] · Launch · [Official source](https://feedback.descript.com/changelog/release-roundupmarch-17th-2026) · from [[Releases/Descript/descript-2026-03-17-69b3257b60b225e10f6a3a28-246aeffc|Release roundup—March 17th, 2026]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> When you upload audio or video to your Drive [Media Library](https://help.descript.com/hc/en-us/articles/43448763539213-Media-Library-organize-and-reuse-content-across-projects), Descript will now transcribe the file automatically.
>
> Transcripts are saved with the Media Library file, so they can carry over when you reuse that file.
>
> You are **not charged additional media minutes** when you add an already-uploaded Media Library file to a project.
>
> Source: https://feedback.descript.com/changelog/release-roundupmarch-17th-2026
