# Improved loading state for translation

**Descript** · 2025-11-21 · [[Themes/interface-experience|Interface Experience]] · [Official source](https://feedback.descript.com/changelog/release-roundupnovember-21st-2025) · from [[Releases/Descript/descript-2025-11-21-691f93d1f2015b6143a936e6-495dc9d9|Release roundup—November 21st, 2025]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> When you translate a video with [dubbing](https://help.descript.com/hc/en-us/articles/37194900295821-Dub-speech-to-add-translated-voiceover), you'll now see a progress indicator in the sidebar that shows which translations are currently processing. You’ll also see indicators above each section as it’s being translated in real time.
>
> The updated loading state makes it easier to track multiple translations at once and gives you a better sense of how long the process will take.
>
> Source: https://feedback.descript.com/changelog/release-roundupnovember-21st-2025
