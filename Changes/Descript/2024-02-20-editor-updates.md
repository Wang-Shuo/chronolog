# Editor Updates

**Descript** · 2024-02-20 · [[Themes/editor-experience|Editor Experience]] · Launch · [Official source](https://feedback.descript.com/changelog/release-version-83) · from [[Releases/Descript/descript-2024-02-20-65d4eab1ad5d54d52ed3c0fa-c2fa414f|Release Version 83]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> Text layers can now have different properties between Scenes, so you can use a different font or styling between sections of your project. When you select a full layer with multiple properties, you’ll see the word Mixed in the Font and Style section, and you can select any scene to see its scene-specific properties.
>
> You can select the properties for a layer within an individual scene by clicking the layer in the Canvas during the desired scene.
>
> This update pairs well with the recent launch of the Timeline Redesign available with [Descript Labs](https://help.descript.com/hc/en-us/articles/23515226920973-Preview-upcoming-features-with-Descript-Labs), which improves the visual clarity of the Timeline.
>
> Source: https://feedback.descript.com/changelog/release-version-83
