# Additional editor updates

**Descript** · 2024-09-25 · [[Themes/editor-experience|Editor Experience]] · Launch · [Official source](https://feedback.descript.com/changelog/release-version-99) · from [[Releases/Descript/descript-2024-09-25-66f1ed3467f5b0cbdcc0d155-14be1212|Release Version 99]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> A new [edit in timeline](https://help.descript.com/hc/en-us/articles/20952542722957-Edit-boundaries) has been button has been added to the toolbar popover that appears when you select an edit boundary in the script while the timeline is hidden. This is designed to make it clearer how you can adjust edit boundaries in fine deal, which will be especially helpful to newer users.
>
> We consolidated the [two stock media panels](https://help.descript.com/hc/en-us/articles/27204675401485-Media-Panel) on the sidebar into a single panel, now called Stock. This new version of the panel contains both Visual and Audio stock media for easier browsing. Just click the tab for the media type you’re looking for.
>
> Timeline exports are now available [on the Web](https://help.descript.com/hc/en-us/articles/16987605355277-Descript-for-Web-and-Desktop-Preview). The options are the same as the desktop version of Descript, and include Pro Tools/Logic (.aaf), Audition (.sesx), Samplitude/Reaper (.edl), Final Cut Pro X (.fcpxml), Premiere (.xml), and DaVinci Resolve (.xml).
>
> This is rolling out slowly so if you're not seeing it yet it should be enabled for you soon.
>
> We've also enabled file conversion processes such as Normalize audio, Convert to mono, and Repair audio on the Web version of Descript.
>
> Source: https://feedback.descript.com/changelog/release-version-99
