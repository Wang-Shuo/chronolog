# Editor updates

**Descript** · 2025-04-08 · [[Themes/editor-experience|Editor Experience]] · Launch · [Official source](https://feedback.descript.com/changelog/release-version-112) · from [[Releases/Descript/descript-2025-04-08-67f566b464be60e217c949ee-140ce254|Release Version 112]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> The Add layer button on the [Selection toolbar](https://help.descript.com/hc/en-us/articles/10164874052237-Selection-toolbar) is back, and has its own icon.
>
> We restored the [Previous scene, and Next scene](https://help.descript.com/hc/en-us/articles/10164534109837-Playback-and-navigation) buttons to the playback controls, in our previous update, these icons were removed for some users.
>
> We’ve made improvements to the responsiveness of text entry when working with text layers like Titles. There should be less input delay.
>
> Since some have asked: we do not yet have the ability to bring back Import from YouTube, but are working on it and will update you as soon as we know more.
>
> Source: https://feedback.descript.com/changelog/release-version-112
