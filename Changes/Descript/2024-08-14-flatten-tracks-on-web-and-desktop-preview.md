**Descript** · 2024-08-14 · [[Themes/mobile-desktop|Mobile and Desktop]] · Launch · [Official source](https://feedback.descript.com/changelog/descript-season-7-release-version-96) · from [[Releases/Descript/descript-2024-08-14-66bbbc3d5113288e1d0cca63-f6dbdde9|Descript Season 7 - Release Version 96]]

> You can now use the [flatten tracks](https://help.descript.com/hc/en-us/articles/10503079305869-Flatten-tracks) function on the Web, and in the Desktop preview version of Descript. It runs a bit faster than it does on regular Desktop, and has a progress meter.
