# Edit image and video from the media library

**Descript** · 2025-10-23 · [[Themes/editor-experience|Editor Experience]] · Launch · [Official source](https://feedback.descript.com/changelog/release-roundupoctober-23rd-2025) · from [[Releases/Descript/descript-2025-10-23-68faa249aae7b47cd5e72ea1-b70e43a4|Release roundup—October 23rd, 2025]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> You can now use [Underlord](https://help.descript.com/hc/en-us/articles/36803785502221-Underlord-beta-Your-AI-co-editor-in-Descript) directly from the media library in the Project panel. When you open an image or video in the preview popout, you'll see an Underlord button with options to generate new content based on that file.
>
> This gives you the same generation options that are available from the scene toolbar, but now you can access them right from your media library.
>
> Source: https://feedback.descript.com/changelog/release-roundupoctober-23rd-2025
