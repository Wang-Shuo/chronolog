# A/V sync offset controls

**Descript** · 2025-06-25 · [[Themes/voice|Voice and Audio]] · Launch · [Official source](https://feedback.descript.com/changelog/release-roundupjune-25th-2025) · from [[Releases/Descript/descript-2025-06-25-685c06c091f36d8569309b19-df2c2fb3|Release roundup—June 25th, 2025]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> You can now adjust the [A/V sync of files](https://help.descript.com/hc/en-us/articles/10256395939341-Troubleshooting-audio-and-video-sync-issues) automatically from the Project panel. This allows you to fix audio/video sync issues by applying a positive value to delay the video, or a negative value to advance the video.
>
> This should save you time if you've been manually adjusting A/V sync issues using the Sequence editor.
>
> Source: https://feedback.descript.com/changelog/release-roundupjune-25th-2025
