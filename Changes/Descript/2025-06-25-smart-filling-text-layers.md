# Smart filling text layers

**Descript** · 2025-06-25 · [[Themes/voice|Voice and Audio]] · Launch · [Official source](https://feedback.descript.com/changelog/release-roundupjune-25th-2025) · from [[Releases/Descript/descript-2025-06-25-685c06c091f36d8569309b19-df2c2fb3|Release roundup—June 25th, 2025]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> We’ve added a new Smart fill tool for text layers when you apply a [layout](https://help.descript.com/hc/en-us/articles/10255950033805-Layout-packs-and-layout-overview) from the gallery. It reads the script track and automatically fills text layers like titles and lists with relevant details from your transcription.
>
> This is a great way to save time with a better-than-blank placeholder, or final text if you’re satisfied with the results.
>
> This setting is toggled on by default for any of our premade layout packs, but you can toggle it on or off for your [custom layout packs](https://help.descript.com/hc/en-us/articles/10255964343053-Creating-adjusting-and-customizing-a-custom-layout) from the Layout pack menu in Drive view.
>
> Source: https://feedback.descript.com/changelog/release-roundupjune-25th-2025
