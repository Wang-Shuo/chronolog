# Improved transcription with ElevenLabs Scribe v2

**Descript** · 2026-05-14 · [[Themes/voice|Voice and Audio]] · [Official source](https://feedback.descript.com/changelog/the-descript-telethon-begins-but-first-releases) · from [[Releases/Descript/descript-2026-05-14-6a05e75cbbef22ce4b0633c9-b87fafc2|The Descript Telethon begins, but first... releases]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> Scribe v2 is now the default [transcription model](https://help.descript.com/hc/en-us/articles/10249424286477-Automatic-transcription) across all supported languages. It outperformed our other models in testing, resulting in fewer corrections per minute and fewer capitalization fixes.
>
> What changed:
>
> **Automatic** mode now routes to Scribe v2 (previously Rev v2 for English, now Scribe v2 for all languages)
>
> The **model picker** now shows real model names: **Automatic**, **Scribe v2**, and **Rev v2**
>
> **British English**: Scribe v2 uses American English spelling. To get British spelling, select Rev v2 from the model picker
>
> Source: https://feedback.descript.com/changelog/the-descript-telethon-begins-but-first-releases
