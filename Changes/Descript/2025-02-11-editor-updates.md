# Editor updates

**Descript** · 2025-02-11 · [[Themes/editor-experience|Editor Experience]] · Launch · [Official source](https://feedback.descript.com/changelog/release-version-108) · from [[Releases/Descript/descript-2025-02-11-67ab977b354800cdb65c181c-b474aa11|Release Version 108]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> You can now add [transition](https://help.descript.com/hc/en-us/articles/10255990548877-Applying-a-transition-to-a-clip) effects at a clip level when you add a cross fade and click for more options. This was initially the result of a bug, but due to some users mentioning it had a utility, we implemented it as a feature.
>
> The Labs toggle for Smart Transitions has been removed as the feature is now live for all users.
>
> You can toggle on Smart Transitions for All scenes in the Settings menu. This option is in Beta which means you could encounter bugs or other unexpected behavior while using it.
>
> Source: https://feedback.descript.com/changelog/release-version-108
