# Editor updates

**Descript** · 2025-02-25 · [[Themes/editor-experience|Editor Experience]] · Launch · [Official source](https://feedback.descript.com/changelog/release-version-109) · from [[Releases/Descript/descript-2025-02-25-67bde093ca243fdab541e3f6-d25f4f75|Release Version 109]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> We’ve added some helpful decoration to the toolbars to show you how many current [effects](https://help.descript.com/hc/en-us/articles/13593402120333-Effects-overview), animations, or transitions are currently applied, shading over already applied effects in dropdown menus and more subtle changes to make it easier to read your layer setting from the toolbars.
>
> Audio and video effects now both have “above the fold” effects listed, and off by default. This is just to help make these features and other effects easier to find.
>
> We’ve made some backend improvements to [Text-to-speech](https://help.descript.com/hc/en-us/articles/10166020211085-Generating-text-to-speech) generation. They will now generate faster and produce a higher quality output.
>
> Source: https://feedback.descript.com/changelog/release-version-109
