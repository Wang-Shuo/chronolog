# Savable custom parameters for generated images and video

**Descript** · 2025-10-23 · [[Themes/image-generation|Image Generation]] · Launch · [Official source](https://feedback.descript.com/changelog/release-roundupoctober-23rd-2025) · from [[Releases/Descript/descript-2025-10-23-68faa249aae7b47cd5e72ea1-b70e43a4|Release roundup—October 23rd, 2025]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> You can now customize settings based on the AI model you've selected for [image](https://help.descript.com/hc/en-us/articles/17045119670029-Generate-AI-images) and [video generation](https://help.descript.com/hc/en-us/articles/38621681243789-Generate-AI-video). Different models support different parameters, and the interface will show you which settings are available for your chosen model.
>
> For video generation, depending on the model, you can adjust:
>
> Aspect ratio
>
> Audio generation (available on select models)
>
> For image generation, you can configure model-specific parameters like number of outputs and other settings that vary by model.
>
> These settings appear in the generation panel when you're using the AI Tools sidebar or working with Underlord. The available options update automatically based on which model you select, so you'll only see parameters that your chosen model supports.
>
> Source: https://feedback.descript.com/changelog/release-roundupoctober-23rd-2025
