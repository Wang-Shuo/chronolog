# Edit Word Gaps from the Script**

**Descript** · 2023-07-10 · [[Themes/context-window|Context Window]] · Launch · [Official source](https://feedback.descript.com/changelog/version-68-release) · from [[Releases/Descript/descript-2023-07-10-64ac412e0a49ed588306f998-b4887a52|Version 68 Release]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> A new option in the context menu lets you [change how long the word gaps are right from the Script](https://help.descript.com/hc/en-us/articles/17460915431053). Right-click at any point in the Script to access the context menu.
>
> You can choose from preset durations, enter a specific duration for the gap by pressing **Cmd-G** on macOS or **Ctrl-G** on Win, or quickly use the last gap duration by pressing **Cmd-Shift-G** on macOS or **Ctrl-Shift-G** on Win.
>
