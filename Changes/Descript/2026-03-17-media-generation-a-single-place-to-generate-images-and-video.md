# Media generation: a single place to generate images and video

**Descript** · 2026-03-17 · [[Themes/video-generation|Video Generation]] · Launch · [Official source](https://feedback.descript.com/changelog/release-roundupmarch-17th-2026) · from [[Releases/Descript/descript-2026-03-17-69b3257b60b225e10f6a3a28-246aeffc|Release roundup—March 17th, 2026]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> [Media generation](https://help.descript.com/hc/en-us/articles/38621681243789-Generate-AI-images-and-video) now opens in one unified panel for both **image** and **video** generation. You can switch between **Image** and **Video** tabs in the same place, with separate prompt and history for each media type.
>
> You will also see commonly used settings more prominently (for example, the model and aspect ratio), so you can adjust them without digging through advanced options.
>
