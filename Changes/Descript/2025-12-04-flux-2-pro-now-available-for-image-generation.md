# Flux 2 Pro now available for image generation

**Descript** · 2025-12-04 · [[Themes/image-generation|Image Generation]] · Launch · [Official source](https://feedback.descript.com/changelog/release-roundupdecember-4th-2025) · from [[Releases/Descript/descript-2025-12-04-6930e3d143084a3405d0352d-695ede77|Release roundup—December 4th, 2025]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> We’ve also added Flux 2 Pro as an [image generation](https://help.descript.com/hc/en-us/articles/17045119670029-Generate-AI-images) model in Descript. This model balances speed and quality, with improved text rendering and capabilities for restyling existing images.
>
> To switch models, go to [Settings → General](https://help.descript.com/hc/en-us/articles/39869916772621-Generative-image-and-video-models-in-Descript) and select Flux 2 Pro from the image generation model dropdown, or select it in the Generate an image panel using the model picker.
>
> Source: https://feedback.descript.com/changelog/release-roundupdecember-4th-2025
