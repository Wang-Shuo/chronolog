# AI Action groups

**Descript** · 2023-12-05 · [[Themes/interface-experience|Interface Experience]] · Launch · [Official source](https://feedback.descript.com/changelog/release-version-7821) · from [[Releases/Descript/descript-2023-12-05-656e26a9b35bd6ff6af3afdf-ae239196|Release Version 78.2.1]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> We’ve added categories to the AI Actions menu for easier navigation and a clearer sense of what each action can do.
>
> **Write** - Actions with prompts to create scripts from scratch or improve scripts via re-writing.
>
> **Edit** - Actions that change the script such as removing filler words, or adding chapters or markers.
>
> **Find** - Actions that help you locate clips in your composition for highlight reels, or social media promotion.
>
> **Publish** - Actions to help you publish content, like generating a summary, social media posts, or a YouTube description.
>
> Source: https://feedback.descript.com/changelog/release-version-7821
