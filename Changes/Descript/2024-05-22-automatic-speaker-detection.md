# Automatic Speaker Detection

**Descript** · 2024-05-22 · [[Themes/interface-experience|Interface Experience]] · Launch · [Official source](https://feedback.descript.com/changelog/release-version-90) · from [[Releases/Descript/descript-2024-05-22-664e1fc1bcb5dd0aa5b5cead-6ab95e46|Release Version 90]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> The speaker detective will now run automatically when you import a file. You no longer have to manually initiate, provide a speaker count, or guess at how many speakers you have if you don’t already know. Each speaker will be labeled with a generic label (Speaker 1, 2, 3 etc.) You can then rename them using the [speaker label menu](https://help.descript.com/hc/en-us/articles/10164803814285-Speakers).
>
> This change is rolling out slowly, so if you don’t see it right away it should be enabled for you within a few days.
>
> Source: https://feedback.descript.com/changelog/release-version-90
