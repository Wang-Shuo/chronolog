# Word gap improvements

**Descript** · 2023-09-18 · [[Themes/multimodal|Multimodal Input]] · Launch · [Official source](https://feedback.descript.com/changelog/release-version-73) · from [[Releases/Descript/descript-2023-09-18-65088b3d73cf3a09c09b31e6-b20a11ca|Release Version 73]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> [Dragging on the wordbar](https://help.descript.com/hc/en-us/articles/10249346632717-The-wordbar) in the timeline to add a gap in a video now automatically adds a [freeze frame](https://help.descript.com/hc/en-us/articles/10249348682637-Freeze-frames) there. If you want a gap clip instead, you can still [manually add a gap clip](https://help.descript.com/hc/en-us/articles/10249333655693-Using-gap-clips#01H82Q3FNF8ERFTEXQ8NJS9GVF) from the context menu in the timeline.
>
> When updating a word gap duration, we no longer automatically spot audition. This should make it faster to make lots of quick updates to word gap durations, and you can always spot audition when you need to using **Cmd-Shift-Space** on macOS or **Cntrl-Shift-Space** in Windows.
>
> Source: https://feedback.descript.com/changelog/release-version-73
