# And tying all of these changes together, we’ve added a [new Layout…

**Descript** · 2025-02-26 · [[Themes/interface-experience|Interface Experience]] · [Official source](https://feedback.descript.com/changelog/descript-season-8) · from [[Releases/Descript/descript-2025-02-26-67bf40cdb942379190027575-de2ca988|Descript Season 8]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> And tying all of these changes together, we’ve added a [new Layout picker](https://help.descript.com/hc/en-us/articles/10255950033805-Layout-packs-and-layout-overview) to make it easier to preview layouts before adding them into your project. This can be accessed from the Scene panel, from the Scene editor toolbar, or from the Script toolbar.
>
> Each of our new Layouts includes our new [Smart transitions](https://help.descript.com/hc/en-us/articles/34011944399629-Smart-Transitions), which detect all the layers that change between scenes in a project, and automatically adds transitions for each one as it moves into the next layout. This can include fades, zooms, and other animations for a 1-click layer of professional polish.
>
> Join us for a live demo with CEO Andrew Mason on March 11th, 2025. He’ll be showing off the new layouts, smart transitions, and taking your questions. [Register here.](https://lu.ma/descript-season-8)
>
> Source: https://feedback.descript.com/changelog/descript-season-8
