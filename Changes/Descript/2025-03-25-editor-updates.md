# Editor updates

**Descript** · 2025-03-25 · [[Themes/editor-experience|Editor Experience]] · Launch · [Official source](https://feedback.descript.com/changelog/release-version-111) · from [[Releases/Descript/descript-2025-03-25-67e2f0e02b7c9f658ffc55c9-c954b6e3|Release Version 111]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> We've updated how we handle [aspect ratios in compositions](https://help.descript.com/hc/en-us/articles/12920160974477-Aspect-ratio-and-video-settings). Instead of matching the aspect ratio of the first file, we now automatically select the nearest standard aspect ratio. You can still adjust to custom aspect ratios in your video settings.
>
> Playback will no longer be paused when you [Correct](https://help.descript.com/hc/en-us/articles/10119613609229-Correcting-your-transcript) the Script. This makes for a more seamless workflow when making script corrections on the fly.
>
> Source: https://feedback.descript.com/changelog/release-version-111
