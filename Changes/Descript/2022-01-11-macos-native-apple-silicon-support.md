# macOS: Native Apple Silicon Support

**Descript** · 2022-01-11 · [[Themes/mobile-desktop|Mobile and Desktop]] · Launch · [Official source](https://feedback.descript.com/changelog/version-30-release) · from [[Releases/Descript/descript-2022-01-11-6390c9df4a4a0d64fa56496c-c85ba67c|Version 30 Release]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> We've added native editing support for Apple Silicon Macs! Everything should run a whole lot faster, and we've squashed a ton of bugs that might've bothered you before.
>
> If you have an Apple Silicon Mac, make sure to fully exit the Descript app (including the [screen recorder](https://help.descript.com/hc/en-us/articles/360051277571-Screen-Recorder); do that by clicking on the ellipsis in the top right hand corner of the Screen Recorder menu, then clicking Quit). Then delete the app from your Applications folder, and install the latest version from [https://www.descript.com/download/mac](https://www.descript.com/download/mac)
>
> Source: https://feedback.descript.com/changelog/version-30-release
