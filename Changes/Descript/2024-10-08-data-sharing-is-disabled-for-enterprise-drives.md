# Data sharing is disabled for Enterprise Drives

**Descript** · 2024-10-08 · [[Themes/collaboration|Collaboration]] · Launch · [Official source](https://feedback.descript.com/changelog/release-version-100) · from [[Releases/Descript/descript-2024-10-08-670564dc958faa93e6166a33-dd601db4|Release Version 100]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> Enterprise drives will soon be automatically [opted out of data sharing](https://help.descript.com/hc/en-us/articles/10255866490125-Account-data-and-privacy). This has been a frequently requested feature from Enterprise teams. As of this release, if data sharing is disabled individual team members or admins will *not* have the option to re-enable it.
>
> Source: https://feedback.descript.com/changelog/release-version-100
