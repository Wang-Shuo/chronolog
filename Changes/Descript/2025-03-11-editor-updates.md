# Editor updates

**Descript** · 2025-03-11 · [[Themes/editor-experience|Editor Experience]] · Launch · [Official source](https://feedback.descript.com/changelog/release-version-110) · from [[Releases/Descript/descript-2025-03-11-67d055ccb3acc17d9eacc9d6-c217f0c7|Release Version 110]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> We have removed the Correction wizard. This was an outdated and under supported tool for making Script corrections. Very few users engaged with it and all the improvements we’ve made to general correction tools have made it obsolete.
>
> In the past, using [Re-transcribe](https://help.descript.com/hc/en-us/search/click?data=BAh7DjoHaWRsKwgNpJTqPgk6D2FjY291bnRfaWRpA%2BS0ljoJdHlwZUkiDGFydGljbGUGOgZFVDoIdXJsSSJUaHR0cHM6Ly9oZWxwLmRlc2NyaXB0LmNvbS9oYy9lbi11cy9hcnRpY2xlcy8xMDE2NTgyODIzMjIwNS1Qcm9qZWN0LWZpbGUtYWN0aW9ucwY7CFQ6DnNlYXJjaF9pZEkiKWI1YTczYTA4LTdiOGQtNDNmNy1hMmU2LTJmNDUyYjVhMTM4NQY7CEY6CXJhbmtpCDoLbG9jYWxlSSIKZW4tdXMGOwhUOgpxdWVyeUkiEnJlLXRyYW5zY3JpYmUGOwhUOhJyZXN1bHRzX2NvdW50aQHV--a82c4007683532638185bd0cbc8f7d9bd63d8ab2) file would use your transcription balance. This is no longer the case, any Re-transcribing a file for any reason *will not* result in transcription time being used.
>
> Source: https://feedback.descript.com/changelog/release-version-110
