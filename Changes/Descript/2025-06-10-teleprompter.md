# Teleprompter

**Descript** · 2025-06-10 · [[Themes/editor-experience|Editor Experience]] · Launch · [Official source](https://feedback.descript.com/changelog/release-roundupjune-10th-2025) · from [[Releases/Descript/descript-2025-06-10-6848be0d00a0835d070d7935-0982dfd9|Release roundup—June 10th, 2025]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> We’ve added a [teleprompter](https://help.descript.com/hc/en-us/articles/35482375421581-Record-with-Descript-s-built-in-teleprompter) to both the Editor recorder, and to the Screen recorder. The new teleprompter allows you to type a script, paste a script, or import a script from a project. You can then set a text size, and scroll speed.
>
> The teleprompter comes also comes with:
>
> A separate light and dark mode button so you can have increased contrast against the editor window or wherever other windows you’re using it.
>
> Mirrored mode for users who have a physical teleprompter handy.
>
> Focus mode which darkens everything but the currently highlighted line.
>
> The scroll speed has two settings:
>
> **Variable -** This scrolls faster over line breaks and empty space
>
> **Constant -** This scrolls at a constant pace regardless of breaks in the script
>
> The teleprompter will be automatically hidden from any recordings you make.
>
> This is a long-standing feature request, and we’re excited to finally get it into your hands.
>
> Source: https://feedback.descript.com/changelog/release-roundupjune-10th-2025
