# Other editor tweaks

**Descript** · 2024-11-05 · [[Themes/editor-experience|Editor Experience]] · Launch · [Official source](https://feedback.descript.com/changelog/release-version-102) · from [[Releases/Descript/descript-2024-11-05-672a4fac68acbe93f698bb4b-eff3b53e|Release Version 102]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> We reworded the [shorten word gaps](https://help.descript.com/hc/en-us/articles/21908864772493-Sound-Good-Actions#h_01HGS2HNKQ1G0J75RW72W46X6R) feature to be more clear. It will *only* search for gaps longer than the input value (i.e. a value of 1 second will only search for gaps of 1.01 or longer.)
>
> Our partnership with Unsplash has ended for the time being, and as a result their library has been removed from the [Stock panel](https://help.descript.com/hc/en-us/articles/27204675401485-Stock-Panel).
>
