# Text-to-image generation

**Descript** · 2023-06-26 · [[Themes/image-generation|Image Generation]] · Launch · [Official source](https://feedback.descript.com/changelog/version-67-release) · from [[Releases/Descript/descript-2023-06-26-649a060b4540744f0210fcd8-5874dabe|Version 67 Release]]

<!-- chronolog:begin region="evidence" -->
> You can now [generate AI images using text prompts](https://help.descript.com/hc/en-us/articles/17045119670029-Generate-AI-images-with-text) to use as custom B-roll images in your projects. To try this feature, go to **Media > Images > Text to Image**, and enter a description of the image you want to create. You'll be presented with three image options to choose from.
