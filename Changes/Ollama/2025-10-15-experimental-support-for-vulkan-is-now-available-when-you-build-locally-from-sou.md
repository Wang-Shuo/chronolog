# Experimental support for Vulkan is now available when you build locally from source

**Ollama** · 2025-10-15 · [[Themes/apps-integrations|Apps and Integrations]] · Launch · [Official source](https://github.com/ollama/ollama/releases/tag/v0.12.6) · from [[Releases/Ollama/ollama-2025-10-15-v0-12-6-github-254837655-c69558b6|v0.12.6]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> Experimental support for Vulkan is now available when you build locally from source. This will enable additional GPUs from AMD, and Intel which are not currently supported by Ollama. To build locally, install the [Vulkan SDK](https://vulkan.lunarg.com/) and set VULKAN_SDK in your environment, then follow the [developer instructions](https://github.com/ollama/ollama/blob/main/docs/development.md). In a future release, Vulkan support will be included in the binary release as well. Please file issues if you run into any problems.
>
> Source: https://github.com/ollama/ollama/releases/tag/v0.12.6
