# 8 other changes in v0.9.1

**Ollama** · 2025-06-09 · Other changes · Digest · [Official source](https://github.com/ollama/ollama/releases/tag/v0.9.1) · from [[Releases/Ollama/ollama-2025-06-09-v0-9-1-github-224087817-76ffb3c8|v0.9.1]]

## Changes in this digest

> [Magistral](https://ollama.com/library/magistral)

> [Llama 4](https://ollama.com/library/llama4)

> [Mistral](https://ollama.com/library/mistral)

> \<img width="1073" alt="Screenshot 2025-06-17 at 11 41 43 AM" src="https://github.com/user-attachments/assets/fe69e299-3d62-49c1-a16f-65b6ac426c83" />

> Ollama can now be exposed on the network, allowing others to access Ollama on other devices or even over the internet. This is useful for having Ollama running on a powerful Mac, PC or Linux computer while making it accessible to less powerful devices.

> Enabling this allows websites to access your local installation of Ollama. This is handy for developing browser-based applications using Ollama's [JavaScript library](https://github.com/ollama/ollama-js).

> [Magistral](https://ollama.com/library/magistral) now supports disabling thinking mode. Note: it is also recommended to change the system prompt when doing so.

> Error messages that previously showed `POST predict` will now be more informative
