# 3 Multimodal Input changes in v0.1.15

**Ollama** · 2023-12-12 · [[Themes/multimodal|Multimodal Input]] · Digest · [Official source](https://github.com/ollama/ollama/releases/tag/v0.1.15) · from [[Releases/Ollama/ollama-2023-12-12-v0-1-15-github-133517915-5af535e3|v0.1.15]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Ollama now supports multimodal models that can describe what they see. To use a multimodal model with `ollama run`, include the full path of a `png` or `jpeg` image in the prompt:

> [LLaVA](https://ollama.ai/library/llava): A novel end-to-end trained large multimodal model that combines a vision encoder and Vicuna for general-purpose visual and language understanding. Available in 7b and 13b parameter sizes.

> [BakLLaVA](https://ollama.ai/library/bakllava): BakLLaVA is a multimodal model consisting of the Mistral 7B base model augmented with the LLaVA architecture.

Source: https://github.com/ollama/ollama/releases/tag/v0.1.15
