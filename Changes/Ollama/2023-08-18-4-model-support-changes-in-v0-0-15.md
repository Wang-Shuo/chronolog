<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> \<a href="https://ollama.ai/library">\<img src="https://github.com/jmorganca/ollama/assets/3325447/6bcf210d-3cf5-42cd-84ae-f0e29d82ec49" alt="an image of ollama sitting in front of shelves with many books depicting a library of models that are available for download" width="50%">\</a>

> Ollama now supports a list of models published on [ollama.ai/library](https://ollama.ai/library). We are working on ways to allow anyone to push models to Ollama. Expect more news on this in the future.

> Experimental support for creating fine-tuned models via `ollama create` with Modelfiles: use the `ADAPTER` Modelfile instruction

> Ollama will now use an already loaded model for `/api/embeddings` if it is available
