# 12 Mobile and Desktop changes in v1.17.16

**OpenCode** · 2026-07-09 · [[Themes/mobile-desktop|Mobile and Desktop]] · Digest · [Official source](https://opencode.ai/changelog/v1.17.16) · from [[Releases/OpenCode/opencode-2026-07-09-v1-17-16-8c4a42fa|v1.17.16]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Desktop Added a composer add menu for files, commands, context, and shell mode without losing draft text.

> Desktop Added a provider setup tip on new sessions when no external providers are connected.

> Desktop Remember review panel mode and selected file per session.

> Desktop Added inline file browser tabs for opening and previewing files from the side panel.

> Desktop Updated desktop translations.

> Desktop Kept the review pane usable on wide screens by reserving its minimum width.

> Desktop Fixed hidden session panes staying mounted and causing side-panel glitches.

> Desktop Routed legacy drafts back to the session page.

> Desktop Loaded full review diffs for large patches when the initial diff is capped.

> Desktop Removed the first-open flash in the command palette.

> Desktop Routed the new session shortcut through tabs in the new layout.

> Desktop Kept session routes inside the correct layout when opening legacy session URLs.

Source: https://opencode.ai/changelog/v1.17.16
