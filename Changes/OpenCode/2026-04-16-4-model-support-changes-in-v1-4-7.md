## Changes in this digest

> Core Cloudflare AI Gateway now drops max_tokens for OpenAI reasoning models so GPT-5 and o-series requests stop failing.

> Core Azure models now default store=true , fixing requests that require stored responses.

> Core Claude Opus 4.7 now supports xhigh adaptive reasoning.
