# 7 Apps and Integrations changes in v1.17.0

**OpenCode** · 2026-06-10 · [[Themes/apps-integrations|Apps and Integrations]] · Digest · [Official source](https://opencode.ai/changelog/v1.17.0) · from [[Releases/OpenCode/opencode-2026-06-10-v1-17-0-776801ad|v1.17.0]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Core mcp add now works in non-interactive flows.

> SDK Large v2 tool outputs are now bounded and expose retained output paths for follow-up inspection.

> Core Improved MCP connection status messages so failures are easier to act on.

> Core MCP tool calls now receive abort signals, so cancellations stop more reliably.

> Core MCP catalogs now paginate correctly instead of truncating larger lists.

> Core MCP servers now respect advertised capabilities.

> Desktop MCP status now refreshes when the active directory changes.

Source: https://opencode.ai/changelog/v1.17.0
