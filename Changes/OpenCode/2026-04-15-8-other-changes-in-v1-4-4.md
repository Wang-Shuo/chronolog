# 8 other changes in v1.4.4

**OpenCode** · 2026-04-15 · Other changes · Digest · [Official source](https://opencode.ai/changelog/v1.4.4) · from [[Releases/OpenCode/opencode-2026-04-15-v1-4-4-b66f2e07|v1.4.4]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Core Restored the flat reply shape for question API responses.

> Core Prevented duplicate user messages in ACP clients.

> Core Stopped emitting user_message_chunk events during session and prompt turns in ACP clients.

> Core Added Alibaba provider support with cache support.

> Core Snapshots now fully respect .gitignore , including previously tracked files.

> Core Reading images no longer counts against quota.

> Core Sessions can now update project permissions mid-run.

> Core Enabled thinking for zhipuai-coding-plan and fixed Korean IME truncation.

Source: https://opencode.ai/changelog/v1.4.4
