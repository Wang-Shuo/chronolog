> Desktop Show a subagent's model, status, and elapsed time in its composer area.

> Desktop Add text-rendering controls to the debug bar.

> Desktop Show elapsed time for background work.

> Desktop Split the side pane and add a draggable bottom pane with tabs.

> Desktop Open multiple file tabs at once and open side-panel content in tabs.

> Desktop Move running work to the background when you steer a session.

> Desktop Let the timeline scroll beneath the composer while keeping its content visible.

> Desktop Add a Reduce motion appearance setting.

> Desktop Open image previews directly from message and composer thumbnails.

> Desktop Show individual Code Mode tool calls in Execute rows.

> Desktop Add a Commentary timeline category and display setting.

> Desktop Support @ links to other sessions in messages.

> Desktop Polish spacing, alignment, borders, and typography across the session header, titlebar, composer, file tree, browser pane, timeline, and Settings.

> Desktop Keep todo items from shrinking in the todo panel.

> Desktop Keep question-dock answers and controls positioned correctly when changing questions.

> Desktop Finish quitting after Cmd+Q on macOS.

> Desktop Deliver steering messages when an earlier move was missed.

> Desktop Restrict Search projects to the project list.

> Desktop Let custom Close tab shortcuts close terminal and browser tabs.

> Desktop Prevent live status rows from jumping or leaving gaps above the composer.

> Desktop Keep browser tabs still behind open dialogs.

> Desktop Render session diffs reliably.

> Desktop Keep keyboard focus in terminals, side panels, dialogs, and the composer when appropriate.

> Desktop Preserve empty browser and side-panel tabs instead of closing them automatically.

> Desktop Restore horizontal scrolling and sticky change badges in the file tree.

> Desktop Show live Thinking for reasoning-only turns.

> Desktop Stop loading older history after completing the initially visible turn and prioritize the first transcript page.

> Desktop Keep Home project and session lists reliable during refreshes.

> Desktop Keep deleted sessions from reappearing on Home.

> Desktop Find sessions immediately in @ mentions, including multi-word titles.

> Desktop Keep queued messages editable while changes sync with the server.

> Desktop Open image and video URLs in the browser pane.

> Desktop Mark submitted generated forms as complete and send each response only once.

> Desktop Group untracked folders into one expandable review row.

> Desktop Let you paste into the composer from the session view.

> Desktop Recover failed beta background servers and preserve their required CLI versions.

> Desktop Keep the running server available while beta updates install.

> Desktop Make links in user messages, shell output, and Code Mode output clickable.

> Desktop Make Check for Updates always report its result.

> Desktop Keep OpenCode keyboard shortcuts working in the browser pane.

> Desktop Preview image attachments supplied by file path.

> Desktop Apply configured code and UI fonts consistently.

> Desktop Keep activity and busy indicators steady while switching sessions.

> Desktop Reserve ⇧⌘W for closing the window so ⌘W does not.

> Desktop Make image preview transitions resize smoothly without clipping or blocking clicks.

> Desktop Keep tables visible beneath sticky headers.

> Desktop Fit provider connection steps without shifting a dialog's top edge.

> Desktop Give unavailable-server panels clear error styling.

> Desktop Keep long Execute tool code contained and show successful Code Mode output.

> Desktop Focus the most useful control when dialogs open, including Cancel in delete confirmations.

> Desktop Install Windows beta, stable, and nightly builds into separate directories.

> Desktop Keep session tabs recoverable when their server becomes unreachable.

> Desktop Reread open files without resetting their scroll position.

> Desktop Polish hover states, cursors, tooltips, focus rings, scrollbars, and transitions across desktop controls.
