# 17 other changes in v1.3.6 + 2

**OpenCode** · 2026-03-29 · Other changes · Digest · [Official source](https://opencode.ai/changelog/v1.3.6) · from [[Releases/OpenCode/opencode-2026-03-29-v1-3-6-6f35969f|v1.3.6 + 2]]

## Changes in this digest

> Core Update opencode-gitlab-auth to 2.0.1

> Core Refactored session processor to use effect-based architecture

> Core Use AppFileSystem instead of raw Filesystem for better abstraction

> Core Upgrade OpenTUI to version 0.1.91

> Core Update Effect to version 4.0.0-beta.42

> Core Use ChildProcessSpawner instead of Process.spawn for formatting

> Core Move more responsibility to workspace routing

> Core Refactor Session service to use Effect-based architecture

> Core Add additional overflow error patterns to error handling

> Core Split out instance and route through workspaces

> Core Effectify Skill service internals

> Core Yield services instead of promise facades in Effect refactor

> Core Use cachedInvalidateWithTTL for config and bump Effect to beta.37

> Core Refactor Config service to use Effect

> Core Remove workspace server and WorkspaceContext, improve routing architecture

> Core PR #19758: Fixed token usage double-counting for Anthropic and Amazon Bedrock providers that caused inflated token counts in session metrics

> Core Adjust GPT prompt to be more minimal and fix file reference annoyances

Source: https://opencode.ai/changelog/v1.3.6
