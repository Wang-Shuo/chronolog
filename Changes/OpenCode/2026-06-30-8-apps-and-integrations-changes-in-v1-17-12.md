# 8 Apps and Integrations changes in v1.17.12

**OpenCode** · 2026-06-30 · [[Themes/apps-integrations|Apps and Integrations]] · Digest · [Official source](https://opencode.ai/changelog/v1.17.12) · from [[Releases/OpenCode/opencode-2026-06-30-v1-17-12-8813aff2|v1.17.12]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Desktop Autocomplete MCP resources in the composer.

> SDK Add SDK access to active sessions.

> SDK Restore session runtime operations such as event streaming, interrupts, and message lookup.

> Core Prefer MCP content responses over structured output when both are present.

> Core Scope MCP auth status to each server URL.

> SDK Preserve V2Event names in SSE streams.

> SDK Wake embedded session execution after new prompts.

> SDK Resolve MIME types for prompt attachments sent by URI.

Source: https://opencode.ai/changelog/v1.17.12
