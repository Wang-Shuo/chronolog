# 7 Mobile and Desktop changes in v1.18.13

**OpenCode** · 2026-08-04 · [[Themes/mobile-desktop|Mobile and Desktop]] · Digest · [Official source](https://opencode.ai/changelog/v1.18.13) · from [[Releases/OpenCode/opencode-2026-08-04-v1-18-13-ea757111|v1.18.13]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Desktop Added early right-to-left layout support across the app and session views.

> Desktop Added locale-aware plural rules so translated counts and summaries read correctly.

> Desktop Expanded translation coverage and added more supported desktop languages.

> Desktop Fixed several right-to-left layout issues across tabs, drawers, resizing, and titlebar interactions.

> Desktop Fixed shared right-to-left UI behavior such as directional icons and drawer placement.

> Desktop Sessions without titles now fall back to generated names instead of appearing blank.

> Desktop Moved markdown parsing off the main thread to keep the app more responsive while rendering messages.

Source: https://opencode.ai/changelog/v1.18.13
