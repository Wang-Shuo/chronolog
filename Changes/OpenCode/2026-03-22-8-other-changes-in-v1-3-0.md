# 8 other changes in v1.3.0

**OpenCode** · 2026-03-22 · Other changes · Digest · [Official source](https://opencode.ai/changelog/v1.3.0) · from [[Releases/OpenCode/opencode-2026-03-22-v1-3-0-00955596|v1.3.0]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Important Interactive Update Flow : Major and minor updates now show a confirmation dialog before upgrading, allowing you to review changes before updating. You can also skip specific versions if you prefer to stay on your current release.

> Important Node.js Support : opencode can now run on Node.js in addition to Bun, with a dedicated Node.js entry point and build script that bundles the server with database migrations.

> UI/UX Improvements Theme Improvements : Improved UI contrast and reduced brightness of hover/active elements for better readability and reduced eye strain.

> UI/UX Improvements System Prompt : Cleaner AI responses with a streamlined fallback system prompt that removes unnecessary boilerplate text.

> UI/UX Improvements Tool Discovery : Fixed tool discovery for npm-installed packages by including the cache bin directory in PATH lookups, ensuring locally installed tools are properly found.

> UI/UX Improvements Error Messages : Tool and session error messages now display in clean, human-readable format instead of showing confusing technical error strings.

> UI/UX Improvements Chunk Timeout : Disabled chunk timeout by default to prevent issues across various use cases; users can still enable it in their configuration if needed.

> UI/UX Improvements Event Ordering : Events in real-time streams now process sequentially in order, ensuring consistent and predictable event display instead of potentially out-of-order delivery.

Source: https://opencode.ai/changelog/v1.3.0
