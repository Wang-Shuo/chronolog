# 3 Interface Experience changes in v1.3.0

**OpenCode** · 2026-03-22 · [[Themes/interface-experience|Interface Experience]] · Digest · [Official source](https://opencode.ai/changelog/v1.3.0) · from [[Releases/OpenCode/opencode-2026-03-22-v1-3-0-00955596|v1.3.0]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Desktop App Improvements Workspace Switching : Fixed visual flickering when switching between workspaces or projects - the interface now transitions smoothly without showing loading spinners during navigation.

> Desktop App Improvements Sidebar Resize : Fixed issue where sidebar would automatically close when being resized to minimum width. The sidebar now clamps at minimum width instead of closing.

> UI/UX Improvements Remote Server Switching : Fixed issues when switching between remote servers that caused stale project data, broken terminal spawning, and sidebar showing incorrect projects.

Source: https://opencode.ai/changelog/v1.3.0
