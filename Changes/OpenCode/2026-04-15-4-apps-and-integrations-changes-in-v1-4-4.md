<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Core Fixed reasoning summary injection for @ai-sdk/openai-compatible providers.

> Terminal Plugin auth no longer asks for an API key when the plugin has no authorize method.

> SDK The JavaScript SDK now throws a clear error when an older server responds with HTML instead of the API.

> Extensions Plugins can now register custom workspace adaptors that appear in workspace creation.
