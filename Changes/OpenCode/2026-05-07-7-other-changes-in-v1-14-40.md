## Changes in this digest

> Core Return consistent not-found errors for missing sessions.

> Core Apply CORS headers before auth so browser clients can reach legacy server endpoints.

> Core Fix serve , web , and ACP network options triggering runtime re-entry errors.

> Core Only show connected workspaces in warp flows, and carry the new directory into the session after warping.

> Core Sanitize invalid surrogate characters before provider transforms.

> Core Use the current workspace with /new , including local-project warps.

> Core Retry server_is_overloaded API errors automatically.
