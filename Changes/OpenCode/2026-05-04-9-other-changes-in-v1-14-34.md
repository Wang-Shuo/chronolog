## Changes in this digest

> Core Add v2 session failure events so clients can detect and show failed runs.

> Core Return structured error bodies from the effect HTTP server instead of empty failures.

> Core Reload server auth environment variables correctly for each new HTTP listener.

> Core Fix the web UI proxy so public manifest assets load and proxied responses do not break on transfer-encoding .

> Core Fix embedded UI serving from the standalone server build.

> Core Respect custom basic auth usernames in opencode clients.

> Core Prompt browsers for basic auth on protected server logins.

> Core Fix v2 session API responses to encode optional fields correctly.

> Core Fix pagination Link headers to use the real request host.
