# 10 Interface Experience changes in v2.2.0

**OpenCode** · 2026-10-27 · [[Themes/interface-experience|Interface Experience]] · Digest · [Official source](https://opencode.ai/changelog/v2.2.0) · from [[Releases/OpenCode/opencode-2026-10-27-v2-2-0-f60b51f1|v2.2.0]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Terminal Add /usage , model-picker, prompt, sidebar, warning, and error details for OpenCode Console usage limits.

> Desktop Open session extension lists on hover and follow keyboard navigation.

> Desktop Add a searchable prompt history picker.

> Desktop Add a session-details menu to the session header.

> Desktop Restore session summary and project menu actions.

> Desktop Attach the new-session location picker below the composer.

> Desktop Add a sidebar toggle for vertical tabs.

> Desktop Keep the @ menu open while it searches.

> Desktop Keep side-panel content and browser pages visible while the sidebar or panel moves.

> Desktop Polish sidebar, panel, composer, activity, question-dock, loading, and motion behavior across light and dark themes.

Source: https://opencode.ai/changelog/v2.2.0
