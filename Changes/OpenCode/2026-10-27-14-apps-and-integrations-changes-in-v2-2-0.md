# 14 Apps and Integrations changes in v2.2.0

**OpenCode** · 2026-10-27 · [[Themes/apps-integrations|Apps and Integrations]] · Digest · [Official source](https://opencode.ai/changelog/v2.2.0) · from [[Releases/OpenCode/opencode-2026-10-27-v2-2-0-f60b51f1|v2.2.0]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Core Improve integration rebuild performance.

> Core Let plugins filter event subscriptions by type.

> Core Expose MCP server titles from serverInfo .

> Terminal List OpenCode Console before OpenCode Go in the integration picker.

> Desktop Refresh the Manage models, MCP, and fork dialogs with compact searchable lists.

> Core Wait for plugins to finish reloading before each session step and tool call.

> Core Preserve legacy MCP codemode settings during migration.

> Core Keep working MCP tools available when a server returns malformed ones.

> Terminal Keep the TUI running when a plugin slot or route renders bare text.

> Desktop Prevent duplicate tab shortcuts and remove uninstalled plugin commands from Shortcuts.

> Desktop Toggle MCP servers for the current session location from Settings.

> SDK Fix generated Promise client input types for TypeScript consumers.

> SDK Avoid unnecessary catalog refreshes for locations an SDK client has not loaded.

> SDK Restore running sessions created while an SDK client was disconnected.

Source: https://opencode.ai/changelog/v2.2.0
