# 11 Mobile and Desktop changes in v1.17.11

**OpenCode** · 2026-06-25 · [[Themes/mobile-desktop|Mobile and Desktop]] · Digest · [Official source](https://opencode.ai/changelog/v1.17.11) · from [[Releases/OpenCode/opencode-2026-06-25-v1-17-11-7c4dccff|v1.17.11]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Desktop Add draggable tabs.

> Desktop Improve the empty home state when you have no sessions.

> Desktop Restyle the jump-to-latest button in the v2 session view.

> Desktop Improve the redesigned desktop layout, including better titlebar tabs and archived sessions.

> Desktop Keep prompt drafts attached to the correct project server.

> Desktop Restore home actions when session lists are empty or still loading.

> Desktop Keep todo docks in place when switching between sessions.

> Desktop Automatically close tabs for sessions that no longer exist.

> Desktop Keep provider dialogs, prompt rollbacks, and async attachments tied to the session where they started.

> Desktop Clear late session notifications after you open the session.

> Desktop Remove the session loading stripe.
