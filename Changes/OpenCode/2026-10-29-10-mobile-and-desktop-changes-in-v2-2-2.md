# 10 Mobile and Desktop changes in v2.2.2

**OpenCode** · 2026-10-29 · [[Themes/mobile-desktop|Mobile and Desktop]] · Digest · [Official source](https://opencode.ai/changelog/v2.2.2) · from [[Releases/OpenCode/opencode-2026-10-29-v2-2-2-2b757877|v2.2.2]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Desktop Restored classic question cards by default and added Settings → Experimental → New question UI for the redesigned keyboard-oriented dock.

> Desktop Added a side-panel tab menu and kept close buttons visible when tabs overflow.

> Desktop Redesigned the active todo pill to show the current task and concurrent work more clearly.

> Desktop Added consistent styling for searchable dialogs and composer pills.

> Desktop Stopped queued prompts from dropping frames as their content grows.

> Desktop Counted queued quotes and browser annotations as attachments.

> Desktop Reported failures to persist composer attachments through the normal error UI.

> Desktop Made Markdown fragment links scroll to the referenced heading.

> Desktop Ordered the inbox’s Working shelf by execution start time.

> Desktop Added reset details, an account link, and a composer tray for Go usage limits.

Source: https://opencode.ai/changelog/v2.2.2
