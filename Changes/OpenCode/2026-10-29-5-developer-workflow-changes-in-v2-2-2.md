# 5 Developer Workflow changes in v2.2.2

**OpenCode** · 2026-10-29 · [[Themes/developer-workflow|Developer Workflow]] · Digest · [Official source](https://opencode.ai/changelog/v2.2.2) · from [[Releases/OpenCode/opencode-2026-10-29-v2-2-2-2b757877|v2.2.2]]

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Core Rejected persistent terminal requests whose working directory no longer exists.

> Terminal Preserved captured attachments and their original source paths.

> Terminal Prevented middle-truncated paths from overflowing at very narrow terminal widths.

> Terminal Improved Go usage-limit messages with the reset time and account page link.

> Terminal Correctly typed and displayed Go and ChatGPT usage-limit errors.
