# 14 Mobile and Desktop changes in v1.17.14

**OpenCode** · 2026-07-06 · [[Themes/mobile-desktop|Mobile and Desktop]] · Digest · [Official source](https://opencode.ai/changelog/v1.17.14) · from [[Releases/OpenCode/opencode-2026-07-06-v1-17-14-6f861196|v1.17.14]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Desktop Show draft server status in the title bar.

> Desktop Unified the provider connect flow across the app.

> Desktop Improved model search in picker dialogs.

> Desktop Added recently closed projects to Home.

> Desktop Made tab navigation respond on mouse down in the new layout.

> Desktop Overhauled the v2 review panel.

> Desktop Fixed new sessions from Home using the wrong project.

> Desktop Fixed first-launch onboarding so it only appears when appropriate.

> Desktop Fixed timeline loads that started on assistant replies by backfilling the missing user turn.

> Desktop Restored typing in the composer while the window is unfocused.

> Desktop Fixed dropdown search behavior.

> Desktop Kept the v2 review pane mounted when switching session tabs.

> Desktop Fixed child-session navigation and lineage resolution during tab transitions.

> Desktop Kept desktop window tabs after closing and reopening the app.
