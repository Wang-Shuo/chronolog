# 13 Developer Workflow changes in v2.2.0

**OpenCode** · 2026-10-27 · [[Themes/developer-workflow|Developer Workflow]] · Digest · [Official source](https://opencode.ai/changelog/v2.2.0) · from [[Releases/OpenCode/opencode-2026-10-27-v2-2-0-f60b51f1|v2.2.0]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Terminal Reduce CPU use while animated session-tab pulses are visible.

> Terminal Make CLI service registration more reliable when concurrent processes update its files.

> Desktop Quote selected timeline or terminal text into the composer.

> Desktop Let you choose a new directory or worktree when a session location is unavailable.

> Core List and search remote Git branches correctly without bare remote names.

> Terminal Return opencode run --format json server connection errors as JSON.

> Terminal Preserve pasted prompt text when copying it back out.

> Terminal Reliably update the background service on Windows when its files are briefly locked.

> Terminal Keep the background service state directory out of tool shells and identify processes blocking its port.

> Terminal Refresh Git branch details after switching branches.

> Terminal Accept --server and --standalone anywhere in supported CLI commands.

> Terminal Connect remote access tunnels through HTTP proxies.

> Terminal Keep development builds on a separate server, database, and port from released builds.

Source: https://opencode.ai/changelog/v2.2.0
