# 8 Mobile and Desktop changes in v1.18.8

**OpenCode** · 2026-07-28 · [[Themes/mobile-desktop|Mobile and Desktop]] · Digest · [Official source](https://opencode.ai/changelog/v1.18.8) · from [[Releases/OpenCode/opencode-2026-07-28-v1-18-8-df744f48|v1.18.8]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Desktop Added a shortcut to open the project selector in new sessions.

> Desktop Tab keyboard navigation now follows the visible tab order.

> Desktop Opening files now expands Windows folders with trailing separators.

> Desktop Provider connection state now refreshes immediately after changes.

> Desktop Linux packages now install AppStream metadata.

> Desktop Local desktop runs now use the channel database.

> Desktop Prevents freezes when closing projects from the home view.

> Desktop Prevents the right panel from freezing the session view while loading.

Source: https://opencode.ai/changelog/v1.18.8
