<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Core Webfetch and Code Mode fetch now reject URLs that contain credentials and ignore the #fragment when matching permission rules, and Code Mode fetch checks every redirect against your webfetch rules.

> Core Ask for external_directory permission before session_move leaves the current project.

> Core Prevent repeated zsh q flags from freezing shell permission scanning. Thanks @yangguan-xue.
