# 6 Developer Workflow changes in v1.17.0

**OpenCode** · 2026-06-10 · [[Themes/developer-workflow|Developer Workflow]] · Digest · [Official source](https://opencode.ai/changelog/v1.17.0) · from [[Releases/OpenCode/opencode-2026-06-10-v1-17-0-776801ad|v1.17.0]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Terminal The session move flow now highlights project copies more clearly and keeps the current location selected.

> Terminal Project copies can now be deleted directly from the move dialog.

> Desktop Added WSL-backed Desktop support and WSL server management on Windows.

> Terminal New project copies are now bootstrapped before the TUI switches into them.

> Terminal Moving a session now injects a reminder about the new working directory.

> Desktop Fixed several WSL Desktop bugs.

Source: https://opencode.ai/changelog/v1.17.0
