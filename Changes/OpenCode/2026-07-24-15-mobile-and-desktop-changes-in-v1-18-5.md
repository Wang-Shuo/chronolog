# 15 Mobile and Desktop changes in v1.18.5

**OpenCode** · 2026-07-24 · [[Themes/mobile-desktop|Mobile and Desktop]] · Digest · [Official source](https://opencode.ai/changelog/v1.18.5) · from [[Releases/OpenCode/opencode-2026-07-24-v1-18-5-afa44289|v1.18.5]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Desktop Support current-server review data in the desktop app.

> Desktop Update server discovery flows for current servers.

> Desktop Support current-server session actions, including prompts and commands.

> Desktop Render current-server session timelines.

> Desktop Stream current-server events in the desktop app.

> Desktop Detect legacy and current servers so the desktop app can work with both.

> Desktop Restore optimistic timeline updates while responses are still streaming.

> Desktop Hide legacy-only features when connected to current servers.

> Desktop Preserve inline file mentions when sending prompts to legacy servers.

> Desktop Stop auto-accepting config permissions on current servers.

> Desktop Keep current servers out of the legacy layout.

> Desktop Show plain file contents in file-specific tabs instead of review diffs.

> Desktop Keep paginated session timelines in the right order.

> Desktop Restore directory-scoped session status for legacy servers.

> Desktop Reload legacy session progress after hydration.

Source: https://opencode.ai/changelog/v1.18.5
