# 5 Mobile and Desktop changes in v1.3.0

**OpenCode** · 2026-03-22 · [[Themes/mobile-desktop|Mobile and Desktop]] · Digest · [Official source](https://opencode.ai/changelog/v1.3.0) · from [[Releases/OpenCode/opencode-2026-03-22-v1-3-0-00955596|v1.3.0]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Important Git-backed Session Review : Added git-backed session review modes, enabling users to review uncommitted changes and branch diffs directly within opencode. Git changes are now the default review source with the desktop review tree staying synchronized with your selected source.

> Desktop App Improvements Project Navigation : Navigate between projects faster using keyboard shortcuts (cmd+option+arrow keys).

> Desktop App Improvements File Uploads : Desktop app now supports file type filters and multiple file selection when uploading files.

> Desktop App Improvements Loading States : Improved loading state management across the app for smoother, more consistent feedback during async operations.

> UI/UX Improvements Desktop Stability : Improved desktop stability with more reliable workspace and session routing, fixing sidebar selection mismatches and race conditions when switching projects.

Source: https://opencode.ai/changelog/v1.3.0
