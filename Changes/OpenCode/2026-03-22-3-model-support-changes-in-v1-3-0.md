# 3 Model Support changes in v1.3.0

**OpenCode** · 2026-03-22 · [[Themes/model-support|Model Support]] · Digest · [Official source](https://opencode.ai/changelog/v1.3.0) · from [[Releases/OpenCode/opencode-2026-03-22-v1-3-0-00955596|v1.3.0]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Providers & Models GPT Model List : Updated the GPT subscription model list with the latest available models.

> Providers & Models Vertex AI Fix : Fixed Vertex AI errors with non-thinking models (like gemini-2.0-flash) by only applying thinking configuration to models that support reasoning capabilities.

> Providers & Models Cost Chunk Format : Fixed streaming error where cost data was sent in upstream provider format instead of client-requested format, preventing validation errors when mixing provider formats.
