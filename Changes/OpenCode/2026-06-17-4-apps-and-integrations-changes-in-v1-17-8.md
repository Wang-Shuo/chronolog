# 4 Apps and Integrations changes in v1.17.8

**OpenCode** · 2026-06-17 · [[Themes/apps-integrations|Apps and Integrations]] · Digest · [Official source](https://opencode.ai/changelog/v1.17.8) · from [[Releases/OpenCode/opencode-2026-06-17-v1-17-8-b3531749|v1.17.8]]

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Core OpenAI-compatible providers now accept MCP tool schemas that previously failed validation.

> Core MCP tools without declared schema properties now work with providers that expect object properties.

> Core Long-running MCP tools now keep their timeout alive when they report progress.

> Core MCP tool failures now surface the server's error text instead of a generic failure.
