# 6 Reliability and Performance changes in v2.2.0

**OpenCode** · 2026-10-27 · [[Themes/reliability-performance|Reliability and Performance]] · Digest · [Official source](https://opencode.ai/changelog/v2.2.0) · from [[Releases/OpenCode/opencode-2026-10-27-v2-2-0-f60b51f1|v2.2.0]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Core Convert tool schemas once to speed up tool execution.

> Core Make Git project discovery faster while recognizing repository changes.

> Desktop Render Mermaid diagrams in messages much faster, sized to fit the column.

> Desktop Improve streamed Markdown rendering reliability and performance.

> Core Load session diffs without reading every message, improving performance for large sessions.

> Desktop Improve file-view performance with reused views, virtualized medium files, and cached diffs.

Source: https://opencode.ai/changelog/v2.2.0
