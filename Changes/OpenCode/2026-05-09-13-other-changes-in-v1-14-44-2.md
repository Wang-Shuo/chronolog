# 13 other changes in v1.14.44 + 2

**OpenCode** · 2026-05-09 · Other changes · Digest · [Official source](https://opencode.ai/changelog/v1.14.44) · from [[Releases/OpenCode/opencode-2026-05-09-v1-14-44-6cb8a034|v1.14.44 + 2]]

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Core Added workspace sync so adapter-backed workspaces can be discovered and registered automatically.

> Core Added an interactive split-footer mode for opencode run .

> Core Returned structured validation errors from the HTTP API.

> Core Included auth challenges on typed HTTP API 401 responses.

> Core Fixed detached sessions so they are claimed by the source project again.

> Core Forwarded SIGINT , SIGTERM , and SIGHUP correctly when running through the npm shim.

> Core Allowed skills without descriptions to load correctly.

> Core Required auth on effect HTTP API root routes.

> Core Kept tool ordering stable so tool lists stop reshuffling between runs.

> Core Made retry dialogs more specific to the provider and failure reason.

> Core Fixed upgrades failing for existing workspaces when adding the time_used field.

> Core Keep provider and config API responses working when auth loaders add non-JSON options to providers.

> Core Include tool image attachments in ACP updates and session replays.
