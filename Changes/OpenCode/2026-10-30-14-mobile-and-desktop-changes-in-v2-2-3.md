# 14 Mobile and Desktop changes in v2.2.3

**OpenCode** · 2026-10-30 · [[Themes/mobile-desktop|Mobile and Desktop]] · Digest · [Official source](https://opencode.ai/changelog/v2.2.3) · from [[Releases/OpenCode/opencode-2026-10-30-v2-2-3-0c0c59eb|v2.2.3]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Desktop Added a Desktop spellcheck toggle under Settings → General and system-language dictionary selection on Windows and Linux.

> Desktop Added PageUp and PageDown timeline paging from the composer without moving the draft cursor or focus.

> Desktop Added independently configurable question notifications and sounds under Settings → Notifications → Questions .

> Desktop Added one-click version copying in Settings → About .

> Desktop Grouped added projects in workspace settings.

> Desktop Made question-answer text selectable.

> Desktop Adapted the session header to narrow timeline widths.

> Desktop Kept question options and submit controls reachable on mobile.

> Desktop Preserved simultaneous request notifications and inbox scroll position when opening sessions.

> Desktop Fixed consecutive dropped files so every file mention is inserted into the composer.

> Desktop Fixed ⌘W side-panel closing and focus restoration when no closable tabs remain.

> Desktop Kept the mobile session drawer open while a session loads.

> Desktop Restored maximized windows on their saved display and retained renderer permissions across shared-session windows.

> Desktop Fixed the macOS application icon and added the required folder-access description to the app bundle.

Source: https://opencode.ai/changelog/v2.2.3
