# 9 Mobile and Desktop changes in v2.2.1

**OpenCode** · 2026-10-29 · [[Themes/mobile-desktop|Mobile and Desktop]] · Digest · [Official source](https://opencode.ai/changelog/v2.2.1) · from [[Releases/OpenCode/opencode-2026-10-29-v2-2-1-8378da57|v2.2.1]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Desktop Add /reload to reload configuration without restarting.

> Desktop Refine project and worktree selection, command search, prompt-history focus, composer model labels, and artifact preview controls.

> Desktop Highlight quoted timeline content while you write its first comment.

> Desktop Keep draft attachment bytes local when using experimental media URIs.

> Desktop Treat the reachable scroll boundary as the end when Desktop zoom is active.

> Desktop Prevent shell text from showing through copy buttons and avoid restyling the transcript when closing a side panel.

> Desktop Keep rendering malformed tool metadata instead of crashing the timeline.

> Desktop Make dropdowns open immediately and keep the new-session location shortcut working after tooltip interactions.

> Desktop Remove edge halos from macOS application icons.

Source: https://opencode.ai/changelog/v2.2.1
