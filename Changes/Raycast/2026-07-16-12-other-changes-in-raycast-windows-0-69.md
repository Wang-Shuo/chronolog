# 12 other changes in Raycast windows 0.69

**Raycast** · 2026-07-16 · Other changes · Digest · [Official source](https://www.raycast.com/changelog/windows/0-69) · from [[Releases/Raycast/raycast-2026-07-16-windows-0-69-2a500e61|Raycast windows 0.69]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> AI Chat : Added support for skills. Skills can be loaded into a chat automatically or via @-mention and skill folders can be configured in Settings.

> AI Chat : Screen captures of the entire screen or specific windows can now be attached to AI Chat or Quick AI via menus and commands

> Cloud Sync: Customize what gets synced across your devices

> Cloud Sync: Manage your synced devices

> Root Search : Added ability to show favorites in compact mode

> Windows Settings : Open Control Panel items from Raycast

> AI : \<br> tags in AI markdown now render as line breaks

> AI : @-mentions left in the composer when closing AI Chat get preserved when re-opening AI Chat again

> AI Chat : Consecutive tool calls get collapsed into a group to reduce visual clutter

> UI : Improved ghost dropdown button design (Settings selects)

> Core: F ixed an issue where Raycast windows could appear at a wrong size

> File Search: File Search no longer prevents Raycast from launching if the user’s disk is full

Source: https://www.raycast.com/changelog/windows/0-69
