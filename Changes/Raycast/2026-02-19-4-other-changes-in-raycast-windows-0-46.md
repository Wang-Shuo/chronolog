## Changes in this digest

> Raycast Notes : Toggles the Notes window. 🎉

> Create Note: Creates a new note and opens the window. It’s ideal to capture your thoughts with zero friction.

> Search Notes: Search all your notes by title and content, making it easy to revisit previous notes.

> Advanced Settings : Added new “Open Folders in Tabs” setting to open folders as new tabs in an existing Windows Explorer window.
