# 9 other changes in Raycast windows 2.9

**Raycast** · 2026-10-22 · Other changes · Digest · [Official source](https://www.raycast.com/changelog/windows/2-9) · from [[Releases/Raycast/raycast-2026-10-22-windows-2-9-21373de7|Raycast windows 2.9]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Notes : Added a Send to AI Chat action to Search Notes and the Notes window. Press Ctrl + J to attach the note to AI Chat

> Action Panel : Improved search ranking by prioritizing complete word matches

> AI Chat : Wide tables can now go past the usual text width to show more columns, while staying lined up with the text and keeping each column readable

> AI Chat : Long responses render more smoothly while they're streaming in

> AI Chat : Improved Mermaid diagram loading and added error details when a diagram couldn’t be rendered

> Manage Bluetooth Devices : AirPods battery levels now stay up to date as the device reports them

> UI : Improved handling of toast/hud dismissal, fixing recurring issue of toast/hud reappearing after dismissal

> UI : Added support for pending + progress display in HUDs

> UI : HUDs and in-window toasts can now be dismissed

Source: https://www.raycast.com/changelog/windows/2-9
