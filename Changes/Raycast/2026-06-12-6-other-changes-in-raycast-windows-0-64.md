**Raycast** · 2026-06-12 · Other changes · Digest · [Official source](https://www.raycast.com/changelog/windows/0-64) · from [[Releases/Raycast/raycast-2026-06-12-windows-0-64-b12c3d44|Raycast windows 0.64]]

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Window Management : Toggle Always on Top. Pin the focused window so it stays above all others. Run it again to unpin.

> Clipboard History: Better query matching for non-Latin alphabets (e.g. Cyrillic, CJK)

> Clipboard History : Improved UX of "… and Keep Window Open" actions by delaying the state update so items aren't reordered yet

> Run : Improved view layout

> System : Add ability to skip confirmation for emptying the recycle bin

> AI : Markdown streaming is more stable with reduced flashes of incorrectly parsed content
