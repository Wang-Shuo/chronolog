# 7 other changes in Raycast macos 0.57

**Raycast** · 2026-05-08 · Other changes · Digest · [Official source](https://www.raycast.com/changelog/macos/0-57) · from [[Releases/Raycast/raycast-2026-05-08-macos-0-57-0bde5a1b|Raycast macos 0.57]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Quicklinks : Added ability to create a Quicklink from a URL typed in Root Search

> Core : Enhanced paste actions throughout the app to show the receiving (frontmost) app name/icon

> Import : Added a progress toast when importing from the Welcome view

> Import : Improved UX when an incorrect password is entered

> AI Chat : Deleting all chats in AI Chat no longer deletes pinned chats

> Core : Ensured move favorite / move pinned actions use the same shortcuts

> Snippets : We now respect the Injection Delay setting when injecting snippets

Source: https://www.raycast.com/changelog/macos/0-57
