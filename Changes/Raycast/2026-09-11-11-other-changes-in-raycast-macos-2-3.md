# 11 other changes in Raycast macos 2.3

**Raycast** · 2026-09-11 · Other changes · Digest · [Official source](https://www.raycast.com/changelog/macos/2-3) · from [[Releases/Raycast/raycast-2026-09-11-macos-2-3-56ab676e|Raycast macos 2.3]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> AI: Press ⌘ + F to find text in chat

> AI : Deleted chats now land in Recently Deleted , where you can restore them before they're permanently removed after a retention window of 60 days

> AI : Raycast now prevents your computer from sleeping while AI is running

> AI : Tool approval prompts now clearly explain the requested action and its impact, making them easier to review before continuing

> AI: Searching chats will now include content hits

> Clipboard History: Added AI tools to search entries by text, title, or text found in images, and to filter by type

> Clipboard History: Added AI tools to open a specific entry and rewrite its contents, with a confirmation step before anything is replaced

> File Search: Directories automatically excluded from indexing due to significant churn can now be permanently re-included via File Search Settings

> File Search: Exact term matches should now rank higher in results

> Root Search: Applications on external drives now appear as soon as the drive is mounted and are removed when it's ejected, instead of only after restarting Raycast

> Script Commands : Added support for using scripts with a text argument as fallback commands

Source: https://www.raycast.com/changelog/macos/2-3
