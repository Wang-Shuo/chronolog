**Raycast** · 2026-06-18 · [[Themes/voice|Voice and Audio]] · Digest · [Official source](https://www.raycast.com/changelog/windows/0-65) · from [[Releases/Raycast/raycast-2026-06-18-windows-0-65-d3330da5|Raycast windows 0.65]]

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Dictation : Using the “Copy to Clipboard” output mode no longer adds transcriptions to Clipboard History

> Dictation : Allow pasting of comma separated items into vocabulary, accessible via the Vocabulary command or settings

> Dictation : Microphone audio is automatically boosted during dictation sessions for improved transcription accuracy.
