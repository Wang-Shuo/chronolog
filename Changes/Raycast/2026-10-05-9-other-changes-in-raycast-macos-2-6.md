# 9 other changes in Raycast macos 2.6

**Raycast** · 2026-10-05 · Other changes · Digest · [Official source](https://www.raycast.com/changelog/macos/2-6) · from [[Releases/Raycast/raycast-2026-10-05-macos-2-6-9acb3bc3|Raycast macos 2.6]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Clipboard History : Added a Paste as PNG action for TIFF images

> UI : Added automatic color contrast adjustments throughout to ensure the UI remains legible

> AI Permissions: Extended Always Allow approvals to cover similar commands

> Clipboard History : Improved contrast of color swatch in color items

> Eject All Disks : Improved support for external drives and disk images, and added details about disks that could not be ejected

> General : Improved reliability when your Mac wakes from sleep

> Quick AI : Added an option to hide the Quick AI hint in Root Search

> Root Search : Added support for numpad for number hotkeys

> UI : Ensured consistent window-blurred icon opacity between single/grouped buttons

Source: https://www.raycast.com/changelog/macos/2-6
