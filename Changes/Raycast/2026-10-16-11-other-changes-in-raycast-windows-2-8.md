# 11 other changes in Raycast windows 2.8

**Raycast** · 2026-10-16 · Other changes · Digest · [Official source](https://www.raycast.com/changelog/windows/2-8) · from [[Releases/Raycast/raycast-2026-10-16-windows-2-8-bbe2969f|Raycast windows 2.8]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Emoji & Symbols : Added Greek letters

> Notes : Cmd+click on a parent todo now toggles all nested todos

> AI Chat : Added a primary action setting to Send Window and Send Element to AI

> AI Chat : Clarified when you’ve reached the weekly Claude Fable usage limit

> AI Chat : Reduced the data sent at the start of a chat by loading extension tools more selectively

> Clipboard History : Improved image & file icons

> Core : Raycast now recovers on its own when the WebView2 browser process crashes or is killed

> Proxy : Raycast now honors HTTP_PROXY, HTTPS_PROXY and NO_PROXY for all its traffic.

> Root Search : Commands are grouped by extension when search field is empty

> AI Chat : Pasting a link copied from Edge's address bar into the composer now inserts the URL rather than the page title

> Window Management : Ignored hotkeys for missing layouts and custom commands

Source: https://www.raycast.com/changelog/windows/2-8
