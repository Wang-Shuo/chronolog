# 5 other changes in Raycast windows 0.32

**Raycast** · 2025-10-10 · Other changes · Digest · [Official source](https://www.raycast.com/changelog/windows/0-32) · from [[Releases/Raycast/raycast-2025-10-10-windows-0-32-e5584173|Raycast windows 0.32]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Root Search: You can now go back to previous searches by pressing the ArrowUp key

> Root Search: Added a new Uninstall Application action for applications

> Clipboard History : non-qualified links are now categorised/previewed correctly

> Quicklinks: User-created Quicklinks are now separated from normal commands in settings

> Snippets : Text is now selectable in the snippet preview
