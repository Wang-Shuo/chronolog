# 4 other changes in Raycast macos-v1 1.47.0

**Raycast** · 2023-02-01 · Other changes · Digest · [Official source](https://www.raycast.com/changelog/macos-v1/1-47-0) · from [[Releases/Raycast/raycast-2023-02-01-macos-v1-1-47-0-2d2d6708|Raycast macos-v1 1.47.0]]

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Preferences: Add a preference to replace ⌃⌥⌘⇧ by ✦ (hyper key).

> Snippets: Add an action to delete all local snippets.

> Snippets: The - and _ characters are no longer treated as delimiters when using the After Delimiter expansion options. So they can safely be used in snippet keywords.

> AppUpdates: I mproved permissions handling for users working on non-admin accounts.
