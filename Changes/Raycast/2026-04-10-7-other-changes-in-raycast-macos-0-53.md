# 7 other changes in Raycast macos 0.53

**Raycast** · 2026-04-10 · Other changes · Digest · [Official source](https://www.raycast.com/changelog/macos/0-53) · from [[Releases/Raycast/raycast-2026-04-10-macos-0-53-d57fb79a|Raycast macos 0.53]]

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Hyper Key : Added better diagnostics for conflicting applications detection.

> Keyboard Settings: Added “Escape Key Closes Window” in Keyboard settings.

> Advanced Settings: Added “Window Activation Behavior” to select whether window move to the active space or the user is moved to the window space.

> Root Search: Enable drag & drop for Applications

> Snippets: Improved snippet injection within Raycast

> Hyper Key: Improve diagnostics and keyboard reconnection handling

> Clipboard History: Improved pasting reliability for some applications (cmux)
