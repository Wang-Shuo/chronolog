# 15 other changes in Raycast windows 0.34

**Raycast** · 2025-10-29 · Other changes · Digest · [Official source](https://www.raycast.com/changelog/windows/0-34) · from [[Releases/Raycast/raycast-2025-10-29-windows-0-34-1b9f7b28|Raycast windows 0.34]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Window Management : New extension to move and scale your windows.

> Clipboard History : Added alternative “Keep Open” actions for copy/paste.

> Clipboard History : Added a new Open With… action.

> Clipboard History : Added a new Show in File Explorer action.

> Clipboard History : Added a new Copy Color as… action.

> Clipboard History : Added a new Save as File… action.

> Clipboard History: Added “Primary Action” setting to choose between the “Paste to Active App” and “Copy to Clipboard actions.

> Clipboard History: Added “Show visual information for links” setting to opt-out from displaying favicons and link previews.

> File Search : Added a new Open With… action.

> File Search : Added a new Paste File action.

> Snippets : Added a new Export Snippet… action.

> Root Search: commands now have a Favorite action that let you place your favorite commands at the top.

> Quick AI : Inline sources in text are now less visually prominent with a more detailed source summary at the bottom of the text.

> Clipboard History : We now correctly ignore empty entries.

> Quicklinks: Quicklinks with default argument placeholders now work in Root Search.

Source: https://www.raycast.com/changelog/windows/0-34
