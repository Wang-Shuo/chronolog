# 9 other changes in Raycast windows 0.35

**Raycast** · 2025-11-06 · Other changes · Digest · [Official source](https://www.raycast.com/changelog/windows/0-35) · from [[Releases/Raycast/raycast-2025-11-06-windows-0-35-f7079e0b|Raycast windows 0.35]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Games : New extension to search and start your games all in one place.

> Clipboard History : Added “Automatic Text Recognition” setting. Text content in images will be recognized automatically. This enables you to search images by their text content. You can also copy the text from an image using the “Copy Text from Image” action.

> Clipboard History : Added “Disabled Applications” setting. Use this filter to opt-out certain applications from having their content saved in Clipboard History.

> Clipboard History : Improved email handling, we better differentiate emails from links. There is now a new “Email” category.

> Clipboard History : Do not store sensitive data in the history.

> General : Added support for Numpad Enter key throughout the UI.

> General : Improved fuzzy matching in menus.

> Startup: We now check if the app’s databases are set up correctly and will show an alert with recovery options at startup if there are any issues.

> File Search : .rayignore files created by the “Exclude from index” action are now correctly marked as hidden files.

Source: https://www.raycast.com/changelog/windows/0-35
