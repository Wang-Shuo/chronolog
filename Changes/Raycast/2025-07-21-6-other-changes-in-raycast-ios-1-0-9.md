# 6 other changes in Raycast ios 1.0.9

**Raycast** · 2025-07-21 · Other changes · Digest · [Official source](https://www.raycast.com/changelog/ios/1-0-9) · from [[Releases/Raycast/raycast-2025-07-21-ios-1-0-9-e973a197|Raycast ios 1.0.9]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> AI: Support for file attachments in chat

> AI : Access Kimi K2 by Moonshot AI

> Notes: You can now perform ad-hoc prompting by using Ask AI in notes

> AI: Chat will now scroll to the last item when loading an old chat

> Misc : Added a button to paste and open commands with a single argument content field

> Misc: Previously, recordings of more than 10 mins would fail in AI composer and in notes. There should be no limit anymore
