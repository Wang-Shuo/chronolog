# 15 other changes in Raycast ios 1.2.0

**Raycast** · 2025-12-05 · Other changes · Digest · [Official source](https://www.raycast.com/changelog/ios/1-2-0) · from [[Releases/Raycast/raycast-2025-12-05-ios-1-2-0-e4453aa3|Raycast ios 1.2.0]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Home: Drag and drop to sort favorites

> AI: Support for code blocks which also can be copied

> AI: Drag and drop to sort presets in overlay

> AI: Snappier keyboard animation when activating the composer

> AI: Fade-in animation when streaming response

> AI: New loading indicator when generating response

> AI: Support for additional Markdown elements: images, dividers, strikethrough, blockquotes, and links in headers

> Home: Rebuilt from scratch, should feel a lot smoother and more performant

> AI: Keep keyboard open when scrolling chat

> AI: Always make sure bottom content is visible when keyboard gets activated

> AI: Swipe up inside composer to activate

> AI: Improved and more informative error messaging

> AI: Automatically show keyboard when creating new chat

> Lists: Improved logic to remember scroll position in AI, Notes, Quicklinks and Snippets lists

> Lists: Improved animations and transition to search

Source: https://www.raycast.com/changelog/ios/1-2-0
