# 7 other changes in Raycast windows 0.71

**Raycast** · 2026-08-19 · Other changes · Digest · [Official source](https://www.raycast.com/changelog/windows/0-71) · from [[Releases/Raycast/raycast-2026-08-19-windows-0-71-774d965e|Raycast windows 0.71]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Quick AI : “Send Message” AI setting is now respected by Quick AI as well which allows submitting queries on Control Return

> Hotkeys: You can now assign single or double tap modifiers as hotkeys

> Capture Window : Screenshots saved for the Store are now normalized to the required 2000×1250 size, and the Store option is only offered when capturing the main window

> Game Launcher : Games installed through Riot Games, Rockstar Games, Battlestate Games, and Roblox are now discovered automatically

> Hyperkey: works on JIS keyboards, which means VK_DBE_ALPHANUMERIC can now be used as Hyperkey

> System: “Empty Recycle Bin” HUD feedback is improved

> Quicklook: swaps the previewed file instead of closing when you preview a different image from AI Chat

Source: https://www.raycast.com/changelog/windows/0-71
