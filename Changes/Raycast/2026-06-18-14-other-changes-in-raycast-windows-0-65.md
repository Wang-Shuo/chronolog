# 14 other changes in Raycast windows 0.65

**Raycast** · 2026-06-18 · Other changes · Digest · [Official source](https://www.raycast.com/changelog/windows/0-65) · from [[Releases/Raycast/raycast-2026-06-18-windows-0-65-d3330da5|Raycast windows 0.65]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Quick AI : Redesigned interface with a more powerful composer at the bottom and a look that is closer to AI Chat

> Manual : New Ask Manual AI Extension

> AI : Custom AI commands now have an Output Behavior setting, so you can choose to open them in Raycast or replace selected text in place

> Translator : Custom translate commands now have an Output Behavior setting, so you can choose to open them in Raycast or replace selected text in place

> AI : Removed flashes of incorrectly parsed content during streaming

> AI : Improved retry logic for failed requests

> Updates : “What's New” now appears only for notable releases

> Focus : Added Zen Browser support

> Core : Disabled acrylic background for non-topmost windows

> File Search: Multiple queries are no longer emitted as you type

> File Search: While a new search query fetches results, existing results are no longer cleared

> Root Search: File URLs now correctly resolve filesystem entries if they exist

> UI : Use correct button order in alerts

> Updates: F ixed “New update Available” not being visible in certain scenarios

Source: https://www.raycast.com/changelog/windows/0-65
