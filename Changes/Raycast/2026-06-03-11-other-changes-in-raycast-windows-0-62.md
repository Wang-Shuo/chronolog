# 11 other changes in Raycast windows 0.62

**Raycast** · 2026-06-03 · Other changes · Digest · [Official source](https://www.raycast.com/changelog/windows/0-62) · from [[Releases/Raycast/raycast-2026-06-03-windows-0-62-00226600|Raycast windows 0.62]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Calculator: Enable color conversion from Calculator settings to start surfacing color results in root search

> Calculator : Type or paste any color value in root search to see an instant preview

> Calculator : Copy a converted color in any supported format — hex, rgb, hsl, and modern color spaces like Oklch and Lab

> System : Updated window closing, maximization, and restore animations

> System : Increased the window title bar height

> Calendar : Parse “safe links” to get the meeting urls

> Quicklinks : Improve support for quicklinks to Raycast deeplinks

> Games : Added support for favoriting games

> System : Do not show "Unable to toggle system appearance” when System appearance changes

> Translator : Show source text in the target panel when the source and target languages are the same

> Script Commands : Handle ANSI output

Source: https://www.raycast.com/changelog/windows/0-62
