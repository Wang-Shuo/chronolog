# We made several memory and performance improvements

**Raycast** · 2026-10-05 · [[Themes/reliability-performance|Reliability and Performance]] · [Official source](https://www.raycast.com/changelog/macos/2-6) · from [[Releases/Raycast/raycast-2026-10-05-macos-2-6-9acb3bc3|Raycast macos 2.6]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> We made several memory and performance improvements. Raycast's host process now uses about 50% less memory. Each extension process uses about 30% less memory at startup and less CPU when launching, which helps menu bar commands, background refreshes, and AI tools. We also fixed a memory leak that grew the longer Raycast stayed open. More details are below, and further improvements are coming in the next updates.
>
