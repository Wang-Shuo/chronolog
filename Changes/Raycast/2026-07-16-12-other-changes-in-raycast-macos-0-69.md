# 12 other changes in Raycast macos 0.69

**Raycast** · 2026-07-16 · Other changes · Digest · [Official source](https://www.raycast.com/changelog/macos/0-69) · from [[Releases/Raycast/raycast-2026-07-16-macos-0-69-aa9bbacf|Raycast macos 0.69]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Cloud Sync: Customize what gets synced across your devices

> Cloud Sync: Manage your synced devices

> Root Search : Added ability to show favorites in compact mode

> AI : \<br> tags in AI markdown now render as line breaks

> AI : @-mentions left in the composer when closing AI Chat get preserved when re-opening AI Chat again

> AI Chat : Consecutive tool calls get collapsed into a group to reduce visual clutter

> Database: Improved database recovery when the Application Support folder has been mistakenly removed or there is a transient keychain failure

> Raycast Focus: Support Focus Categories in Import & Export Settings & Data

> UI : Improved ghost dropdown button design (Settings selects)

> Window Management : layout previews now show a hint when width or height are set to auto

> Hyper Key: Improved Quick Press ABC input source switch reliability

> File Search: File Search no longer prevents Raycast from launching if the user’s disk is full

Source: https://www.raycast.com/changelog/macos/0-69
