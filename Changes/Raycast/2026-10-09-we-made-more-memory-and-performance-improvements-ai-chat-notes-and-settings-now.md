# We made more memory and performance improvements

**Raycast** · 2026-10-09 · [[Themes/memory|Memory and Personalization]] · [Official source](https://www.raycast.com/changelog/macos/2-7) · from [[Releases/Raycast/raycast-2026-10-09-macos-2-7-72853197|Raycast macos 2.7]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> We made more memory and performance improvements. AI Chat, Notes and Settings now each run in their own process, so a busy chat or a heavy note no longer slows down Root Search, and closing them frees up their memory. The launcher can use up to 35% less memory while idle. File Search uses up to 80% less memory at peak and up to 95% less while searching, searches are up to 30% faster, and background indexing uses much less CPU. More details are below.
>
> Source: https://www.raycast.com/changelog/macos/2-7
