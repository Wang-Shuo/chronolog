# 11 other changes in Raycast macos 2.8

**Raycast** · 2026-10-16 · Other changes · Digest · [Official source](https://www.raycast.com/changelog/macos/2-8) · from [[Releases/Raycast/raycast-2026-10-16-macos-2-8-5f7981fc|Raycast macos 2.8]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Calendar : Added support for joining Gong meetings

> Emoji & Symbols : Added Greek letters

> Notes : Cmd+click on a parent todo now toggles all nested todos

> AI Chat : Reduced the data sent at the start of a chat by loading extension tools more selectively

> AI Chat : Clarified when you’ve reached the weekly Claude Fable usage limit

> AI Chat : Added a primary action setting to Send Window and Send Element to AI

> Clipboard History : Improved image & file icons

> Proxy : Raycast now honors HTTP_PROXY, HTTPS_PROXY and NO_PROXY for all its traffic.

> Updater: Detect an update installed from another user account on the same Mac

> Window Management : Ignored hotkeys for missing layouts and custom commands

> Updater: Raycast now relaunches itself if an update or restart fails after the app was already closed

Source: https://www.raycast.com/changelog/macos/2-8
