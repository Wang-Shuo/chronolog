# 3 Interface Experience changes in Raycast macos 0.71

**Raycast** · 2026-08-19 · [[Themes/interface-experience|Interface Experience]] · Digest · [Official source](https://www.raycast.com/changelog/macos/0-71) · from [[Releases/Raycast/raycast-2026-08-19-macos-0-71-666f2816|Raycast macos 0.71]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Hotkeys : Added support for chords using a modifier held on both sides of the keyboard (e.g. left ⌘ + right ⌘), including recording and display in the hotkey recorder

> Emoji Picker : Added the missing "Copy with Skin Tone…" action

> Hotkeys : The recorder now detects and warns about combinations that can't coexist with an existing hotkey, instead of flagging only identical ones (e.g. single-tap ⌘ vs double-tap ⌘⌘)

Source: https://www.raycast.com/changelog/macos/0-71
