# 9 other changes in Raycast macos 0.56

**Raycast** · 2026-05-08 · Other changes · Digest · [Official source](https://www.raycast.com/changelog/macos/0-56) · from [[Releases/Raycast/raycast-2026-05-08-macos-0-56-0dfd8c64|Raycast macos 0.56]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Quick AI : Got a design refresh which is closer to AI Chat with a composer at the bottom and support for multiline, attachments, and more

> AI Chat and Quick AI : Allow scrolling with page up and page down keys

> AI Settings : Split AI Settings into multiple sub-views for better organization

> General : We now better handle international keyboard layouts , both in built-in shortcuts in the Action Panel which are now key-equivalent, as well as for global hotkeys were we now correctly represent the printed character based on the currently active layout

> Window Capture : Increased the padding of the window to make screenshots look more airy

> Quicklinks: Added Open With… and Show in Finder actions

> Snippets: You can now search for snippets by keyword

> Import: Improved handling of ad-hoc/untitled AI Commands

> Misc: Hide traffic light buttons from the launcher window

Source: https://www.raycast.com/changelog/macos/0-56
