# 13 other changes in Raycast windows 0.67

**Raycast** · 2026-07-03 · Other changes · Digest · [Official source](https://www.raycast.com/changelog/windows/0-67) · from [[Releases/Raycast/raycast-2026-07-03-windows-0-67-6799247d|Raycast windows 0.67]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> AI : AI can ask you multiple choice questions through the Ask User Question tool when requiring extra information or when it’s not certain about something

> AI Chat : Long user messages collapse to take less space away with ability to expand them when needed

> File Search : Settings now have a “Reset to Defaults” button to restore all default Search Scopes and ignore patterns

> File Search : File Search now has a “Enforce Low Disk Space Block” to prevent File Search from indexing if you do not have enough disk space where Raycast is installed

> System Actions : The Bluetooth toggle now shows its on/off state in the HUD

> Core : Reduced CPU usage when detecting running applications

> Core : Startup time has been improved in certain environments

> Hotkeys : Hyperkey now disables the Caps Lock state when it prevents using it

> Notes : The default window position is now in the top-right corner of the active display

> Notes : The window will now open on the currently active display

> System : Improved support for third-party file explorers

> Focus : Improved Zen browser support

> Root Search : Improved width handling of search arguments (inputs and select menus)

Source: https://www.raycast.com/changelog/windows/0-67
