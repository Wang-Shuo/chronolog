# 12 other changes in Raycast windows 0.68

**Raycast** · 2026-07-09 · Other changes · Digest · [Official source](https://www.raycast.com/changelog/windows/0-68) · from [[Releases/Raycast/raycast-2026-07-09-windows-0-68-0faac2dd|Raycast windows 0.68]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> AI Chat : Get more granular control on which tool calls run automatically with the new Always Allow list

> Auto Quit : Now you can automatically quit applications after a period of inactivity

> Focus : Arc browser support

> File Previews : Allowed SVGs to be previewed as images rather than code

> Hyperkey : Trigger Escape quick action now works for Raycast windows as well

> Notifications : now have a smooth fade out animation

> Startup : Improved startup task reliability

> Focus : Improved Zen Browser support

> Quicklinks : using Windows paths should work correctly when migrating from an older version now

> Search Arguments : Added missing badge for optional args

> Search Arguments : Consistently ensured we don’t allow submitting with incomplete args (Root Search, Snippets, Quicklinks, AI commands, etc)

> Theme Studio : Added closing support on ESC press and updated activation logic

Source: https://www.raycast.com/changelog/windows/0-68
