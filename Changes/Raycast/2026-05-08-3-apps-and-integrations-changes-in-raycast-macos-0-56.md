# 3 Apps and Integrations changes in Raycast macos 0.56

**Raycast** · 2026-05-08 · [[Themes/apps-integrations|Apps and Integrations]] · Digest · [Official source](https://www.raycast.com/changelog/macos/0-56) · from [[Releases/Raycast/raycast-2026-05-08-macos-0-56-0dfd8c64|Raycast macos 0.56]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> AI : Now that AI Extensions are available, we are introducing a way for extensions to be loaded automatically depending on the request. No need to tag AI extensions anymore - but you can do it to force its usage.

> MCP : You can now install MCP servers and use them in Quick AI and AI Chat

> Import: Added support for importing local (development) extensions during migration
