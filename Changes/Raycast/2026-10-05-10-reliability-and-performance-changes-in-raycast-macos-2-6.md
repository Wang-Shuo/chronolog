# 10 Reliability and Performance changes in Raycast macos 2.6

**Raycast** · 2026-10-05 · [[Themes/reliability-performance|Reliability and Performance]] · Digest · [Official source](https://www.raycast.com/changelog/macos/2-6) · from [[Releases/Raycast/raycast-2026-10-05-macos-2-6-9acb3bc3|Raycast macos 2.6]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> AI Chat : Mermaid diagrams now load only when a chat first needs them, which reduces memory usage

> Extensions : Improved performance when extensions refresh frequently in the background

> Memory Usage : Reduced idle memory use and improved memory cleanup after closing Raycast windows by releasing retained graphics memory

> Memory Usage : Reduced memory overhead from command icons

> Memory Usage : Reduced extension worker memory by ~30% in idle workers

> Memory Usage : Reduced native host memory by 50%

> Memory Usage : Improved process memory diagnostic

> Performance: Reduced extensions worker startup CPU usage

> Performance: Speed up command launches and prevent misinput while commands are loading

> Root Search : Recent searches keep their results, so typing them again responds faster

Source: https://www.raycast.com/changelog/macos/2-6
