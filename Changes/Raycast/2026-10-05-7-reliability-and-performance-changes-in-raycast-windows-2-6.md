**Raycast** · 2026-10-05 · [[Themes/reliability-performance|Reliability and Performance]] · Digest · [Official source](https://www.raycast.com/changelog/windows/2-6) · from [[Releases/Raycast/raycast-2026-10-05-windows-2-6-d311ff25|Raycast windows 2.6]]

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> AI Chat : Mermaid diagrams now load only when a chat first needs them, which reduces memory usage

> Extensions : Improved performance when extensions refresh frequently in the background

> Memory Usage : Reduced memory overhead from command icons and deferred loading diagram support until needed

> Memory Usage : Reduced memory used by file indexing

> Memory Usage : Reduced memory use in idle extension workers

> Performance : Reduced extension worker startup CPU usage

> Root Search : Recent searches keep their results, so typing them again responds faster
