# 5 other changes in Raycast windows 2.4

**Raycast** · 2026-09-14 · Other changes · Digest · [Official source](https://www.raycast.com/changelog/windows/2-4) · from [[Releases/Raycast/raycast-2026-09-14-windows-2-4-f4b95aa8|Raycast windows 2.4]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> AI Chat : Copying or pasting a response now takes only the final answer, leaving out the working narration that came before it

> Script Commands : Scripts now run from their own folder by default, with support for relative and home-directory paths

> System : Toggle HDR, Toggle Night Light, Toggle Hidden Files and Toggle System Appearance now confirm the resulting state

> Emoji & Symbols : Fixed searches containing double quotes failing to return results

> Raycast Focus & Calendar : Fixed duration inputs such as “until 15:00” and “until 3pm” not being recognised

Source: https://www.raycast.com/changelog/windows/2-4
