<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> File Search : Network and removable drive entries should no longer be lost on startup

> File Search : Exclusion patterns in Settings and ignore files should now handle case-sensitivity correctly

> File Search : Indexing the filesystem root ( / ) is now allowed (but not recommended)

> Migration: Added missing settings for Start Typing Practice and Calculator History commands

> Migration: Added a fallback for Raycast v1 discovery if Spotlight is disabled
