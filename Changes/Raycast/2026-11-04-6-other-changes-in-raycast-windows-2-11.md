# 6 other changes in Raycast windows 2.11

**Raycast** · 2026-11-04 · Other changes · Digest · [Official source](https://www.raycast.com/changelog/windows/2-11) · from [[Releases/Raycast/raycast-2026-11-04-windows-2-11-94c55091|Raycast windows 2.11]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> AI Chat : Allowed renaming chats before the first response finishes

> Proxy : Added support for proxy auto-configuration (PAC) scripts when Use System Proxy Settings is on

> Proxy : Proxy setting changes now apply without restarting Raycast

> System : Improved reliability of foreground window switching

> AI Chat & Quick AI : Fixed resumed background tasks and AI commands unexpectedly asking for input

> Updates : Raycast now reopens if an update fails to install

Source: https://www.raycast.com/changelog/windows/2-11
