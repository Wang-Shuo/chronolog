# 7 other changes in Raycast windows 0.70

**Raycast** · 2026-07-23 · Other changes · Digest · [Official source](https://www.raycast.com/changelog/windows/0-70) · from [[Releases/Raycast/raycast-2026-07-23-windows-0-70-a1c03cc9|Raycast windows 0.70]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> AI : Changed links in markdown to blue color to make them more visible

> AI Chat : Simplified and cleaned up the layout of the composer, confirmation prompts and questions asked back to the user

> Cloud Sync: Added support for networks that use TLS-inspecting proxies (common in corporate setups) — Raycast now trusts the system certificate store and user-installed certificates, and shows a clearer status when a network blocks the secure connection

> Cloud Sync: The Synced Content view now shows real progress while duplicate items are being cleaned up

> Cloud Sync: Syncing a large backlog now runs in small, paced batches and pauses itself when it would slow down what you're doing, so the app stays responsive during big catch-ups

> AI: Branching a chat now duplicates its attachments, so the new branch keeps its files

> Translator : Result text area can now be selected

Source: https://www.raycast.com/changelog/windows/0-70
