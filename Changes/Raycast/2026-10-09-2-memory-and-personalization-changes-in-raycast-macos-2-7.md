# 2 Memory and Personalization changes in Raycast macos 2.7

**Raycast** · 2026-10-09 · [[Themes/memory|Memory and Personalization]] · Digest · [Official source](https://www.raycast.com/changelog/macos/2-7) · from [[Releases/Raycast/raycast-2026-10-09-macos-2-7-72853197|Raycast macos 2.7]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> File Search : Improved CPU and memory utilization. It now uses up to 80% less memory at peak and up to 95% less while searching. Searches are also up to 30% faster, depending on the search terms and number of documents

> Memory & Performance: AI Chat, Notes and Settings now each run in their own process, separate from the launcher. A busy AI Chat or a heavy note no longer slows down Root Search, closed windows free their memory after a cooldown period so Raycast uses less while idle, and it's easier to see which part of Raycast is using memory or CPU

Source: https://www.raycast.com/changelog/macos/2-7
