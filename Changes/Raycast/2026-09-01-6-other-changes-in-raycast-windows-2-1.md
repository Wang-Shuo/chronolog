# 6 other changes in Raycast windows 2.1

**Raycast** · 2026-09-01 · Other changes · Digest · [Official source](https://www.raycast.com/changelog/windows/2-1) · from [[Releases/Raycast/raycast-2026-09-01-windows-2-1-62e6c367|Raycast windows 2.1]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Applications : App icons now follow the light/dark appearance, so monochrome icons like ChatGPT's are no longer invisible in dark mode

> Updater : Raycast now relaunches itself after an update installed by the Microsoft Store or winget, instead of staying closed until the next logon

> Windows Settings : Settings are now filtered by your device's capabilities, so entries like lid actions only show up on laptops

> Windows Settings : Settings are grouped into browsable sections instead of one flat list

> Windows Settings : Settings have shorter, more searchable names, and irrelevant Windows entries like "Set up a kiosk" are gone.

> Clipboard History : Ensured pasting non-full entries can still correctly update history (ie. paste as plain text)

Source: https://www.raycast.com/changelog/windows/2-1
