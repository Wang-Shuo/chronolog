# 7 other changes in Raycast windows 0.21

**Raycast** · 2025-04-10 · Other changes · Digest · [Official source](https://www.raycast.com/changelog/windows/0-21) · from [[Releases/Raycast/raycast-2025-04-10-windows-0-21-2b5e1759|Raycast windows 0.21]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Added an Open in Browser quick action to links in Clipboard History

> Added support for shortcuts that use URI handlers. This enables your Steam applications to be launched through Raycast.

> Clipboard history entries are now deduplicated, so when you copy the same content multiple times, it only appears once in your history. Deduplication only applies to new entries.

> Copied files that are images now show up in the images category in clipboard history in addition to the files category.

> The emoji search has been tweaked to return more results.

> Quick Open will not appear if there is a space in the search term. This is to prevent it from appearing for search queries.

> Updated our in-app social links.

Source: https://www.raycast.com/changelog/windows/0-21
