# 7 other changes in Raycast macos 0.55

**Raycast** · 2026-04-27 · Other changes · Digest · [Official source](https://www.raycast.com/changelog/macos/0-55) · from [[Releases/Raycast/raycast-2026-04-27-macos-0-55-cf37c451|Raycast macos 0.55]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Window Management: New Switch to Next Space and Switch to Previous Space commands to change Space without animations

> AI : Raycast is now able to handle large amounts of AI data better in various places like Quick AI, AI Chat and AI Settings

> AI : Restructured AI Settings by moving sections into sub-pages

> Import: Fallback commands should now be included when importing from Classic.

> Clipboard History : Save as File now supports images

> Hyper Key: Support for the “Use Caps Lock to switch input sources” system setting. If you have Hyper Key set to “Caps Lock” and Quick Press to “Trigger Caps Lock”, pressing Caps Lock quickly will switch input sources if you have the system setting mentioned above enabled.

> Hyper Key Diagnostics : Diagnostics are now visible even when Hyper Key is healthy, and BetterTouchTool conflict is shown as a warning (not blocking)

Source: https://www.raycast.com/changelog/macos/0-55
