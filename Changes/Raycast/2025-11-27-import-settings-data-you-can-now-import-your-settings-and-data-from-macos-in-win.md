# Import Settings & Data : You can now import your settings and data from macOS in Windows

**Raycast** · 2025-11-27 · [[Themes/mobile-desktop|Mobile and Desktop]] · [Official source](https://www.raycast.com/changelog/windows/0-38) · from [[Releases/Raycast/raycast-2025-11-27-windows-0-38-753ad6ba|Raycast windows 0.38]]

> Import Settings & Data : You can now import your settings and data from macOS in Windows. Use the Export Settings & Data command on macOS, transfer the rayconfig file, then use the Import Settings & Data command on Windows. Currently import supports Quicklinks, Snippets and some settings.
