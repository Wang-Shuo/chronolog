# 4 Reliability and Performance changes in Raycast windows 2.8

**Raycast** · 2026-10-16 · [[Themes/reliability-performance|Reliability and Performance]] · Digest · [Official source](https://www.raycast.com/changelog/windows/2-8) · from [[Releases/Raycast/raycast-2026-10-16-windows-2-8-bbe2969f|Raycast windows 2.8]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Core : Improved performance all over the application, which should fix issues such as when Raycast is slow to show up after being idle for a while

> Extensions : Installs and updates are about 4× faster on average, and up to 30× faster

> File Search : Results show up to 6× faster, slow searches are gone, and typos are handled much better

> Smoother scrolling : Root Search and other lists scroll up to 2× faster

Source: https://www.raycast.com/changelog/windows/2-8
