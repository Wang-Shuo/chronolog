# 5 other changes in Raycast windows 2.0

**Raycast** · 2026-08-25 · Other changes · Digest · [Official source](https://www.raycast.com/changelog/windows/2-0) · from [[Releases/Raycast/raycast-2026-08-25-windows-2-0-327831d3|Raycast windows 2.0]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> AI : Code blocks now render tabs at four-space width

> Focus : Added Floorp browser support

> System : Sleep and wake are now detected reliably on modern laptops, so background work pauses during standby and Raycast is responsive again immediately after waking

> Windows Settings : Root search now covers every individual setting from the Windows settings catalog and every Control Panel tasks

> Windows Settings : The Settings window groups Windows settings into the same categories Windows uses, instead of one flat list

Source: https://www.raycast.com/changelog/windows/2-0
