# 12 other changes in Raycast macos 2.7

**Raycast** · 2026-10-09 · Other changes · Digest · [Official source](https://www.raycast.com/changelog/macos/2-7) · from [[Releases/Raycast/raycast-2026-10-09-macos-2-7-72853197|Raycast macos 2.7]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Script Commands : Added controls to enable or disable background refresh for individual scripts

> AI Skills : Improved error details to help AI recover when a skill cannot be loaded

> File Search : Common development environment caches (e.g. .cargo/global-cache , .venv ) are now excluded from indexing

> File Search: Added image dimensions to the details panel

> Root Search : Improved ranking to favor complete words and exact title matches while preserving results learned from your previous searches

> Root Search : Prioritized applications when results are otherwise equally relevant

> Startup : Raycast now waits for the keychain to become available instead of showing "Failed to start". If it waits more than 10 seconds, it tells you what it's waiting for

> Feedback : Allowed Escape to close the window, respecting the user preference

> File Search : Brought back the Raycast v1 shortcut ⌘ + I for Show Info in Finder

> Notes : Made sure notes you create now keep working after future updates

> Quicklinks : Preserved favicons when “Open With” is a browser

> Root Search : Prevented Quicklink arguments retaining focus after execution

Source: https://www.raycast.com/changelog/macos/2-7
