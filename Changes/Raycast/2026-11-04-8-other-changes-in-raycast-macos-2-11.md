# 8 other changes in Raycast macos 2.11

**Raycast** · 2026-11-04 · Other changes · Digest · [Official source](https://www.raycast.com/changelog/macos/2-11) · from [[Releases/Raycast/raycast-2026-11-04-macos-2-11-dca1962c|Raycast macos 2.11]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Contacts : Added the Contacts AI Extension to search, create, update, and delete contacts from AI Chat

> Organizations : Added your organizations to root search to jump straight to their settings

> AI Chat : Allowed renaming chats before the first response finishes

> Notes : Checked tasks now move below the unchecked tasks of their group

> Notes : The pinned Notes window now stays visible when switching Spaces

> Proxy : Added support for proxy auto-configuration (PAC) scripts when Use System Proxy Settings is on

> Proxy : Proxy setting changes now apply without restarting Raycast

> AI Chat & Quick AI : Fixed resumed background tasks and AI commands unexpectedly asking for input

Source: https://www.raycast.com/changelog/macos/2-11
