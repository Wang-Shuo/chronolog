## Changes in this digest

> REM to PX Conversion: Type any REM or PX value into the calculator and see its conversion. Set your base REM value in the calculator settings

> Calculator: Added two new actions: "Swap Units" and "Copy Unformatted Answer"

> Calculator: The "Refresh Currencies" action now only appears for relevant currency conversions

> Changelog : Improved layout, added pagination and better search

> Compact Mode : Made is possible to expand when calling an action panel
