# 8 other changes in Raycast macos 2.5

**Raycast** · 2026-09-28 · Other changes · Digest · [Official source](https://www.raycast.com/changelog/macos/2-5) · from [[Releases/Raycast/raycast-2026-09-28-macos-2-5-b344e6c0|Raycast macos 2.5]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> AI Chat : Rename a chat by double-clicking its title in the top bar. Press Enter to save or Esc to cancel, and the window can still be dragged by the title

> File Search: Added a setting to entirely disable indexing of network/removable/virtual volumes

> File Search: Indexing now respects the .metadata_never_index marker file convention from Spotlight

> Diagnostics : Added a warning in Settings → About when another app’s Secure Input may interfere with Snippet Expansion or Hyper Key , with guidance on resolving it

> Script Commands : Added line wrapping to full output so long lines are easier to read

> AI Commands : Disabled automatic tool discovery and skill loading

> Crash: Improved recovery when the launcher displays a blank window due to a GPU process hang

> File Search: Classify NFS, VirtualBox and other mounted volumes correctly as non-local volumes

Source: https://www.raycast.com/changelog/macos/2-5
