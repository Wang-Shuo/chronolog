# 8 other changes in Raycast macos 2.4

**Raycast** · 2026-09-14 · Other changes · Digest · [Official source](https://www.raycast.com/changelog/macos/2-4) · from [[Releases/Raycast/raycast-2026-09-14-macos-2-4-2c7ef37f|Raycast macos 2.4]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> AI Chat : Copying or pasting a response now takes only the final answer, leaving out the working narration that came before it

> Calendar : Added support for opening events in BusyCal installed through Setapp

> Script Commands : Scripts now run from their own folder by default, with support for relative and home-directory paths

> Script Commands : Script commands now run with your regional locale, so dates, numbers and currency in their output match your system settings

> Startup : Added clearer instructions for restarting Raycast after cancelling Keychain access

> Emoji & Symbols : Fixed searches containing double quotes failing to return results

> Raycast Focus : Restored the glow and confirmation message when starting a session through a deeplink

> Raycast Focus & Calendar : Fixed duration inputs such as “until 15:00” and “until 3pm” not being recognized

Source: https://www.raycast.com/changelog/macos/2-4
