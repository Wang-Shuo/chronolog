# 30 other changes in Raycast macos 0.51

**Raycast** · 2026-03-27 · Other changes · Digest · [Official source](https://www.raycast.com/changelog/macos/0-51) · from [[Releases/Raycast/raycast-2026-03-27-macos-0-51-f8c9b4ea|Raycast macos 0.51]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> General : A new refreshed look and feel across the app. Redesigned for Tahoe.

> General : A new, simplified compact mode design

> General : Symlinks of Applications are now visible in Root Search

> Shortcuts : Assign hotkeys and aliases directly from the action panel in Root Search

> Quick AI: Redesigned to match AI Chat and with a more powerful composer

> AI Chat: Skills installed on the computer are now supported and load in dynamically

> AI Chat: Chats can be auto-archived after a set period of time

> AI Chat: Danger mode which bypasses all confirmation prompts

> File Search: Files and directories can now be found in Root Search

> Snippets : Added support for tagging

> Quicklinks : Added support for tagging

> Quicklinks : Added support for pinning

> Dynamic Placeholders: Added a new {calculator} dynamic placeholder. Available in Snippets, Quicklinks and AI Commands.

> Calculator : Added syntax highlighting

> Calculator : Inline translation with in suffix

> Clipboard: We can now save (and can restore) all original representations copied

> Clipboard : Added ability to rename clipboard entries

> Clipboard : Clipboard entries with multiple files/content are now grouped together

> Translator : Default language settings

> Translator : Create custom commands with predefined language pairs, so you can quickly translate between your most-used languages without selecting them each time.

> General : Raycast V2 Manual and links throughout the application

> General: Bigger font size

> Cloud Sync: Full Cloud Sync solution that will let you sync all of your data across platforms and Raycast versions.

> R aycast AI: Send to … AI chat commands

> Theming : Theme presets and the ability to create your own themes

> Window Management : Create Window Management Layout Commands

> Feature : Raycast Focus

> Feature : Auto Quit

> Affiliate Program: Become an Affiliate and Open Affiliate Dashboard Commands

> Calculator: Flight tracker

Source: https://www.raycast.com/changelog/macos/0-51
