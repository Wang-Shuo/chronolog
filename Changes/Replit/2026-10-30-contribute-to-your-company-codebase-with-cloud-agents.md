# Contribute to your company codebase with Cloud Agents

**Replit** · 2026-10-30 · [[Themes/agent-mode|Agent Mode]] · Launch · [Official source](https://docs.replit.com/updates/2026/10/30/changelog) · from [[Releases/Replit/replit-2026-10-30-2026-10-30-8c94fa6c|Replit updates — 2026-10-30]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> Turn an idea into a tested code change, even if you're not an engineer. Describe what should change, and a Replit Cloud Agent finds the relevant code, makes the change, tests it in your running app, and opens a GitHub pull request or GitLab merge request with screenshots and video.
>
> Your team sets up a shared development environment once. Changes run in isolated cloud sandboxes and follow your team's contribution guidelines. Engineers review the changes and stay in control of what ships.
>
> Learn how to [contribute to your company's codebase with Replit](https://docs.replit.com/build/code/code-with-replit.md).
>
