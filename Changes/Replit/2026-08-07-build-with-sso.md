# Build with SSO

**Replit** · 2026-08-07 · [[Themes/account-access|Account and Access]] · Launch · [Official source](https://docs.replit.com/updates/2026/08/07/changelog) · from [[Releases/Replit/replit-2026-08-07-2026-08-07-d8d80b64|Replit updates — 2026-08-07]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> Pro builders can now configure enterprise SSO for a Replit App that uses [Clerk Auth](https://docs.replit.com/features/auth-and-identity/clerk-auth.md). Ask Agent for the authentication change you need, and Agent directs you to the Clerk Dashboard. There, connect Okta or Microsoft Entra ID through OIDC or SAML. Enterprise SSO connections are free through October 1, 2026. After that, Clerk pass-through pricing applies. Enterprise availability is coming soon.
>
