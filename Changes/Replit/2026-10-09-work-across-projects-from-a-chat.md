# Work across projects from a chat

**Replit** · 2026-10-09 · [[Themes/context-window|Context Window]] · Launch · [Official source](https://docs.replit.com/updates/2026/10/09/changelog) · from [[Releases/Replit/replit-2026-10-09-2026-10-09-58884c93|Replit updates — 2026-10-09]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> You can now ask Replit to find your existing projects, read their files, and send tasks to them, all from a chat. Name a project or describe what it does, then use that context without switching between projects.
>
> Changes run as background tasks you can review, and nothing is published automatically.
>
> Bring a feature from one project to another, compare how your apps work, or draft documentation across several websites from a single chat.
>
> Ask Replit to use one project's features as a reference for another, all from a chat.
>
> Source: https://docs.replit.com/updates/2026/10/09/changelog
