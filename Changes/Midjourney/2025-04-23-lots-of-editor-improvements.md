# Lots of editor improvements

**Midjourney** · 2025-04-23 · [[Themes/editor-experience|Editor Experience]] · Launch · [Official source](https://updates.midjourney.com/editor-improvements-a/) · from [[Releases/Midjourney/midjourney-2025-04-23-https-updates-midjourney-com-editor-improvements-a-cbe424a2|Editor improvements and more]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> We've also opened up the external image editor to all membership tiers!
>
> We refreshed the full UI to make it simpler to edit and retexture images
>
> We combined editor experience for editing MJ images or external images. You can access the editor through the edit button in the sidebar, or via the 'Edit' button in the lightbox
>
> You can now import multiple images on layers. Use this to make creative collages of images or inventive new retextures
>
> Smart selection allows you to click on an object to be removed
>
> We've made the AI moderation smarter. You should see fewer prompts be blocked.
>
> Source: https://updates.midjourney.com/editor-improvements-a/
