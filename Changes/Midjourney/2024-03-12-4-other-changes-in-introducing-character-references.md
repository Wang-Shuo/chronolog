# 4 other changes in Introducing Character References

**Midjourney** · 2024-03-12 · Other changes · Digest · [Official source](https://updates.midjourney.com/character-refs/) · from [[Releases/Midjourney/midjourney-2024-03-12-https-updates-midjourney-com-character-refs-9f2821ed|Introducing Character References]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
## Changes in this digest

> Type --cref URL after your prompt with a URL to an image of a character

> You can use --cw to modify reference 'strength' from 100 to 0

> strength 100 ( --cw 100 ) is default and uses the face, hair, and clothes

> At strength 0 ( --cw 0 ) it'll just focus on face (good for changing outfits / hair etc)
