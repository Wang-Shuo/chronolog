<!-- chronolog:begin region="evidence" -->
> lots more changes on alpha.midjourney.com ! Same goal as before: make the site easier and more intuitive without taking away any of the control you have today. Some things will still be broken, but we're shipping often, so tell us if you find bugs.
>
> KOREAN! Speak/read Korean? This is the update for you. Interested in helping bring Midjourney to more languages? Sign up here .
>
> EDITING Lots of fixes on the v8.2 editor. The prompt bar now asks "What would you like to change?" when you attach an image. Draft batches show their source images in a grid with a hover preview, and offer Enhance, replacing a previously useless Upscale button.. The “Add to Folder" option now works from the editor even if you have no folders yet.
