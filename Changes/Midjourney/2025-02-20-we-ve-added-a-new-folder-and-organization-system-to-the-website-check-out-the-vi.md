**Midjourney** · 2025-02-20 · [[Themes/multimodal|Multimodal Input]] · [Official source](https://updates.midjourney.com/new-tools-for-organization/) · from [[Releases/Midjourney/midjourney-2025-02-20-https-updates-midjourney-com-new-tools-for-organization-e18c4a31|New Tools for Organization]]

<!-- chronolog:begin region="evidence" -->
> We've added a new folder and organization system to the website. Check out the video below for a nice overview.
>
> Some highlights:
>
> When you’re viewing a folder, all the images you create will be added to that folder automatically
>
> Folders can be placed into groups to let you sort related projects or ideas.
>
> You can add images to multiple folders. If an image is within folders, they will be shown in the lightbox
>
> It’s now possible to download all the images in a folder just by right-clicking on it and choosing “Download”
>
> You can add items to folders by right-clicking an image, dragging images into folder, or clicking the folder button inside the lightbox
>
> Source: https://updates.midjourney.com/new-tools-for-organization/
