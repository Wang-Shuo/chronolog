# PROMPT BAR & PILLS Typing a single backtick no longer freezes the tab

**Midjourney** · 2026-09-16 · [[Themes/editor-experience|Editor Experience]] · [Official source](https://updates.midjourney.com/alpha-changelog-9-16-26/) · from [[Releases/Midjourney/midjourney-2026-09-16-https-updates-midjourney-com-alpha-changelog-9-16-26-6cfac023|Alpha Changelog - 9/16/26]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> PROMPT BAR & PILLS Typing a single backtick no longer freezes the tab. Typing --no a, b now reads the whole list. Long text wraps instead of clipping. What you type in a pill stays even when a preview pops up. The search drawer shows your Frequent and Recent srefs, click one to filter. The "what persists between prompts and sessions" question is still open. Default parameters are the next step.
