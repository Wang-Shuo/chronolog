# Midjourney launches V7 model speedups today

**Midjourney** · 2025-05-02 · [[Themes/model-support|Model Support]] · Launch · [Official source](https://updates.midjourney.com/fast-mode-for-v7/) · from [[Releases/Midjourney/midjourney-2025-05-02-https-updates-midjourney-com-fast-mode-for-v7-23289fba|Fast mode for V7]]
<!-- chronolog:end -->

<!-- chronolog:begin region="evidence" -->
> We're launching V7 model speedups today. This includes the release of the default fast mode, which makes V7 2x cheaper than before (now about the same price as a V6 job).
>
> The model optimizations mean that jobs will take ~40 seconds on fast mode, and 18 seconds on turbo mode.
>
> The new model should have slightly improved hands, but if you want the old version you can still get it via --q 2 .
>
> We've also added a new "experimental" --q 4 mode which might give you better coherence and details.
>
> If you find any interesting differences or bugs with any of the versions please let us know in #ideas-and-features
>
> Source: https://updates.midjourney.com/fast-mode-for-v7/
